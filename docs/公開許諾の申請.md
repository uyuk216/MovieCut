# 改造版を公開したいとき(公開許諾の申請)

ゆっくりエディタを改造したものや、そのソースコードを公開するには、作者の許可と料金の支払いが必要です(LICENSE.md の追加条項 A2・A3)。自分のパソコンで使うだけなら申請は不要です。

## 申請の流れ

1. 申請を送る(宛先:【連絡先】)
2. 作者が内容を確認する(審査)
3. 承認されたら、料金【料金】を支払う
4. 作者が許諾書を発行する
5. 許諾書の範囲で公開する

## 申請に書くこと

- 申請者の名前(または団体名)と連絡先
- 何を変更したか(機能の追加・修正、見た目の変更など)
- どこで、どんな方法で公開するか(例:GitHub、自分のサイト、配布サイトなど。URLも)
- 公開するもの(アプリのみ / ソースコードも)
- 公開で使う名前(アプリ名)とアイコン
- 無料で配るか、有料で配るか
- 外部エンジン(VOICEVOX、AquesTalk など)の規約を守る方法

## 審査について

- 作者は申請を承認しないことがあります。
- 条件を付けて承認することがあります(例:名前の変更、表示の追加)。
- 審査の期間は【審査期間の目安】です。

## 支払い

- 料金:【料金】
- 支払い方法:【支払い方法】
- 支払いを確認してから、許諾書を発行します。

## 名前とアイコン

許諾書で特に認められない限り、元の名前「ゆっくりエディタ」とアイコンは使えません。別の名前とアイコンを用意してください。

## 注意

- 許諾書は、外部エンジン(VOICEVOX、AquesTalk、ffmpeg)の規約を免除しません。`docs/第三者の規約.md` を見てください。
- 許諾書の範囲を超える公開はできません。

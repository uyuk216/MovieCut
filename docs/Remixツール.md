# Remixツール(音楽の尺合わせ)

Premiere Pro の Remix ツール(音楽クリップを目標の尺へ、フレーズを保って自動で
つなぎ直す機能)の MovieCut 等価機能。音楽クリップと目標の尺を指定すると、
ビート位置を候補に区間を選び直し(繰り返し/省略)、クロスフェードでつないで
目標尺に合わせた新しいクリップ列を生成する。

- 計算(Core、画面・Undo に依存しない): `Sources/MovieCutCore/Remix.swift`(`Remix` / `RemixFallback`)
- アプリ側(解析・Undo・状態欄): `Sources/MovieCut/ProjectModel+Remix.swift`
- 画面: `Sources/MovieCut/RemixSheet.swift`
- テスト: `Tests/MovieCutCoreTests/RemixTests.swift`、`Tests/MovieCutTests/RemixAppTests.swift`

## 使い方

1. 音のあるクリップ(音声・動画。速度変更・逆再生・速度ランプの無いもの)を選び、
   クリップ ▸「Remixツール…」を開く。
2. シートが音声を解析し、ビートの候補(取れなければ音の切り替わり点)を出す。
3. 目標の尺(秒)とクロスフェードの長さ(0〜0.3 秒、既定 0.1 秒)を決める。
   出来上がりの尺・区間数・つなぎ目の数がその場でプレビューされる。
   目標に近づけない組み合わせのときは、理由が表示されて作成できない。
4. 「Remixを作成」を押す。新しいクリップ列は、元クリップのあるレイヤーの末尾に
   隙間なく並べて置かれる。配置は全体で 1 回の Undo で戻せる。

## 仕組みと決まり

- 元クリップは変更しない。区間は元クリップから切り出した新しいクリップで、
  切り出しは通常の分割(`ClipEditing.split`)と同じ経路なので、キーフレーム・
  音声フェード・トランジションの振り分けは分割と同じになる。
- 対象はビート検出と同じ条件のクリップだけ(素材時刻とクリップ時刻が 1 対 1)。

### アルゴリズム

1. 候補: `BeatDetector` でビート格子を求め、信頼度が 0.2 以上ならビート位置を
   候補にする。ビートが取れない素材ではフォールバック(後述)に切り替える。
2. フレーズ化: 候補で区切った原子区間を、目安の長さ(ビート候補では
   候補間隔の中央値 × 4 拍、フォールバックでは 2 秒)以上になるまでまとめて
   フレーズにする。区切りは必ず候補位置に整列する。
3. 区間選定: フレーズを素材の順序どおりに走査し、取る/取らないを決める
   部分集合選択(ビームサーチ。決定的で、同じ入力では同じ結果になる)。
   - 最初のフレーズは必ず取る(曲の頭から始める)。
   - 短縮: フレーズを省略して目標に近づける。繰り返しはしない。
   - 延長: フレーズ列を繰り返した仮想列から選ぶ(曲を繰り返して延ばす)。
     周回をまたぐ接続は別区間になる。
   - 連続して取ったフレーズ(同一周回内で素材上も連続)は 1 区間にまとめる
     (無駄なつなぎ目を作らない)。
   - 出来上がりの尺と目標の差が許容誤差(フレーズ目安の 25%、最低 0.2 秒)を
     超える計画しか作れないときは、黙って大きく外れたものを作らず
     「区間の組み合わせでは目標の尺に近づけませんでした」と表示して止める。
4. クロスフェード: つなぎ目にはフェードのペア(前の区間のフェードアウト +
   次の区間のフェードイン、等パワー曲線、長さは短い側の区間の半分まで)を付ける。
   同一レイヤーでクリップを重ねないという MovieCut の不変条件があるため、
   重ね合わせによるクロスフェードではなくフェードのペアで表す。
   フェードはクリップの内側の処理なので、出来上がりの尺は区間長の合計と一致する。

### フォールバック(ビートが取れない素材)

- 候補は 2 種類の合算: 無音(-40dB 未満)と有音の切り替わり点と、波形の
  立ち上がり(オンセット)のピーク(平均 + 1.5 × 標準偏差 以上、最小間隔 0.3 秒)。
- 全て無音・一定音量のように変化点が取れない素材では候補が空になり、
  「ビートも音の切り替わり点も見つかりませんでした」と表示して止める。
  シートにはフォールバックを使ったことが表示され、作成後の状態欄にも出る。

## 限界

- 歌詞のある素材の連続性は保証しない(つなぎ目で歌詞が途切れたり繰り返したり
  する)。これは Premiere Pro の Remix でも同様の領域。
- 映像付きクリップでは、映像も区間単位でつなぎ直される(音楽専用の処理ではない)。
- 尺はフレーズ単位で合わせるため、目標と完全に一致するとは限らない
  (許容誤差の範囲で最も近い組み合わせを選ぶ)。
- ビート検出の精度に結果が左右される。拍がずれた素材では区切りもずれる。

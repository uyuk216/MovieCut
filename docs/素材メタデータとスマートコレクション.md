# 素材メタデータとスマートコレクション

Premiere Pro の「メタデータ／ラベル／評価」とスマートコレクション相当の実装です。
素材ごとにキーワード・評価・メモ・ラベル色を持ち、素材ブラウザで絞り込み・検索でき、
条件を名前付きで保存する「スマートコレクション」で、一致する素材を自動で集められます。

文字起こしの内容で探す「メディアインテリジェンス検索」(docs/メディアインテリジェンス検索.md)
とは別物です。あちらは素材の中身(話している文)、こちらは人が付けた整理用の情報で探します。

## 使い方

素材ブラウザ(ウインドウ ▸ 素材ブラウザ、または従来の開き方)で操作します。

### メタデータを付ける

1. 素材を選ぶと、右のプレビュー欄の下に「素材のメタデータ」欄が出ます。
2. キーワード(カンマ区切りで複数)、評価(未評価 / ★0〜★5)、ラベル(色 7 色 + なし)、
   メモを入れ、「メタデータを保存」を押します。保存はまとめて 1 回の取り消し(Undo)です。
3. 「メタデータを消去」で、その素材のメタデータをすべて消せます(Undo 1 回)。
4. 一覧の行とグリッドには、付けた評価・ラベル・キーワードの要約が出ます。

### 絞り込み・検索

素材ブラウザ上部の欄で絞り込めます(すべて AND で重なります)。

- 検索語: ファイル名だけでなく、キーワードとメモにも当たります。
- キーワード欄: そのキーワードを持つ素材だけに絞ります。
- 評価: 「★N 以上」を選ぶと、評価が N 以上の素材だけになります(未評価は出ません)。
- ラベル: その色のラベルを持つ素材だけになります。
- 種類(動画・音声・画像)の絞り込みは従来どおりで、上記と AND で重なります。

### スマートコレクション

1. 絞り込み条件を作り、「コレクション名」に名前を入れて
   「今の条件でコレクションを追加」を押すと、条件が保存されます(Undo 1 回)。
   検索語そのものはコレクションに含めません(検索はその場の入力の役割のため)。
2. 「コレクション」の選択欄でコレクションを選ぶと、その条件で絞り込まれます。
   素材にメタデータを付け直すと、コレクションの中身は自動で追随します
   (コレクションは条件だけを持ち、素材のコピーは持ちません)。
3. 「コレクションを削除」で条件だけが消えます。素材やメタデータは消えません(Undo 1 回)。

## 条件の意味(AND / OR)

- **項目の間は AND**: キーワード条件・評価の下限・ラベル・種類・検索語の
  すべてを満たす素材だけが残ります。
- **キーワード条件の中**は、条件の `keywordMode` で決まります。
  `all`(既定)は AND で「指定したキーワードをすべて持つ」、`any` は OR で
  「どれか 1 つでも持てばよい」です。素材ブラウザのキーワード欄は 1 語だけなので
  どちらでも同じですが、保存形式と Core の判定(`MediaFilterCriteria`)では区別します。
- **検索語の中は AND**: 空白で分けた語をすべて含むことが条件で、各語は
  「ファイル名・キーワードのどれか・メモ」のどこかに部分一致すればよい(OR)です。
  大文字小文字・全角半角・濁点の違いは無視します。
- **評価の下限**: 下限が 1 以上のとき、未評価の素材は一致しません。
  下限 0 のときは未評価も一致します。

## 保存形式

プロジェクトファイル(.ymproj / .mcproj)のトップレベルに、使うときだけキーを足します。

- `mediaMetadata`: 素材の参照文字列(`Clip.src` / `mediaPool` の値)をキーにした辞書。
  値は、設定した項目だけを持つオブジェクトです。
  - `keywords`: 文字列の配列(前後の空白なし、空と重複は除く)
  - `rating`: 0〜5 の整数(未評価はキーなし。0 も「評価 0」として残ります)
  - `note`: メモの文字列(空はキーなし)
  - `label`: 色の名前(`red` / `orange` / `yellow` / `green` / `blue` / `purple` / `gray`。
    ラベルなしはキーなし。未知の名前はそのまま保持します)
- `smartCollections`: `{id, name, criteria}` の配列。`criteria` は条件で、
  既定値でない項目だけを書きます(`keywords` / `keywordMode`(`any` のときだけ) /
  `minRating` / `label` / `kind`(`video` / `audio` / `image`) / `text`)。
  条件が空のコレクションは `criteria` キーを持ちません。

保存の約束(既存の作法どおり):

- **メタデータもコレクションも使っていないプロジェクトは、保存バイトが従来と完全一致**
  します(キーを一切書きません)。中身が空になったメタデータも項目ごと消えます。
- 知らないキーは、プロジェクト・メタデータ・コレクション・条件の各階層で
  `extra` に保持して書き戻します。型が違う値も、捨てずにそのまま書き戻します。
- 読み込み時に値は安全な範囲へ整えます(評価は 0〜5、キーワードは 1 素材 100 件まで、
  コレクションは 200 件まで)。正常な値は変えません。

コードの置き場所:

- Core: `Sources/MovieCutCore/MediaMetadata.swift`
  (`MediaMetadata` / `MediaFilterCriteria` / `SmartCollection` / `MediaMetadataEditing`、
  素材ブラウザとの接続は `MediaBrowser.filter(..., metadata:criteria:)`)
- App: `Sources/MovieCut/ProjectModel+MediaMetadata.swift`(Undo 1 回の編集入口)、
  画面は `AudioLibrarySheet`(素材ブラウザ)に統合

## 範囲の割り切り・未対応事項

- **キーは素材の参照文字列そのもの**です。素材ブラウザではファイルの絶対パスが
  キーになります。そのため、相対パスで参照している素材には、ブラウザで付けた
  メタデータが一致しないことがあります(プロジェクト内で完結する参照文字列が正です)。
- **再リンクに追随しません**: 素材の場所を再指定してパスが変わると、メタデータは
  旧パスのキーに残り、新しいパスには付きません(`mediaHints` などと同じキーの考え方
  ですが、再リンク時の付け替えは未実装です)。
- **プロジェクトが参照していないファイル**にも、素材ブラウザの編集欄から
  メタデータを付けられます(キーはそのファイルパスで、今開いているプロジェクトに
  保存されます)。ただし `mediaPool` へは自動で登録しないので、スマートコレクションの
  対象一覧(`MediaMetadataEditing.filteredSources` が数えるのは、クリップの `src` と
  `mediaPool` の和集合)には出ません。素材ブラウザの一覧では、パスが一致すれば
  表示と絞り込みに効きます。
- **複合クリップの中だけにある素材**は、対象一覧(上の和集合)に出ないことがあります
  (既存の素材収集 `MediaFingerprintCollector` と同じ範囲です)。
- スマートコレクションの条件は素材ブラウザの欄(キーワード 1 語・評価の下限・ラベル・
  種類)で作る範囲までです。複数キーワードの `any` 条件や、評価の範囲指定(上限)、
  日付条件などは、保存形式と Core の判定には用意がありますが、作る画面は未実装です。
- メタデータの一括編集(複数素材へ同時付け)は未実装です。1 件ずつの編集のみです。
- パッケージ保存で素材をコピーしたとき、メタデータのキーは元の参照文字列のままです
  (パッケージ側の相対パスへの付け替えは未実装です)。

## 未検証事項

- 画面の実操作(素材ブラウザで編集欄を触る、コレクションを選ぶ)は、単体テスト
  (Core の判定・保存往復、App の Undo 歩数)までで、GUI の実操作確認はしていません。
- 多数の素材(数千件)での絞り込み速度は未計測です(判定は単純な走査です)。

# モーフカット

クリップの境界(前のクリップの終わりと後ろのクリップの頭)を、前後のコマのオプティカルフロー補間と顔の位置合わせで、変形しながらつなぐトランジションです。Premiere Pro のモーフカットに相当します。インタビューの言い直しやジャンプカットの切れ目を目立たなくする用途を想定しています。

## 使い方

- 境界の後ろのクリップを選び、インスペクタの「トランジション」で開始の種類に「モーフカット」を選びます。
- 前のクリップの終了側に付けても同じ境界に効きます。
- 長さは 0.2〜0.5 秒程度の短めが目安です(処理が重いため、長くしすぎないでください)。
- インスペクタの設定は 2 つです。
  - モーフの強さ(0〜1、既定 1): 1 はモーフのみ、0 はクロスディゾルブのみ。途中の値は両者の配合です。
  - 顔の位置合わせを優先(既定オン): 前後のコマで顔の位置が少しずれているとき、中間位置で顔が重なるように合わせます。
- 設定は params の `morphStrength`(数値)と `morphFace`(真偽値)に保存します。既定値のときは書きません。

## 仕組み

1. 境界の相手のクリップから代表コマを取ります(前のクリップなら末尾のコマ、次のクリップなら先頭のコマ)。
2. 前後のコマの間のオプティカルフロー(Vision)を求めます。境界ペアごとにキャッシュします。
3. 顔の位置合わせが有効なら、両方のコマの顔を検出し(これもキャッシュ)、面積が最大の顔どうしの中心差だけ前後のコマを平行移動して、中間位置で顔を重ねます。ずらす量は各軸でフレーム寸法の 20% までです。
4. フローに沿って前後のコマを変形し、トランジション内の進み具合(重み)で混ぜます。
5. 描画は Renderer の共通経路なので、プレビューと書き出しで同じ結果になります。

## フォールバック(クロスディゾルブに落ちる条件)

- フローを求められなかったとき
- 前後のコマの輝度差が場面転換並みに大きいとき(`OpticalFlowInterpolator.sceneCutThreshold` 超え)
- フローの平均量がグリッド短辺の 30% を超えるとき(動きが大きすぎる)
- 両方に顔があり、顔の中心が 50% 以上離れているとき(別の場面とみなす)

次の場合は何もしません(クリップをそのまま描き、壊れた映像にしません)。

- 境界の相手が無いとき
- 前後のコマの寸法が違うとき

## 限界

- 被写体が大きく動く境界や、場面が変わる境界では不自然になることがあります(その場合はディゾルブに落ちます)。
- 文字・複合・シーン・立ち絵のクリップには効きません。映像と画像のクリップだけが対象です。
- 境界の相手は同じレイヤー(トラック)の映像・画像クリップで、間隔が 0.5 秒以内のものです。
- フローと顔検出は重いので、長いトランジションや高解像度では再生が重くなることがあります。

# モーショングラフィックステンプレート(差し替え項目つきアイテムテンプレート)

アイテムテンプレート(#8)に「ここだけ差し替えられる」項目(スロット)を持たせる機能。Premiere の .mogrt(Essential Graphics)に近い差し替えワークフローを、MovieCut 独自形式で提供する。実装は Core(`TemplateSlots.swift` / `ItemTemplate.swift`)とアプリ(`ProjectModel+ItemTemplates.swift`)。

## 使い方

### 保存時にスロットを付ける

1. タイムラインでクリップを選ぶ。
2. 「クリップ ▸ 選択クリップをアイテムテンプレートとして保存…」を開く。
3. 名前を入れ、「差し替え可能項目を付ける(文字・色・画像)」にチェックを入れて(既定でオン)保存する。
4. クリップに実際に値がある項目だけが、スロットの候補として自動で付く。既定値は保存時のクリップの値。チェックを外すと従来どおりスロット無しで保存する。

### 作成・適用時に値を入力する

- 「クリップ ▸ テンプレートからクリップを作成 ▸ 名前」と「クリップ ▸ アイテムテンプレートを適用 ▸ 名前」は、テンプレートにスロットがあるときだけ値入力ダイアログを出す。スロットごとに 1 行で、初期値は既定値。
- 空欄の項目は保存時の値のまま(上書きしない)。無効な値(色の書式違いなど)は、その項目だけ反映せず、状態欄に件数を出す。
- 作成は再生ヘッドの位置に置いて選択する。適用は選択中の同じ種類のクリップへ。どちらも 1 回の Undo。
- スロットが無いテンプレートは従来どおりダイアログ無し。
- 既存クリップへの適用では、スロットの項目だけは中身(文字・色・素材パス)も上書きする。スロット以外のセリフ・素材は従来どおり上書きしない。

## スロットの種類と対象

| 種類(kind) | 対象(target) | 差し替える項目 | 使えるクリップ | 値の形 |
|---|---|---|---|---|
| text | text | 文字 | 文字・ボイス | 文字列(必須なら空白のみ不可) |
| text | subtitleText | 字幕文 | 文字・ボイス | 文字列 |
| color | color | 文字色 | 全種 | `#RRGGBB` / `#RRGGBBAA` |
| color | outline | 輪郭色 | 全種 | `#RRGGBB` / `#RRGGBBAA` |
| color | figureFill | 図形の塗り | 図形 | 色 または `none` |
| color | figureStroke | 図形の線 | 図形 | 色 または `none` |
| image | source(`src`) | 画像・素材パス | 画像・動画・音声 | 空でない文字列 |

- スロットは 1 テンプレートに最大 20 件。id は英数と `.` `_` `-` のみ(最大 40 字)、ラベルは最大 60 字。id が重複したものは先勝ち。
- kind と target が合わないもの、クリップの種類に合わないものは保存時に捨てる。

## 保存形式と後方互換

- 保存先は従来どおり Templates フォルダの `item-templates.json`。
- 各テンプレートに `slots` 配列を足した形。スロットが 0 件のときは `slots` キーを書かない(スロット無しテンプレートの保存形式は従来と同じ)。
- `defaultValue` と `required` は省略可。
- 旧形式の JSON(`slots` キー無し)はそのまま読める。`slots` の一部が壊れていても、そのスロットだけ捨てて残りは読む。読み込み時にスロットは正規化する。

## .mogrt との違い

- .mogrt ファイル自体は読めない・書けない。After Effects / Premiere の内部仕様に依存するため対象外。
- MovieCut 独自形式で、文字・色・画像を差し替えるという同等のワークフローを提供する。アニメーション・エフェクトの内部パラメータをスロットに公開する機能(Essential Graphics のパラメータ公開)はない。公開できるのは上の表の項目だけ。
- 配布用の単独ファイル(.mogrt のような 1 ファイル)への書き出しは未対応。共有はテンプレートの JSON を使う。

## 未検証事項・今後の課題

- 値入力ダイアログと保存ダイアログのチェックボックスは、実機での操作を未確認(自動テストはダイアログを使わない部分のみ)。
- 画像・素材パスの存在確認はしない(未検証。存在しないパスも入力できる)。
- 複数クリップにまたがるテンプレート(プロジェクトテンプレート側)へのスロットは未対応。今後の課題。

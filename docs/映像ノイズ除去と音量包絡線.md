# 映像ノイズ除去と音量包絡線（第3波バッチL: W3-21〜W3-23）

## ブレンドモード（W3-21 / 監査 #52）

基盤（`feat/muse-access`）に実装済み。本バッチでは画素テストを追加して検証を強化した。

- クリップ属性 `blendMode`（未設定 = 通常）。未設定のクリップは保存バイトも描画も従来と完全一致。
- 対応 16 種: 乗算 / スクリーン / オーバーレイ / 比較（暗） / 比較（明） / 覆い焼き / 焼き込み /
  ソフトライト / ハードライト / 差分 / 除外 / 色相 / 彩度 / カラー / 輝度 / 加算。
  描画は Renderer が CGContext のブレンドモードで効かせるため、プレビューと書き出しで同一結果。
- 減算は CGContext に直接の対応モードが無いため未対応（Core Image の CISubtractBlendMode 経由は
  描画経路が二重化するので見送り）。

## 映像ノイズ除去（W3-22 / 監査 #59）

汎用エフェクト群の 1 つとして「ノイズ除去」を追加（`EffectKind.denoise`、画像・動画・文字・複合・立ち絵クリップ）。

- 方式: Core Image の `CINoiseReduction`（空間方向の平滑化）。引数は「強さ」0〜1（既定 0.5）。
  内部写像は `VideoDenoise` に集約: noiseLevel = 0.02 + 0.28 × 強さ、sharpness = 0.4 × (1 − 強さ)。
- 限界（正直な仕様）:
  - 学習型（AI）デノイズではない。強くかけるほど細部も鈍る。
  - 時間方向の処理はしない。前後コマとの比較をしないため、ちらつきの低減は限定的で、
    その代わりプレビューと書き出しで決定的に同じ結果になる。
  - 音声のノイズ除去（AudioFx の denoise）とは別物。こちらは映像専用。
- 追加方式の原則: エフェクトが無い／無効／強さ 0 のクリップは従来と完全一致
  （`EffectPipeline.isIdentity` で解決時に落とされ、速い道のまま）。

## 音量包絡線のタイムライン編集 UI（W3-23 / 監査 #64）

データとミックス反映は既存（`Clip.keyframes["volume"]` → `VolumeEnvelope` → AudioMixer）。
本バッチでタイムライン上の直接編集と、その純粋計算（`VolumeEnvelopeEditing`）を追加した。

操作仕様（選択中の音声・ボイス・動画クリップに、クリップ枠の内側へ折れ線と点を表示）:

- ダブルクリック（クリップ本体）: その位置に点を追加。包絡線が無いクリップでは、まず頭と終わりに
  「いまの設定音量」の基準点を置くので、聞こえ方は変わらない。
- ドラッグ（点）: 時刻と音量を同時に動かす。前後の点は越えられない。離したときに Undo 1 回にまとまる。
- Option+クリック（点）: その点を削除。最後の 1 点を消すと包絡線自体が無くなり、その値が設定音量になる。
- 縦位置は音量 0〜2 に対応（中央が等倍 1.0）。フェードの三角・キーフレームの菱形とは場所が重ならない。

編集はすべて Undo 対応（追加・削除は各 1 回、ドラッグは 1 ジェスチャ = 1 回）。
ミックス・書き出しへの反映は既存の VolumeEnvelope 経路で、テストで担保している。

# おすすめ音声設定の配布

Movie Cut のキャラクターのパネルにある「おすすめ音声設定…」から、声の設定(エンジン・話者・速さ・高さ・抑揚)をまとめて取り込めます。取り込めるのは声のパラメータだけです。キャラクターの名前・色・立ち絵・パス・URL は含めません。

## 形式(JSON、UTF-8、256 KB まで)

```json
{
  "schemaVersion": 1,
  "presets": [
    { "id": "string", "name": "string", "note": "string?", "engine": "voicevox | aquestalk",
      "voice": "string?", "speaker": 3, "speed": 1.0, "pitch": 0.0, "intonation": 1.0, "volume": 1.0 }
  ]
}
```

- `engine` は `voicevox` か `aquestalk`。`voice` は AquesTalk の声の名前、`speaker` は VOICEVOX の話者 ID。
- 数値は Movie Cut の範囲に丸めます(VOICEVOX の速さ 0.5〜2、AquesTalk の速さ 50〜300、高さ -0.15〜0.15、抑揚 0〜2)。`volume` は読むだけで、今は適用しません。
- 知らない項目は無視します。`schemaVersion` が 1 より大きいときは「新しい形式です」と案内します。
- 最大 200 件。`name` は前後の空白を除いて 40 文字まで。

## GitHub Pages で公開する

1. リポジトリに `gh-pages` ブランチを作り、`voice-presets.json` だけを置きます(他のファイルは入れません)。
2. リポジトリの Settings ▸ Pages で、公開元を `gh-pages` ブランチのルートにします。
3. `https://uyuk216.github.io/MovieCut/voice-presets.json` で見えれば、アプリの「ネットから取得」で読めます。
   通信は、この画面を開いたときに一度と、「ネットから取得」を押したときだけ(送るのは取得のリクエストだけ)。HTTPS のみ、10 秒で打ち切り、256 KB まで、Cookie と資格情報は使いません。

ファイルで配るときは、同じ JSON を「ファイルから読み込み…」で選びます。

## 例

```json
{
  "schemaVersion": 1,
  "presets": [
    { "id": "sample-calm", "name": "落ち着いた声", "note": "ゆっくり目", "engine": "voicevox", "speaker": 3, "speed": 0.95, "pitch": -0.02, "intonation": 1.0 },
    { "id": "sample-fast", "name": "早口の声", "engine": "aquestalk", "voice": "れいむ", "speed": 130 }
  ]
}
```

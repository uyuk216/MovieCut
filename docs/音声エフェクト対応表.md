# 音声エフェクト対応表(YMM4 監査 #65 / #66)

- 対象: 第3波バッチK(W3-06 音声エフェクト群 + W3-24 音声ノイズ除去)
- 実装ブランチ: `feat/audio-effects`
- 監査出典: `ymm4-audit-2026-11-19.md` 3.9 節(音声エフェクト 22 種は公式リリースノート由来)

## 設計の原則

- **追加方式**: 新規エフェクトは `Clip.audioFx.extended` という 1 つの任意キーにだけ入る。
 付けていない/無効なだけのクリップは、音もプロジェクトファイルも従来と**バイト単位で一致**する
 (テスト `testEmptyExtendedWritesNothing` / `testMixdownDisabledExtendedIsByteIdentical` で保証)。
- **内蔵の音声合成スタックには触らない**。エフェクトはミックス段(`AudioMixer` → `AudioFxChain`)
 でのみ効くので、プレビュー・書き出し・試聴・ラウドネス測定がすべて同じ音になる。
- 信号処理は純粋な Swift DSP(RBJ 係数・Freeverb 等の既存実装と同じ流儀)。乱数なし=決定的。
- 処理順(固定): 速度/音程 → ノイズ除去(簡易/スペクトル)→ ゲート → 3バンドEQ → コンプレッサー
 → リバーブ → ディレイ → **拡張チェーン** → リミッター → ノーマライズ → 音量/フェード/パン。
 拡張チェーン内部: ハイパス → ローパス → バンドパス → ノッチ → パラメトリックEQ(5バンド)
 → ディストーション → チューブ → ワウ → コーラス → フランジャー → フェイザー → トレモロ
 → ビブラート → エコー → ロボット → 低音質化。
 リミッターが最後段(拡張の前段ではなく後)なので、歪み系を足しても天井は守られる。

制約(正直な限界):
- フィルタは種類ごとに 1 スロットずつ。同時に同じ種類を 2 つ重ねることはできない。
- シェルフ(高域/低域)は 3バンドEQ の帯域として提供し、周波数と Q は固定(100Hz/8kHz)。
- チューブとロボット化は近似であり、YMM4 と同じ音にはならない。
- エフェクトのキーフレーム(時間変化)には未対応(クリップ単位で固定値)。

## 音声ノイズ除去(#66)

既存実装(本バッチ以前)を土台に、本バッチではミックス経由の検証テストと本書の明記を追加した。
方式は 2 段 + ゲートで、すべて古典的手法(学習型ではない)。

| 方式 | 内容 | 得意 | 苦手 |
|---|---|---|---|
| 簡易(既定) | 80Hz ハイパス + 静かな所(RMS −30dBFS 以下)を下げるエクスパンダー。強さ 0〜1 | ファン音・部屋鳴りなど「無音区間のノイズ」 | 声に重なったノイズは消えない |
| 強(スペクトル) | スペクトルゲート。最も静かな 0.5 秒からノイズプロファイルを作り、周波数ごとに「ノイズより十分大きい成分だけ通す」柔らかいマスク(STFT 2048/ホップ 512) | 声の最中の定常ノイズ(エアコン等) | 突発音・非定常ノイズ。静かな区間が無い素材ではプロファイルが声を拾い、効きが弱まる/声が痩せる |
| ノイズゲート | しきい値以下の音を閉じる(ヒステリシス+ホールド付き) | 無音区間を完全に消したい場合 | ノイズそのものの低減ではない |

限界(過剰な期待を避けるための明記):
- 学習型(いわゆる AI ノイズ除去)ではないため、声と同帯域・同時刻のノイズは分離できない。
- スペクトル方式は「最も静かな 0.5 秒 = ノイズだけ」という仮定に依存する。
- 強さを上げるほど声の子音や余韻も削れる(ミュージカルノイズが出ることがある)。

## 保存形式

- キー: `audioFx.extended` 以下に各エフェクト(すべて任意)。未知のキーは `extra` に残して書き戻す(既存の作法と同じ)。
- 既存プロジェクトの読み書きは従来と完全一致(拡張が無い限り `extended` キーは書かれない)。

## UI 配線の到達範囲

- インスペクタ「音声」節に拡張パネルを追加し、**全 16 スロット**(フィルタ 4 種・5バンドEQ・
 ディストーション・チューブ・コーラス・フランジャー・フェイザー・トレモロ・ビブラート・
 ワウ/オートワウ・エコー・低音質化・ロボット化)をトグル+スライダーで操作可能にした。
 スライダーのドラッグは 1 回の Undo にまとまる(既存パネルと同じ)。
- 未達: エフェクトのプリセット集、エフェクト順の入れ替え UI、パラメータのキーフレーム。

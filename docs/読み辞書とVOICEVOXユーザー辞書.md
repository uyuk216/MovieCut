# 読み辞書と VOICEVOX ユーザー辞書

## 読み辞書(アプリ内)
セリフの表記を読み(かな)に置き換えてから音声合成に渡す辞書。プロジェクト(`readingDictionary`)に保存する。
メニュー「読み辞書を編集…」で編集する。字幕は元の表記のまま。

### 項目
| 項目 | 内容 | 未指定のとき(エンジン反映時) |
|---|---|---|
| 表記 (`word`) | 置き換える文字列 | 必須 |
| 読み (`reading`) | かな(反映時にカタカナへ変換) | 必須 |
| アクセント型 (`accentType`) | 0=平板、n=n モーラ目の後で下がる | 0 |
| 品詞 (`partOfSpeech`) | 固有名詞 / 普通名詞 / 動詞 / 形容詞 / 接尾辞(VOICEVOX の word_type と同値) | 固有名詞 |
| 優先度 (`priority`) | 0〜10(範囲外は丸める) | 5 |

アクセント型・品詞・優先度は VOICEVOX ユーザー辞書への反映専用。アプリ内の置き換え(読み上げ文への適用)は表記と読みだけを使う。
旧プロジェクト(表記と読みだけ)はそのまま開け、3 項目が未指定なら保存ファイルにも書き出さない。
テキスト形式(`表記,読み`)の取り込み・書き出しは従来どおり 2 列のみ(拡張項目は含まない)。

### 適用されるエンジン
読み置換は合成の直前に `DictionaryVoiceProvider` が行い、VOICEVOX・AquesTalk(say 代替含む)・COEIROINK・SHAREVOX など全エンジン共通。
台本から声を作るときは `ScriptTimeline.add` が生成時に適用する。

## VOICEVOX user_dict への反映
読み辞書シートの「エンジンへ反映」ボタンで、編集中の辞書(保存前でも可)をエンジンのユーザー辞書へ送る。
接続先はプロジェクトの VOICEVOX URL(`voicevoxUrl`)。

- 使う API: `GET /user_dict`、`POST /user_dict_word`、`PUT /user_dict_word/{uuid}`、`DELETE /user_dict_word/{uuid}`(パラメータは `surface` `pronunciation`(カタカナ)`accent_type` `word_type` `priority`)。
- 同期方式: 表記(surface)をキーにした差分同期。
  - エンジンに無い表記は追加、表記が同じで内容が違えば更新、同じならそのまま。
  - エンジン側にしかない語(VOICEVOX 本体で登録した語など)は既定では消さない。「辞書にない語もエンジンから削除する」をオンにしたときだけ削除する(同じ表記の 2 語目以降も削除)。
  - 計画は純粋関数 `VoicevoxUserDictSync.plan`、実行は `VoicevoxClient.syncUserDict`。
- 結果表示: 追加・更新・削除・変更なしの件数と、失敗した語(表記と理由)をシート内に表示する。語ごとの失敗は他の語を止めない。
- エンジン未起動: 辞書の取得で通信に失敗した時点で止め、「VOICEVOX に接続できません…起動してからもう一度」と表示する(アプリは落ちない)。何も変更されない。
- 反映はエンジン側の辞書(エンジンの設定フォルダ)に残る。アプリ内辞書の保存とは独立した操作で、「保存」では送らない。

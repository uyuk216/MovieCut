# カラーカーブとHSLセカンダリ

ブランチ `feat/color-curves-hsl`。仕様は `SPEC-color-curves.md` に従う。
Premiere Pro の Lumetri「カーブ」「HSL セカンダリ」に相当する色補正を、既存の CIColorCube 基盤の上に追加で実装する。既存エフェクトの挙動は変えない（追加のみ）。

## 概要

- **カラーカーブ（`colorCurves`）**: トーンカーブ（マスター・赤・緑・青）と、色相による 3 種のカーブ（色相→色相・色相→彩度・色相→輝度）を持つ。
- **HSL セカンダリ（`hslSecondary`）**: 色相・彩度・輝度の範囲で色を選び、その範囲だけに色相シフト・彩度倍率・露出（EV）をかける。
- どちらも引数はすべて Double で、キーフレームに対応する。

## 使い方

### カラーカーブ（インスペクタ）

エフェクトカードで `カラーカーブ` を選ぶと、汎用スライダーの代わりにカーブエディタが出る。

- **トーンカーブ**
  - 上部のセグメント（マスター / 赤 / 緑 / 青）で編集するチャンネルを切り替える。選んだチャンネルの曲線を描画に表示する。
  - 制御点は 5 点（横軸の位置は固定。左から 0 / 0.25 / 0.5 / 0.75 / 1）。点を縦にドラッグすると、その点の出力値（y）を変えられる。
  - 「リセット」ボタンで、そのチャンネルを恒等（入力＝出力）に戻す。
- **色相カーブ（3 種）**
  - 色相→色相・色相→彩度・色相→輝度の 3 つのエディタがある。
  - 横軸は入力色相。背景に虹色の帯を薄く描く。制御点も 5 点で、縦ドラッグで値を変える。
  - 縦軸の範囲と恒等線は種別ごとに異なる（色相シフトは −180〜180°、彩度倍率は 0〜2、輝度オフセットは −0.5〜0.5）。

ドラッグ中はキーフレームの値として書き込まれ、ドラッグ終了で「カーブの変更」として Undo 1 回にまとまる。

### HSL セカンダリ（インスペクタ）

HSL セカンダリは汎用スライダーのまま編集する。

- 色相の範囲: 中心（°）、幅（°）、ぼかし（°）
- 彩度の範囲: 下限、上限、ぼかし
- 輝度の範囲: 下限、上限、ぼかし
- 補正: 色相シフト（°）、彩度、露出（EV）
- 全体: 強さ（0〜100%）

範囲の外側は補正されず、範囲の端はぼかし幅の中で滑らかに変わる。

## 基盤の共有設計

- **カーブは CIColorCube の LUT 化**: カラーカーブは `ColorCurves.cubeData` で 33³ の RGBA 格子を作り、`CIColorCube` で適用する。適用の型は既存の色補正（`colorWheels` / `highlightRolloff`）と同じ（unpremultiply → CIColorCube → premultiply）。既存の `ColorWheels` は 17³ を使う。
- **HSL 変換は独立部品**: RGB↔HSL の変換は `ColorHSL` に分けた純粋関数。
- **HSLSelection は補正と分離した独立部品**: 範囲選択（色相・彩度・輝度の重み）は `HSLSelection` にあり、補正（`HSLSecondary`）とは別。将来の HSL マスキングはこの部品をそのまま使う想定。`maskCubeData` は重みをグレースケールで出す CIColorCube データを作る（マスク画像生成の土台）。

## 引数とキーフレーム

- 引数はすべて Double。既存の機構により、項目名 `fx.<番号>.<引数名>` でキーフレームにできる。
- カラーカーブの引数（全 35 個）:
  - トーン: `master0`〜`master4`、`red0`〜`red4`、`green0`〜`green4`、`blue0`〜`blue4`（0〜1、既定は各点の x と同じ値）
  - 色相→色相: `hueHue0`〜`hueHue4`（−180〜180、既定 0）
  - 色相→彩度: `hueSat0`〜`hueSat4`（0〜2、既定 1）
  - 色相→輝度: `hueLum0`〜`hueLum4`（−0.5〜0.5、既定 0）
- HSL セカンダリの引数（13 個）: `hueCenter` / `hueWidth` / `hueFeather` / `satMin` / `satMax` / `satFeather` / `lumMin` / `lumMax` / `lumFeather` / `hueShift` / `satScale` / `exposure` / `strength`。
- 例: トーンのマスター中点は `fx.<番号>.master2` でキーフレームにできる。
- 既定値のままのエフェクトは恒等とみなされ、描画時に除外される。

## 制限

- トーンカーブ・色相カーブの制御点は、横軸の位置を固定した 5 点のみ。点の追加・削除や横方向の移動はできない。
- LUT は 33³ の格子で、色は格子に量子化される。
- HSL セカンダリの範囲をプレビューするマスク表示は未実装。範囲の確認は数値（スライダー）と映像の見た目で行う。

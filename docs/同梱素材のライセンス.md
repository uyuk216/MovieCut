# 同梱素材のライセンス

素材ブラウザの「Movie Cut 同梱」に並ぶ素材(効果音 12・背景 6・図形 6)は、すべて Movie Cut が自分で合成・描画したものです。第三者の音・画像・フォントは使っていません。

**このアプリが生成したものでライセンス自由**です。商用・非商用を問わず、クレジット表記なしで、作った動画に使えます。素材そのものを再配布して売ることだけはしないでください(自分で作り直せる単純なものなので、法的な縛りは付けません)。

- 作り方: `Sources/MovieCutCore/BuiltInSounds.swift`(効果音。固定の式と固定の乱数の種で合成。同じ入力なら毎回同じ音)、`BuiltInImages.swift`(背景・図形。CoreGraphics で描画)。
- 置き場所: Application Support の `MovieCut/Bundled/`(public 版は `Movie Cut (Public)/Bundled/`)。初めて開いたときに作り、以後はキャッシュを使います。式を変えたときは `BuiltInLibrary.version` を上げると作り直します。
- 一覧: 効果音-クリック / カチッ / ポップ / ぼよん / シュッ / ヒュー / チャイム / ベル / ライザー / ドン / ピコン / できた、背景-夕焼け / うみ / ミント / 夜空 / みずたま / ストライプ、図形-まる / ほし / ハート / やじるし / ふきだし / ろっかく。

# ノード式グレーディング

映像などのクリップに「グレーディングノードの直列リスト」を持たせ、上から順に評価して色を作る。ノードの中身は既存のカード式エフェクトをそのまま再利用する（ノード専用の色補正は持たない）。

## 使い方
- クリップのインスペクタ ▸ エフェクト欄の下「グレーディングノード」。
- 「＋ ノードを追加」: カラーホイール／LUT／ホワイトバランス／カラーカーブ／HSLセカンダリ／露出／コントラスト／彩度。
- 一覧で、チェックで有効・無効、行クリックで選択、↑↓で順番（上ほど先に評価）、×で削除。
- 選択中のノードは、不透明度と中身のパラメータ（既存のカード式と同じスライダー、LUT は「選ぶ…」で .cube）を編集できる。Undo はノード操作ごと（スライダーはドラッグ全体で 1 回）。
- カラーカーブのノードは追加できるが、曲線エディタは出ない（スライダー列）。曲線の編集は従来のエフェクトカードで行う。

## 仕様
- 型: `GradeNode`（`Sources/MovieCutCore/GradeNode.swift`）。名前／有効・無効／不透明度（0〜1）／中身 `[Effect]`。編集は `GradeNodeEditing`（純粋関数）。
- 評価順: 入力色空間の変換（`.colorSpace`）→ **ノード（上から順）** → 従来のカード式エフェクト。Renderer の `resolvedEffects` が `.gradeNode` を並べ、`EffectPipeline.apply` が評価する。
- 直列評価: 各ノードは前のノードの出力を入力にする。順序は結果に効く（非可換）。
- 無効ノード・不透明度 0・中身が何もしない値のノードは素通し（描画経路にも載らない）。
- 不透明度: ノードの補正結果と、ノードへの入力を `CIDissolveTransition` で線形に混ぜる（事前乗算の RGBA。1 で補正結果そのまま、0 で入力のまま）。
- ノードの中で使える中身: 明るさ・コントラスト・彩度・色相・露出・モノクロ・セピア・LUT・色調転写・ホワイトバランス・カラーホイール・カラーカーブ・HSLセカンダリ・ハイライト補正・反転・ポスタリゼーション。ぼかし系など絵の外へはみ出す種類は、ノードの中では無視する。
- 中身にキーフレームは付けない（固定値）。
- 対象クリップ: エフェクトを付けられる種類（画像・映像・文字・複合・立ち絵）。

## 保存と後方互換
- クリップの `gradeNodes`（配列）。ノードが無い・空のときは書かない。`enabled` は false のとき、`opacity` は 1 でないときだけ書く。
- フィールドの無い旧プロジェクトは、ノード無しとして従来どおり開く。**ノード無しのクリップは描画経路も結果も従来と同一**（速い道・複合クリップの直描きもそのまま）。
- 読めない形の `gradeNodes` や、ノード内の知らないキーは捨てずに書き戻す。

## 割り切り
- 1 ノードに複数エフェクトを入れる UI は未対応（モデルは `effects` 配列で対応済み。UI は 1 種類ずつ追加）。
- ノードごとのマスク（キー）・ノード分岐・並列ノードは未対応（直列のみ）。
- exo／ymmp への書き出しではノードは反映されない（入力色空間と同じ扱い）。

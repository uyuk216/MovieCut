# 画面収録と自動化(フェーズ D-2 / D-3)

## 画面収録(X-3)

ファイル ▸ **画面を収録…** から、Mac の画面を動画ファイル(.mov / H.264)にして、そのままプロジェクトの素材として取り込めます。

- 対象: **画面全体** / **ウィンドウ 1 つ** / **範囲(矩形)**(ディスプレイ左上からの位置と大きさをポイントで指定)
- 音声: システムの音(アプリから出る音)を入れるかどうかを選べます。マイクは使いません(マイクの許可も求めません)
- フレームレート: 15 / 30 / 60 fps
- 保存先: 既定は「ムービー」フォルダ。シートで変更できます。ファイル名は「画面収録 日時.mov」(同名があれば連番)
- 収録が終わると、既存の「素材を追加」と同じ経路で自動的にプロジェクトへ入ります
- 画面全体・範囲の収録では、Movie Cut 自分のウィンドウは映り込みません(操作シートが見えないように除外しています)

### 許可(画面収録)

macOS の「画面収録」の許可が必要です。許可が無いときは収録を始めず、シートに案内を出します。

- 「許可を求める」: OS の確認を出します
- 「システム設定を開く」: システム設定 ▸ プライバシーとセキュリティ ▸ 画面収録 を開きます。許可のあと、アプリの再起動が必要なことがあります

実装: ScreenCaptureKit(`SCStream`)+ AVAssetWriter。設定・状態遷移・検証・名前付けは Core の `ScreenRecording.swift`、実キャプチャはアプリ側の `ScreenRecorder.swift`、画面は `ScreenRecordingSheet.swift`。失敗はすべて日本語の理由つきでシートに出し、アプリは落としません。

## Shortcuts / AppleScript(X-4)

外部の自動化から、書き出しなどの主要操作を呼べます。書き出しの実体はアプリ画面・コマンドラインと同じ `ExportJob` で、Core の `AutomationExport` が引数の検証と計画づくりを担います(二重実装にしていません)。コマンドライン(`moviecut-cli export`)は従来どおりで、最終的に同じ `ExportJob` へ合流します。

### Shortcuts(App Intents)

ショートカットアプリで次のアクションが使えます(アプリを .app として組み立てたときに登録されます)。

| アクション | 引数 | 結果 |
|---|---|---|
| プロジェクトを書き出す | プロジェクト(ファイル)、プリセット(既定は「プロジェクトの設定のまま」) | 書き出したファイルのパス。書き出し先はプロジェクトと同じフォルダ |
| プロジェクトの情報を見る | プロジェクト(ファイル) | 大きさ・フレームレート・長さ・トラック数・クリップ数のテキスト |
| プロジェクトを作る | 保存先フォルダ、名前 | 作ったプロジェクトのパス(同名は上書きしません) |

### AppleScript

`.app` に同梱の `MovieCut.sdef`(Info.plist で有効化)で、次のコマンドが使えます。

```applescript
tell application "Movie Cut"
    export project (POSIX file "/path/to/project.mcpjc") preset "youtube1080"
    project info (POSIX file "/path/to/project.mcpjc")
end tell
```

- `export project`: 直接パラメータ = プロジェクトファイル。任意引数 `output`(書き出し先ファイル)、`preset`(組み込みプリセットの CLI 名、または保存したプリセット名)。書き出しが終わるまで待って、書き出したファイルを返します
- `project info`: 要約テキストを返します(読み取りのみ)

引数の変換はアプリ側の `ScriptCommands.swift`、実体は Intents と同じ `AutomationExport` です。

# テキスト装飾タグ（文字制御タグ）

テキストクリップと字幕（ボイスクリップ）の本文に、YMM4（ゆっくりMovieMaker4）互換の
**文字制御タグ**を埋め込むと、文字単位で色・サイズ・フォント・ルビなどを変えられます。
仕様は YMM4 公式の「文字制御タグを使用し、テキストの装飾や表示タイミングを制御する」
（https://manjubox.net/ymm4/faq/editing/text_control_tags）に合わせています。

- タグは**本文テキストの中の記法**です。プロジェクトファイルの形式は変えていません。
  タグを含まないテキストの描画・保存は従来と完全に同じです。
- `.ymmp` から取り込んだ YMM4 のテキストも、そのまま装飾つきで表示されます。
- 解釈は `TextMarkup`（`Sources/MovieCutCore/TextMarkup.swift`）、描画は
  `RendererTextMarkup.swift`（横書き）と縦書き経路（`RendererTextChars.swift`）です。

## 共通ルール

- タグ名は大文字・小文字を区別しません（`<s>` と `<S>` は同じ）。
- **構文として不正なタグは、そのまま文字として表示されます**（落としません）。
- タグを文字として表示したいときは先頭に `\` を付けます: `\<s20>` → `<s20>` と表示。
- パラメータの前後にスペースを入れても動作します（例: `<s 120>`, `<rb 東京, とうきょう, 30>`）。
- タグは「書いた位置から後ろ」に効く状態変更型です。改行をまたいでも続きます
  （ただし `<p>` の X オフセットだけは改行で 0 に戻ります）。
- 多くのタグで四則演算が使えます: `+=N` 加算、`-=N` 減算、`*=` 乗算、`/=` 除算
  （基準はそのタグの現在の値）。

## 対応表

| タグ | 書式 | 対応 | 備考 |
|---|---|---|---|
| 色 | `<#rrggbb>` `<#rrggbbaa>` `<#文字色,装飾色>` `<#色名>` `<#>` | ✅ | 装飾色は MovieCut では縁の色。短縮形（1/2/3/4 桁）展開と CSS 色名（約148色）に対応。aa は不透明度として描画に反映 |
| フォント | `<sN>` `<sN,フォント名>` `<sN,フォント名,BISU>` `<s,フォント名>` `<s,,B>` `<s>` | ✅（一部） | サイズは px として扱う。BISU = 太字/斜体/打ち消し/下線（全置換）。末尾の装飾種別（0-6）は解釈するが描画では使わない（MovieCut の装飾モデルに無いため） |
| フォント名・スタイル | `<@フォント名>` `<@フォント名,BISU>` `<@,BISU>` `<@+B>` `<@-I>` `<@+B-I>` `<@>` | ✅（一部） | 全置換と差分（`+`/`-`、`+=`/`-=` 形も可）の両対応。`<@>` はサイズを戻さない。装飾種別 0-6 は上と同じく未使用 |
| ルビ | `<rb親文字,ルビ>` `<rb親文字,ルビ,N>` `<rb親文字,ルビ,N,X,Y>` `<rb親文字,ルビ,,X,Y>` `<rb親文字,ルビ,N,X,Y,フォント,BI,文字色,装飾色>` | ✅ | サイズ N は %（既定 50、四則演算は既定 50 に対する演算）。親文字・ルビ内のカンマは `\,` でエスケープ。BI は B/I のみ。横書きは親文字の上、縦書きは列の右に表示 |
| 字間 | `<lsN>` `<ls>` | ✅ | px 指定。四則演算の基準は現在の字間（初期値はクリップの字間） |
| 座標 | `<pX,Y>` | ✅ | 符号なし=絶対、符号あり=相対。Y は下が正。X は改行でリセット |
| 座標（サイズ比例） | `<ppX,Y>` | ✅ | 値 100 = 現在のフォントサイズ 1 文字分。`+=`/`-=` も比例単位、`*=`/`/=` は px 値への倍率 |
| 回転 | `<rotN>` `<rot>` | ✅ | 度指定、四則演算は累積。同じ回転が続く文字のまとまりを、その中心で時計回りに回す |
| 表示速度 | `<rN>` `<r>` | ⚠️ 消費のみ | 構文が合えばタグとしては消えるが、表示タイミングへの効果は付けていない（MovieCut の文字アニメーションはクリップ単位の設定のため） |
| 待機 | `<wN>` `<w*N>` | ⚠️ 消費のみ | 同上 |
| クリア | `<c>` `<cN>` | ⚠️ 消費のみ | 同上 |

## 表示の範囲と制限

- **横書き・静止画**が正式対応です。行の中でサイズ・フォント・色が混在でき、
  ベースラインは行で揃います。グラデーション（TextStyle）は文字のまとまり単位で掛かります。
- **縦書き**では、タグは消費され（タグ文字は描かれません）、本文は従来の縦書きで表示されます。
  装飾（色・サイズ等）は付きませんが、**ルビは列の右側に縦書きで表示**されます。
  ルビのある縦書きは、読みを置く分だけ列の間隔が広がります。
- **文字ごとのアニメーション**（タイプライター等）の間は、装飾スタイルとルビは付きません
  （タグは消費され、文字数はタグを除いて数えます）。
- クリップのルビ（`Clip.ruby`、字幕ファイルの `<ruby>` 取り込み分）も、横書きの装飾経路と
  縦書きの両方で表示されます。従来は縦書きでは出ませんでした。
- ルビのある行は、読みの高さぶん行間が広がります（従来のクリップルビと同じ規則）。

## 例

```
<#ff0000><s80><rb東京,とうきょう><s><#>は<rb日本,にほん>の首都です
```
→ 「東京」は赤色・80px でルビ付き、「日本」は通常色でルビ付きになります。

```
通常<@+B>太字<@+I>太字+斜体<@-B>斜体のみ<@>通常
<ls20>字間広め<ls>通常に戻る
<rot30>斜めテキスト<rot>通常テキスト
```

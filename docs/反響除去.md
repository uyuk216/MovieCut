# 反響除去（ブランチ feat/pro-dereverb-20261128）

部屋の残響（直接音のあとに遅れて続く響き）を減らす音声エフェクト。ノイズ除去（簡易／強）と並ぶ `AudioFx` の項目で、再生・書き出しの両方に同じ経路で効く。

## 使い方

インスペクタ「音声」→「反響除去」スイッチをオン → 「反響除去の強さ」スライダー（1〜100%、既定 50%）。オフにすると 0 に戻って保存からも消える。音声・ボイス・動画クリップが対象（フリーズフレームは無音なので対象外）。

## 方式（古典 DSP・決定的）

`SpectralDenoise` と同じ STFT（窓 2048・Hann・ホップ 512 = 75% 重ね）に乗せたスペクトル減算（Lebart / Habets 系）。

1. 遅延成分の推定: `late[k] = 10^(−6·Δ/T60) · P[t−D][k]`。D フレーム前（D = 6、約 64 ms）の観測パワーが、残響の減衰ぶんだけ小さくなって今に重なる、というモデル。想定 T60 は 0.5 秒で固定。
2. ゲイン = `√clamp(1 − γ·late/P, 床, 1)`。パワーは隣の 3 bin で平滑化し、下がるのはゆっくり（ぶつぶつ切れない）。
3. 左右でゲインを共有する（左右のパワー平均から 1 本のゲインを作り両方に掛ける）。左右の比・相関が変わらないので定位が崩れない。モノは左右同一入力として同じ扱い。
4. 強さ s（0〜1）で γ = 4·s、床 = −(6 + 24·s) dB。**s = 0 は処理を挟まず素通し**（バイパスとビット一致）。乱数を使わないので、同じ入力なら必ず同じ出力。

実装は `Sources/MovieCutCore/Dereverb.swift`。重ね合わせの枠は `SpectralDenoiseSource` を `StereoFrameProcessor` で一般化して共用した（ノイズ除去の挙動は変えていない）。

## 処理順

速度（AudioRemap）→ 音程 → ノイズ除去（簡易は後段のチェーン、強（スペクトル）は入力側）→ **反響除去（入力側）** → ノイズゲート → EQ → … → ノーマライズ。

反響除去をノイズ除去のあとに置く理由: ノイズの底を残響の尾と取り違えず、またノイズ除去のプロファイルを素の入力から作れるため。ノーマライズの測定にも同じ経路を通すので、倍率は反響除去後の音で決まる。

## 保存形式

`audioFx.dereverb`（0〜1 の数値）。0・未設定は書かない（使わない既存プロジェクトは保存内容が従来と一致）。読めない値は捨てず `extra` に残して書き戻す。`cacheToken` に入るので、変えると再生用ミックスが作り直される。

## 限界

- **学習型ではない。** 学習型の音声修復（ニューラル dereverb など）はローカルの推論エンジンが無いため対象外。ローカルエンジンが入ったら別項目として追加する想定。
- 想定残響時間（T60 0.5 秒）は固定。実際の残響が大きく違う部屋では効きが弱い／強すぎる。
- 強い残響、音楽素材、持続音（伸ばした声・楽器）では、直接音まで削って不自然（こもる・ポンピング）になり得る。音楽素材には使わないこと。
- 合成残響（下記）での数値は目安で、実際の部屋の録音では減り方は小さくなる。

## テスト

`Tests/MovieCutCoreTests/DereverbTests.swift`。合成残響（800 Hz のトーンバースト × 疎な指数減衰インパルス応答、T60 = 0.5 秒）で、バースト終了 80 ms 後〜次のバースト直前の「尾」のエネルギーを測る。

| 強さ | 尾の減少 | 直接音の減少 |
|---|---|---|
| 0.5 | 約 6 dB | 0.1 dB |
| 1.0 | 約 9.6 dB | 0.1 dB |
| ミキサー経由（0.9） | 約 9 dB | — |

ほかに、強さ 0 のビット一致、無音、ピーク上限、ステレオ（左右比・相関）、保存・復元、ミキサー経由（位置ずれなし・ノイズ除去との併用）を確認する。

# HSLマスキング（Premiere Pro 27.0「HSL マスキング」のローカル等価）

ブランチ `feat/hsl-mask`。
棚卸し表 `premiere-inventory.md` カラー節「HSL マスキング」が仕様の起点。
色相・彩度・輝度で領域を切り分け、その部分だけを残す（外は透明）マスクを、
クリップのマスク種別として追加した。既存の形マスク・オブジェクトマスク・
HSL セカンダリの挙動は変えていない（追加のみ）。マスク未使用時は従来と画素一致。

## 使い方

1. 映像・画像など、エフェクトを扱えるクリップを選ぶ。
2. プロパティ欄の「HSLマスク」節で「色の範囲で切り抜く（外は透明）」をオンにする。
3. 範囲を指定する（HSL セカンダリと同じ項目立て）。
   - 色相: 中心（°）、幅（°）、ぼかし（°)。幅 360 で色相は無条件になる。
   - 彩度: 下限、上限、ぼかし。
   - 輝度: 下限、上限、ぼかし。
   - 端はぼかしの幅の中で滑らかに（smoothstep で）切り替わる。
4. 「反転（中を透明にする）」で選択範囲の外側を残す向きに変えられる。
5. 範囲の確認には「マスクプレビュー」を使う（次節）。
6. オフにするとマスクは外れる（`Clip.hslMask` が nil になり、ファイルにも書かれない）。

### 対象だけに補正をかけたいとき

HSL マスク自体は「残す／消す」のマスクなので、補正そのものは持たない。
Premiere と同じ作法で、クリップを複製して片方にだけ補正（エフェクト）をかけ、
そちらに HSL マスクを付ける。複製元（補正なし＋反転マスク）と重ねると、
選択範囲だけ補正が効いた絵になる。形マスク・オブジェクトマスクでも同じ作法が
使われている（`docs/オブジェクトマスク.md` 参照）。

### 他のマスクとの併用

形マスク（`Clip.mask`）、オブジェクトマスク（`Clip.objectMask`）と併用できる。
複数あるときは全部かかる（積＝AND。各マスクで残った部分だけが最終的に残る）。
適用順は、エフェクトの後に 形 → オブジェクト → HSL の順。

## マスクプレビュー

選択範囲を確認するための表示切替。「HSLマスク」節の「マスクプレビュー」で選ぶ。

- **オフ**: 通常のマスク適用。
- **外をグレーで表示**: 選択範囲の外が無彩色（グレー）になり、中は元の色のまま残る。
  透明にはならないので、範囲の形だけを確認できる。
- **中を色付きで表示**: 選択範囲の中がマゼンタで色づく。重みの弱い所は薄く色づく。

注意: プレビューは表示モードとしてクリップに保存され、書き出しにも効く。
確認が終わったらオフに戻すこと（節の中にも注意書きが出る）。

## HSL セカンダリとの違い

| | HSL セカンダリ（既存） | HSL マスク（本実装） |
|---|---|---|
| 種類 | エフェクト（色補正） | クリップのマスク |
| すること | 選んだ範囲だけ色相・彩度・露出を変える | 選んだ範囲だけ残し、外を透明にする |
| 透明度 | 変えない | 変える（外は透明） |
| 範囲選択 | `HSLSelection` | 同じ `HSLSelection` を共有 |
| 保存先 | `Clip.effects` の引数 | `Clip.hslMask` |
| 組み合わせ | 他エフェクトと直列 | 形・オブジェクトマスクと積で併用可 |

範囲選択の部品と数値の意味（中心・幅・ぼかし等）は完全に共通なので、
セカンダリで決めた範囲の値をそのままマスクへ写せる。

## 仕組み（既存基盤の再利用）

新規の基盤は作らず、HSL セカンダリ実装時に用意された部品と、マスク適用の
既存経路への配線で実現した。

| 段階 | 再利用した基盤 |
|---|---|
| 範囲選択 | `HSLSelection`（色相・彩度・輝度の重み 0〜1。HSL セカンダリと共有） |
| マスク LUT | `HSLSelection.maskCubeData`（重みをグレースケールで出す CIColorCube データ 33³）。反転時は重みを 1 − w にして使う |
| マスク画像生成 | `HSLMaskRenderer.maskImage`：クリップ自身の画素を unpremultiply → CIColorCube → premultiply し、白＝残す・黒＝消すのマスク画像にする（HSL セカンダリの適用の型と同じ） |
| マスク適用 | 形マスクと同じ `CIBlendWithMask` 経路。`Renderer.drawEffectedClip` でエフェクトの後、形・オブジェクトマスクに続けてかける |
| 選択の基準 | マスクの重みは「エフェクトをかける前のクリップ自身の色」から作る。色相シフト等の補正で選択範囲が動かないため |
| 保存 | `Clip.hslMask`（新規項目）。`ClipMask` と同じ Codable の作法：既定値は書かない、知らないキーは `extra` に残して書き戻す |
| UI・モデル | インスペクタの節（統一デザインシステムの `InspectorSection` / `LiveSlider`）、編集は形マスクと同じ作法（`setClipProperty` 経由で 1 回の Undo、ドラッグはジェスチャ集約） |
| プレビュー | `HSLMaskRenderer.previewImage`（描画）と `previewed`（1 画素の純粋計算）。グレーの輝度は Rec.709 係数 |

描画の速い道（複合クリップの直接描画・エフェクトなし経路）の条件にも
`hslMask == nil` を加えたので、マスク付きクリップは必ずマスク適用経路を通り、
マスク無しクリップは従来と完全に同じ経路・画素になる。

書き出し形式への変換（YMM4 の .ymmp / AviUtl の .exo）では、他のマスクと同じく
「変換が未対応のため落とす」警告の対象に加えた。

## テスト

- Core（`HSLMaskTests` 13件）：マスク適用の画素（選択色は残る／選択外は透明／
  反転／全域選択）、マスク画像と重みの一致、プレビューの純粋計算（グレー・
  色付き・オフ）、プレビュー画像のアルファ不変、保存/復元（既定値は書かない・
  往復一致・知らないキーの保持）、Renderer 経由の画素（背景との合成、形マスク
  との併用で積になること、マスク無しの不変）。
- App（`HSLMaskAppTests` 3件）：オン/オフ・項目変更・プレビュー切替が各 1 回の
  Undo、ドラッグ（live）で既定値へ戻すと既定のマスクと一致。

## 未検証事項

- アプリ画面（インスペクタの節）での実操作確認は未実施（コンパイル＋単体テストまで）。
- 実写素材での見た目の確認は未実施。テストは合成画像（単色・2色）での画素確認。
- Premiere Pro 27.0 の HSL マスキングとの数値一致は未検証。HSL の定義は
  HSL セカンダリと同じ標準的な HSL を使う。
- マスクプレビューの「書き出しにも効く」仕様は、保存される表示モードとしての
  実装上の選択。プレビューを保存せず画面だけに出す方式への変更は今後の課題。
- 調整レイヤー（`ClipType.adjustment`）のエフェクトへの HSL マスク限定は未対応
  （調整レイヤーは合成結果へエフェクトをかける経路が別で、マスクの概念が無い）。
  必要になれば別途設計する。

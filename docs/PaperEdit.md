# Paper Edit(文字起こしからの組み立て)

Premiere Pro 26.5 の Paper Edit(文字起こしの行を選んでシーケンスを組み立てるラフ編集)の
MovieCut 等価機能。文字起こしの文一覧から行を選び、選んだ順番のまま、対応する区間の
クリップ列を組み立てて配置する。

- 計算(Core、画面・Undo に依存しない): `Sources/MovieCutCore/PaperEdit.swift`(`PaperEdit`)
- アプリ側(Undo・状態欄): `Sources/MovieCut/ProjectModel+PaperEdit.swift`
- 画面: `Sources/MovieCut/TranscriptEditSheet.swift`(「文字起こしで編集」シートの拡張)
- テスト: `Tests/MovieCutCoreTests/PaperEditTests.swift`、`Tests/MovieCutTests/PaperEditAppTests.swift`
- 並べ替えのテスト: `Tests/MovieCutCoreTests/PaperEditOrderTests.swift`
- 単語単位の編集(Core): `Sources/MovieCutCore/TranscriptWordEdit.swift`(`TranscriptWordEdit`)、アプリ側は `ProjectModel+TranscriptEdit.swift` の `cutTranscriptWords`(取り除き)と `ProjectModel+PaperEdit.swift` の `assemblePaperEditWords`(組み立て)
- 単語単位のテスト: `Tests/MovieCutCoreTests/TranscriptWordEditTests.swift`、`Tests/MovieCutCoreTests/TranscriptWordAssemblyTests.swift`、`Tests/MovieCutTests/TranscriptWordEditAppTests.swift`

## 使い方

1. 音のあるクリップ(音声・ボイス・動画。速度変更・逆再生・速度ランプの無いもの)を選び、
   クリップメニュー ▸「文字起こしで編集…」を開く(従来と同じ入口)。
2. シート上部の切り替えで「選んだ文で組み立てる」を選ぶ。
3. 文の行を、使いたい順番に押していく。押した順がそのまま組み立ての並びになる。
   - 行の右端に、その行が組み立ての何番目に入ったか(#1、#3 のように)が出る。
   - 同じ行をもう一度押すと、同じ区間がもう 1 回追加される(繰り返し使える)。
   - 下の「組み立ての並び」で、順番の入れ替えと取り消し(外す)ができる。
     入れ替えはドラッグとボタン(先頭へ/上へ/下へ/末尾へ)の両方に対応する
     (計算は Core の `PaperEdit.moving` / `reordered` / `movingEntry` / `movingEntryToEdge`)。
4. 配置先を選ぶ:
   - 「タイムラインに追加」: 元クリップのあるレイヤーの末尾に、隙間なく並べて足す。
   - 「新しいシーンとして作成」: シーン名を付けると、その名前のシーン定義が作られ、
     中に組み立てたクリップ列が 0 秒から入る。タイムライン自体には足されないので、
     シーン一覧から好きな場所へ配置して使い回せる。
5. 「組み立てる」を押す。配置は全体で 1 回の Undo で戻せる。

## 仕組みと決まり

- 文の時刻(クリップの頭からの秒)に対応する区間を、元クリップから切り出した
  **新しいクリップ**として作る。元クリップは変更しない。
  切り出しは通常の分割(`ClipEditing.split`)と同じ経路なので、キーフレーム・
  音声フェード・トランジションの振り分けは分割と同じになる。
- 区間はクリップの長さの内側に収める。1ms 以下の区間は作らない。
- 切り出せない文が 1 件でもあると、黙って飛ばさず組み立て全体を失敗にする。
- タイムライン配置で既存クリップと重なる場所・ロックされたレイヤーには置かない
  (「タイムラインに追加」はレイヤーの末尾なので通常は重ならない)。
- 対象は文字起こしと同じ条件のクリップだけ(素材時刻とクリップ時刻が 1 対 1)。

## 既存の「文字起こしで編集」との違い

| | 取り除く(従来) | Paper Edit(本機能) |
|---|---|---|
| 操作 | 残す文にチェックを付け、外した文を除く | 使う文を順番に選ぶ |
| 元クリップ | 切り分けられて短くなる(変更される) | 変更しない |
| 結果 | 元クリップの位置で詰まる/穴が空く | 別の場所(レイヤー末尾/新しいシーン)に新しいクリップ列ができる |
| 並べ替え | できない(元の順番のまま) | できる(押した順・並び替えボタン) |
| 同じ文の繰り返し | できない | できる(同じ行を複数回追加) |

## 単語単位の編集(文より細かい取り除き)

シートの切り替えに「単語を取り除く」が増えた。単語の時刻がある文では、単語 1 件ずつに
チェックを入れて取り除ける。取り除きの経路は文のときとまったく同じ
(`ClipEditing.removeSilence`。「後ろを詰める」のチェックも同じ)で、全体で 1 回の Undo。
文の取り除きとの違いは「切る範囲が文ではなく単語 1 件の区間」だけ。

### 単語の時刻が取れるかどうか(現状確認)

- 認識結果の文(`TranscriptSegment`)は `words`(単語ごとの時刻)を持てる。
  - Speech Framework 経路: 認識器の区切り(単語相当)が時刻つきで返り、文にまとめる際も保持される。
  - Whisper 経路: `-ojf` のトークンに時刻がある。ただし日本語は 1 文字が複数トークンに割れて
    トークン単体では文字化け(U+FFFD)することがあり、その区間は文単位に落とされる(words は付かない)。
- 従来は文の一覧(`TranscriptSentence`)へ変換する時点で単語の時刻が落ちていた。今回から
  文が単語の時刻を引き継ぐ(`TranscriptSentence.words` / `hasWordTiming`)。
- 文の切り方そのものは従来と完全一致させる: 変換は入力の要素単位で組み立て、
  要素を単語へ展開して組み直すことはしない(展開すると文字数上限の境目が文の途中へ
  ずれて、従来の文分割が変わってしまう)。文を作った要素がすべて単語の時刻を持つ
  ときだけ、その単語の列を文へ引き継ぐ。要素の一部だけが時刻を持つ文は、文全体が
  「単語単位では編集できない」扱いになる。

### 割り切り(明示)

- **単語の時刻は、文に付随する `words` として返ってきた場合だけを使う。** `words` を持たない
  文は「文そのものが最小単位」とみなし、文 1 件を「1 単語」と言い換えるような推定はしない。
  その文は単語単位では編集できず、シートでは文ごとに「単語単位の時刻がありません」と出し、
  素材全体に時刻が無い場合は「単語単位では編集できません(文単位までです)」と明示する。
- 単語の時刻が無い文の単語が選ばれた状態で取り除きを実行すると、黙って文に広げず
  全体を失敗にする(Core は nil、アプリ側は何も変えず状態欄で理由を出す)。
- 単語が覆っていない間(単語と単語の間の無音など)は、単語を全部取り除いても残る
  (文の範囲へは広げない)。全部の単語を取り除いてクリップが残らなくなる場合は、
  文の全削除と同じく全体を拒否する。
- 音声認識そのものには手を入れていない(Whisper / Speech の結果の使い方だけ)。

## 単語単位の組み立て(単語の並べ替え)

シートの切り替えに「単語で組み立てる」が増えた。Paper Edit の単語版で、単語の時刻が
ある文では単語 1 件ずつを押した順に組み立て列へ入れ、その並びのまま単語の区間だけを
並べたクリップ列を配置する。配置先・元クリップ不変・全体で 1 回の Undo(Undo 名も
「ペーパーエディット」で文の組み立てと同じ)は文の組み立てと共通。

- 並びの解決は Core の `TranscriptWordEdit.resolvedWords`: 単語 1 件を「文 1 件分の
  区間」に直し、配置・重なり検査・失敗の扱いは `PaperEdit.assemble` にそのまま任せる。
- 組み立て列の並べ替え(ドラッグ/先頭へ/上へ/下へ/末尾へ)の計算は、文の組み立て列と
  同じ `PaperEdit` の並べ替えを番号の列経由で使う(`TranscriptWordEdit.movingWords` /
  `reorderedWords` / `movingWordEntry` / `movingWordEntryToEdge`)。
- 取り除きの `cuts` と違い、並びは利用者が作った順序そのものなので、解決できない
  指定(範囲外・単語の時刻が無い文・短すぎる区間)が 1 件でもあれば、黙って捨てず
  全体を失敗にする。同じ単語の繰り返しは文の組み立てと同じく使える。
- 単語の時刻が無い文は、単語を取り除くモードと同じく文ごとに
  「単語単位の時刻がありません」と出し、素材全体に無い場合は冒頭で明示する。

## 未検証事項(単語単位・並べ替えの追加分)

- 画面(シート)の実機確認は未実施(コンパイルと単体テストまで)。特に単語モードの
  チェック一覧と、組み立て列のドラッグ(`List` の `onMove`)の操作感はアプリ起動での確認がまだ。
  ドラッグが効かない環境でもボタン(先頭へ/上へ/下へ/末尾へ)で同じ並べ替えができる。
- シート上部の切り替えが 4 項目になった(文を取り除く/単語を取り除く/選んだ文で
  組み立てる/単語で組み立てる)。幅 520 のシートでラベルが詰まって見えないかは実機確認がまだ。
- 実素材(実音声)での単語削除・単語組み立ての聞こえ方は未確認。合成データの単体テストのみ。
- 単語組み立てで作ったクリップ列の表示名は通常の分割と同じ扱い(単語の本文をクリップ名には
  しない)。名前付けが必要かどうかは利用者の判断待ち(保留事項)。

# プリセット共有ファイル(.mcpreset)

種別をまたいで、プリセット類を 1 ファイルで渡せる共通形式。実装は `Sources/MovieCutCore/SharedPreset.swift`。

## ファイル
- 拡張子 `.mcpreset`(既存の `.json` 系・プロジェクト拡張子と衝突しない)。中身は UTF-8 の JSON。上限 1 MB、入れ子 64 段。
- データのみ。コード・スクリプト・外部参照は持たない。読み込みはファイル名やパスを判断に使わない。

## 項目
| 項目 | 必須 | 内容 |
|---|---|---|
| `formatVersion` | 必須 | 形式バージョン(整数、現在 1) |
| `kind` | 必須 | 種別(下表) |
| `name` | 必須 | 表示名(80 文字まで) |
| `author` | 任意 | 作者(80 文字まで) |
| `description` | 任意 | 説明(500 文字まで) |
| `compat` | 任意 | 互換情報: `app`(`MovieCut`)、`minFormatVersion`(読むのに必要な形式)、`appVersion`(書いたアプリの版) |
| `payload` | 必須 | 本体。種別ごと |

## 対象種別と変換方式(既存の型を土台に二重管理しない)
| kind | 本体 | 読み込みの検査 |
|---|---|---|
| `export-preset` | 既存の `export-presets.json` と同じ形(`{"version":1,"presets":[1件]}`) | `CustomExportPresetStore.decode` |
| `voice-preset` | `VoicePreset` の項目(id/name/engine/speaker/speed…) | `VoicePresetCatalog.decode`(範囲に収める) |
| `item-template` | `ItemTemplate` の Codable そのまま | 名前整理・スロット正規化。id は読み込み側で付け替え |
| `color-correction` | `Effect`(kind が `colorWheels` / `colorCurves`) | 種類の確認。`path` は捨てる |
| `grade-nodes` | `[GradeNode]`(1〜32 個) | `GradeNode.allowedKinds` のみ許可。`path` は捨て、id を付け替え |

既存の保存形式・保存先は変えない。読み込んだ書き出しプリセット/アイテムテンプレートは既存の一覧ファイルへ追加され、色補正・ノードは既存の `EffectEditing.append` / `GradeNodeEditing.add` で選択クリップに入る。音声プリセットは「おすすめ音声設定」画面の「ファイルから読み込み」から読み込む。

## バージョン方針
- `formatVersion` は互換を壊す変更のときだけ上げる。項目の追加は同じバージョンのまま(読む側は知らない項目を無視)。
- 読む側は自分より新しい `formatVersion`(または `compat.minFormatVersion`)を理由つきで断る。古い版は読める状態を保つ。

## 互換検査(理由つきで拒否)
壊れた JSON / 大きすぎる・深すぎる / 必須項目欠落(項目名を表示)/ 新しすぎる形式 / 未知の種別 / 別アプリ用(`compat.app`)/ 本体が範囲外・形違い(種別ごとの既存検査に通らない)。拒否したときは何も取り込まない。

## UI
設定 ▸ プリセット共有 に「共有ファイルへ書き出し…」「共有ファイルから読み込み…」(書き出しプリセット・アイテムテンプレート・色補正・グレーディングノード)。ファイルパネルはボタンを押したときだけ出る。音声プリセットは「おすすめ音声設定」の読み込みが `.mcpreset` も受け付ける。

## 将来の配布との関係
この形式は「1 ファイル = 1 プリセット」の素朴な入れ物で、配布サイトやプラグイン販売で配る単位にそのまま使える。配布側の都合(署名・価格・ライセンス・まとめ配布)は `compat` の外側(パッケージ層)で足し、`payload` は変えない方針。実行コードを含むもの(プラグイン本体)はこの形式の対象外で、`kind` に未知の値が来たら安全側で拒否する。

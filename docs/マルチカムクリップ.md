# マルチカムクリップ

同期済みの複数カメラを「1 つのクリップ」としてタイムラインに置き、有効アングルを切り替えて使う（Premiere／Resolve のマルチカムクリップ相当）。既存のグループ方式（`Multicam.makeGroup`／`cut`）は残してあり、どちらも使える。

## 使い方
- 映像クリップを 2〜9 個選ぶ → クリップ ▸ マルチカメラ ▸ **マルチカメラを作る…** → 「置き方」で **マルチカムクリップとして配置**（既定）か **グループ（従来方式）** を選ぶ。同期（音の相互相関）とずれの手直しは従来と同じ。
- 配置すると、いちばん先頭のクリップ（基準カメラ）の位置・レイヤーに 1 つのクリップが置かれる。ほかの元クリップはタイムラインから外れ、アングルとしてクリップの中に入る（Undo で元に戻る）。
- 切り替え:
  - インスペクタの「マルチカム」: 映像のアングル／音声のアングルのメニュー（クリップ全体を変える）。番号ボタンは再生位置から切り替える。
  - **数字キー 1〜9**（再生中も効く）: 再生位置がマルチカムクリップの中なら、その位置で分割して右側を指定のアングルにする。再生位置が選択クリップの外でほかのマルチカムクリップの上にあれば、そちらが対象。どれにも重ならなければ、選択中のクリップ全体。入力欄にフォーカスがあるとき・⌘/⌥/⌃/⇧ つきは何もしない。ほかのコマンドに割り当て済みの数字キーは奪わない。
  - クリップの右クリック、メニューの「再生位置からアングル N に切り替え」。グループもマルチカムクリップも無ければ何もしない。
- 切り替えは 1 回ずつ元に戻せる。同じアングルへの切り替えは履歴に載らない。

## モデル（`Sources/MovieCutCore/MulticamClip.swift`）
- `Clip.multicam: MulticamClipInfo?` — `angles: [MulticamAngle]`（名前・素材のクリップのコピー・`syncOffset`。既存のグループと同じ型）、`activeAngle`、`audioAngle`（0 始まり。0 = 基準）。
- クリップ自体は **普通の動画クリップ**。`src`／`offset`／`srcDuration` は常に有効アングルから導いた具体値を持つ。したがってプレビュー（`Renderer`）も書き出しも新しい経路なしで同じアングルを描く。
- 基準の素材時刻 = `clip.offset − angles[active].syncOffset`。どのアングルの素材時刻も `基準 + syncOffset`。切り替えはこの式で offset を差し替えるだけで、同じ瞬間が出る。
- 分割（`ClipEditing.split`）は offset を進めるだけなので、各片が `multicam` を保ち、片ごとに独立して切り替えられる。
- 切り替えの純粋関数: `Multicam.setActiveAngle(in:clipId:angle:at:)`（`at` がクリップの内側なら分割して右側だけ）。素材がその区間に無い・ロック・同じアングル・範囲外は変更なし（理由を返す）。
- 角度にできるクリップ（`isAngleCandidate`）からマルチカムクリップ自身は除く（入れ子にしない）。

## 音声
- 既定は基準カメラ（`audioAngle = 0`）。有効アングルとは独立に選べる（映像はカメラ2、音はカメラ1、など）。
- 表現: **音の経路だけ**（`CompoundEditing.audibleClips` の平坦化）で、マルチカムクリップの `src`／`offset`／`srcDuration` を音声アングルの素材（`基準 + syncOffset`）に差し替える。ミキサー・書き出し・ダッキング・ラウドネスはみなこの列を通るので、追加のクリップやレイヤーは要らない。映像のクリップは変わらない。
- 音量・フェード・消音・エフェクト・トラックのミックスは、マルチカムクリップ自身の設定がそのまま効く。
- 音声アングルはクリップごと（分割した各片が独立して持つ）。インスペクタ／右クリックで選択中のクリップに設定する。
- 波形表示と無音検出などの解析は、映像側（有効アングル）の素材を読む。

## 保存と後方互換
- `multicam` は付けたクリップにだけ書く。旧プロジェクト（マルチカムクリップ無し・グループ方式のみ）は従来どおり開き、書き戻してもキーは増えない。`Project.multicams`（グループ方式）は別物で従来のまま。
- `multicam` が読めない形・アングル 0 個・番号が範囲外のときは捨てずに `extra` に回して書き戻し、クリップは普通の動画クリップとして扱う（旧版で開いても有効アングルの映像はそのまま見え、書き出せる）。
- 素材の再リンク（`MissingMedia.relink`）は、使っていないアングルの素材パスも同じ場所へ直す。

## 割り切り
- **全アングル同時プレビュー（マルチビュー）は未対応。** 数 GB の映像を同時にデコードして並べる専用のプレビュー経路が要り（プレビューは 1 本の順次読み前提）、今回の範囲を大きく超えるため見送り。代わりにインスペクタに番号つきのアングルボタンを置いた（アングルのサムネ表示も未対応）。
- アングルごとの色空間・エフェクトの引き継ぎは無い（クリップ自身の設定が全アングルに効く。カメラごとに色を変えたいときはクリップを分割して設定する）。
- 基準以外のアングルが基準の範囲より短い場合、その区間では切り替えを断る（「素材がありません」）。
- パッケージ化（素材の取り込み）・プロキシの書き換えは、使っているアングルの `src` だけに効く。使っていないアングルのパスは、有効にしたときの再リンクで直す。
- exo／ymmp への書き出しは、有効アングルの普通の動画クリップとして出る。

# 外部エンジンの規約について

ゆっくりエディタには、音声エンジンや ffmpeg は**入っていません**。あなたが別にインストールしたものを呼び出すだけです。それぞれの規約は、あなた自身が守ってください。ここは簡単な案内です。最新で正しい内容は、必ず公式の規約を確認してください。

## AquesTalk / AquesTalkPlayer(A-quest)

- 個人の非商用利用は無料とされています。
- 収益化した動画など、商用で使うときは、A-quest の商用ライセンスを自分で購入する必要があります。
- 「商用」にあたる範囲の細かい線引きや、価格・手続きは、公式の規約を確認してください。

## VOICEVOX

- 動画などで使うときは、クレジット表記が必要です。例:「VOICEVOX:ずんだもん」
- キャラクター(声)ごとに、利用規約があります。使うキャラクターの規約を確認してください。
- 商用利用や再配布の条件も、公式の規約を確認してください。

## ffmpeg

- Homebrew などで、あなたが自分でインストールして使います。このアプリには入っていません。
- ffmpeg のライセンスは、ビルドの種類で変わることがあります。公式の規約を確認してください。

## 共通の注意

- 規約は変わることがあります。使う前に最新の公式ページを見てください。
- この案内は法的な助言ではありません。

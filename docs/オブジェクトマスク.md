# オブジェクトマスク（Premiere Pro「AI オブジェクトマスク」のローカル等価）

棚卸し表 `premiere-inventory.md` AI 節「オブジェクトマスク」が仕様の起点。人物・物体を
クリック（または矩形指定）で選択・分離し、ショット全体を追跡するマスクを、すべて
端末上の Vision で実装したもの。生成 AI ではないのでユーザーアカウント依存にはしない。

## 使い方

1. 映像・画像クリップを選ぶ（自分の素材を持つクリップだけが対象。文字・図形など
   輪郭の種が取れないクリップには作れない）。
2. プロパティ欄の「オブジェクトマスク」節で対象を指定する。
   - **プレビューでクリックして指定**: ボタンを押すと待ち状態になり、次にプレビューで
     対象をクリックした点が種になる。点を含むインスタンスのうち一番小さいものを選ぶ
     （含むものが無ければ中心が一番近いもの）。
   - **指定した範囲で作成**: 節の中の横位置・縦位置・幅・高さ（キャンバスに対する割合）
     で矩形を指定し、その矩形と IoU が最大のインスタンスを選ぶ（大きな背景物が
     「重なり面積が大きい」だけで勝たないための指標）。
3. 種は「いまの再生位置のコマ」で取る。対象がはっきり写っているコマへ再生位置を
   合わせてから作成すること。
4. 作成が終わるとマスクがクリップに付き、対象の部分だけが残る（外は透明）。
   エフェクトや色補正は通常どおりクリップへかけられ、マスクはその後に適用される。
   対象だけに補正をかけたいときは、クリップを複製して片方にマスクを付け、
   「反転（中を透明にする）」と組み合わせるのが Premiere と同じ作法。
5. 羽根（ぼかし）と反転は節の中で調整できる（ドラッグは 1 回の Undo）。
   「作り直す」は現在の矩形指定で対象を選び直して追跡をやり直す（羽根・反転は引き継ぐ）。
   「オブジェクトマスクを削除」でマスクだけを外す。

## 仕組み（既存基盤の再利用）

新規の推論基盤は作らず、既存部品の配線で実現した。

| 段階 | 再利用した基盤 |
|---|---|
| 種マスク生成 | 背景抜き（`ForegroundCutout`）と同じ `VNGenerateForegroundInstanceMaskRequest`。新規 `VisionForegroundInstanceDetector` がインスタンスごとにマスクを作り、白い画素の外接矩形を対象の矩形とする |
| 対象の選択（純粋計算） | `ObjectMaskPropagation.pickInstance`（クリック = 点を含む最小 / 矩形 = IoU 最大） |
| 時間方向への伝播 | `ObjectTracking.collect` + `VisionRectTracker`（`VNTrackObjectRequest`、10 回/秒）。種時刻から終わりへと頭への 2 方向に追跡し、サンプル列を合成する |
| 輪郭の追従 | 原則は種マスクの輪郭を追跡矩形へ拡縮して使う。1 秒ごとに前景インスタンスを再検出し、追跡矩形と IoU が最大の対象の輪郭をその時刻のサンプルへ付け足す（`attachMask`、まばらに保持） |
| マスク適用 | `ClipMask` / `ShapeMask` と同じ経路。`Renderer.drawEffectedClip` でエフェクトの後、`CIBlendWithMask` で画素へかける（`ObjectMaskRenderer.apply`）。形マスクと両方あるときは両方かかる |
| 保存 | `Clip.objectMask`（新規項目）。`ClipMask` と同じ Codable の作法：既定値は書かない、知らないキーは `extra` に残して書き戻す、有効サンプルが無いものは未設定として読む |
| UI・実行まわり | インスペクタの節（統一デザインシステムの `InspectorSection` / `LiveSlider` / `MCDesign` トークン）、進捗・キャンセルはオブジェクトトラッキングの `ObjectTrackingSession` の作法を流用。プレビューのクリック指定はパペットピンの「待ち状態→クリックで打つ」作法と同じ |

### 保存形式（`ObjectMask`）

- `seedMask`: 種コマの輪郭。対象の外接矩形へ切り抜き、長辺 256px へ縮小した
  グレースケール PNG の Base64。プロジェクトファイルが膨らまないための要で、
  サンプルごとの輪郭は再検出で変わった時刻だけ `mask` として持つ。
- `samples`: 0.1 秒ごとの外接矩形（左上原点・正規化）。見失いは `rect` なし。
  時刻の矩形は前後を線形補間し、検出の無い区間は `ObjectTrack.maxGap`（1 秒）と
  同じ作法で近い検出までを使う。それより離れた時刻ではマスクをかけない。
- `feather` / `invert`: 形マスクと同じ定義（羽根 1 = 短い辺の 1/4 のなだらかさ）。
- exo / YMM4 書き出しでは未対応として落とす旨を注記する（形マスクと同じ扱い）。

## 制限・未検証事項

- **回転は追従しない**（対象外にした）。追跡矩形は軸平行のままで、輪郭は矩形への
  拡縮で追う。対象が大きく回転・変形するショットでは輪郭がずれる。
- **実写での追跡精度は未検証**。合成画像での単体テスト（補間・描画・保存往復）は
  通っているが、実際の映像での Vision インスタンス検出の当たり外れ、追跡の
  喪失・取り違え、再検出の頻度（1 秒ごと）の妥当性は実写で確認していない。
  オブジェクトトラッキング側の既存実測（合成動画で低速 IoU 0.839、高速・ノイズ
  背景では喪失あり）と同じ水準の限界を引き継ぐ。
- 座標の前提: 追跡・検出は素材コマの正規化座標で行い、そのままキャンバス座標として
  使う（オブジェクトトラッキングと同じ前提）。クリップを大きく変形・切り抜きして
  配置している場合はマスク位置がずれることがある。
- 種マスクは長辺 256px へ縮小して保存するため、大きな対象では輪郭が粗くなる。
  描画時は復号画像を小さなキャッシュ（32 件まで）に保持する。
- 対応クリップは映像・画像のみ。複合・シーン・立ち絵への作成 UI は無い
  （ファイルに値があれば描画経路はそのまま効く）。
- Premiere 27.0 の「追跡改善・ファイル小型化・復元改善」に相当する高度な復元
  （見失い区間の再発見など）は無い。見失った区間はマスクが外れる。

## 人物（自動）— 人物セグメンテーション

クリック不要で、画面内の人物をまとめて 1 つの対象にするオブジェクトマスクの作成入口。
インスペクタの「オブジェクトマスク」節の **「人物（自動）で残す」/「人物（自動）を消す」** から作る。

- 検出: `VisionPersonSegmentationDetector`（`VNGeneratePersonSegmentationRequest`、品質は
  バランス型）。画面内の人物すべてを 1 枚のマスクにまとめ、`ForegroundInstanceDetecting`
  として前景インスタンス検出器と同じ並びに置く（テストでは固定のマスクを返す偽物に差し替えられる）。
  マスクの後処理は `PersonMaskInstance.make`（画像の大きさへ引き伸ばし → 白い画素の外接矩形）。
- 時間追従: 独自の追跡は作らず、既存の `ObjectTracking`（矩形追跡）＋1 秒ごとの再検出
  （この検出器で人物マスクを取り直す）にそのまま乗せる。保存・描画も `Clip.objectMask` の経路。
- 残す／消す: 「残す」= 人物の外が透明、「消す」= `invert`（人物の中が透明）。作成後に
  「反転」のチェックで切り替えられる。羽根も同じ。
- 限界: 人物が複数いても 1 つの対象として追跡する（外接矩形は全員を囲む）。人物同士が
  離れる・画面から出入りするショットでは矩形追跡が外れやすい。**実写での人物検出の精度・
  追跡の当たり外れは未検証**（検出は Vision 依存で、合成マスクでの適用結果のみ単体テスト済み）。
- 補足（既知の問題）: 既存の `ObjectMaskImage.boundingRect(ofMask:)` は上下を逆に測る
  （既存テストの画像がその前提）。人物検出は上下の正しい `boundingRectUpright` を使う。

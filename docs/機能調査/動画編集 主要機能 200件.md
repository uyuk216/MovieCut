# 動画編集ソフトの主要機能 200件

**主要な動画編集ソフトの公式資料から、用途の異なる200機能を整理した。** Adobe Premiere、DaVinci Resolve / Fusion / Fairlight、Final Cut Pro、VEGAS Pro、Filmora、CapCut、ゆっくりMovieMaker4（YMM4）を中心に確認し、Media Encoder・Compressorなどの連携製品も含めた。調査日は2026年10月29日。

「主要」は主要製品で存在を確認した意味で、200件すべてが全ソフト共通・一般利用者に必須という意味ではない。表の「高度」「AI」「実況向け」「モバイル限定」などで用途や制約を補足した。無印は通常の編集機能であり、複数社への普及率を測った分類ではない。各行の製品例は存在を確認した例で、全製品の対応比較ではない。

個別の解像度・コーデック・同じ機能の別名は件数を増やすために分割していない。たとえばJ/Lカット、複数の交換形式、読みと発音の辞書、サムネイルの選定と装飾はまとめた。Movie Cutの現行実装との突き合わせや実装優先度の確定は今回行っていない。

## この一覧を使うときの確認点

料金・OS・対応版・AIクレジット・地域差を200件すべてで横断照合した一覧ではない。製品名だけの行を「無料版でも利用可能」と読み替えず、採用候補を決める段階でリンク先の提供条件を確認する。AI機能も一律にクラウド必須ではなく、端末上で解析する機能がある。実際の使い勝手、精度、速度、素材の権利条件は今回の調査対象外である。

Movie Cutの検討では、まず日常の編集、素材再リンク、字幕、音声整音、保存復旧、書き出しのような制作全体を支える項目をひとまとまりで比較できる。その後に、実況の台本・辞書・立ち絵、SNS向けの再構成、専門的な合成など、作りたい動画に応じて候補を絞ると判断しやすい。これは用途からの整理案であり、この調査だけで実装順を決定したものではない。

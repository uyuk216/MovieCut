# エッセンシャルサウンド（ブランチ feat/essential-sound）

Premiere Pro の「エッセンシャルサウンド」等価機能。音のあるクリップに種別（会話／ミュージック／効果音（SFX）／アンビエンス）を付けるだけで、その種別向けの整音をワンクリックで適用できる。
新しい音声処理は作らず、整音は既存の設定（`AudioFx` の各項目・「声として扱う」・自動ダッキング）の組み合わせだけで表す。

- 起点: `feat/muse-access` e1c4305
- 棚卸し出典: `premiere-inventory.md` オーディオ節「エッセンシャルサウンド」（部分実装 → 本機能で不足分を解消）

## 使い方

1. タイムラインで音のあるクリップ（音声・ボイス・動画）を選ぶ。
2. インスペクタ「音声」の先頭に「エッセンシャルサウンド」が出る。「音の種類」で 会話／ミュージック／効果音（SFX）／アンビエンス／未分類 を選ぶ（この時点ではタグが付くだけで、音は変わらない）。
3. 種別を選ぶと、その種別の整音内容の説明と「整音を適用」ボタンが出る。押すと整音がまとめて適用される。すでに同じ内容が適用済みのときはボタンが押せない。
4. 適用後も、ノイズ除去・EQ・コンプレッサー・ノーマライズ・ダッキングなどは通常の「音声」節で個別に調整できる（プリセットは既存設定の組み合わせなので、特別な状態にはならない）。
5. 種別を「未分類」に戻しても、適用済みの整音はそのまま残る（タグと整音は別の操作）。整音自体を戻したいときは Undo を使う。

Undo の単位: 種別の変更は 1 操作 = Undo 1 回、整音の適用も全体で Undo 1 回。何も変わらない操作（同じ種別を選び直す、適用済みのプリセットをもう一度適用する）は履歴に載らない。

対象外のクリップ: 画像・文字などの音の無いクリップ、フリーズフレームのクリップにはパネル自体が出ない。ロックされたレイヤー・クリップ（複合クリップの外側がロックされている場合も含む）には適用しない。複合クリップの中のクリップにも種別・整音は効く。

## 種別ごとの適用内容

プリセットが触らない項目（リバーブ・ディレイ・パン・音量・フェード・音程など）は、そのまま残る。

| 種別 | 適用内容 |
|---|---|
| 会話 | ノイズ除去 50%（簡易。スペクトル指定は保持）、EQ（低域 −3 dB・中域 +2 dB・高域 +1 dB）、コンプレッサー（しきい値 −18 dB・比率 3:1・アタック 10 ms・リリース 120 ms・メイクアップ +2 dB）、ノイズゲート −50 dB、リミッター −1 dB、ノーマライズ（ラウドネス −16 LUFS）。音声クリップは「声として扱う」をオン（ダッキングの引き金になる）。ダッキングは外す |
| ミュージック | 自動ダッキングを既定値で設定（−12 dB・アタック 0.15 秒・リリース 0.5 秒。音声クリップのみ）、ノーマライズ（ピーク −1 dB）、リミッター −1 dB。ノイズ除去は外す（付けていた場合）。「声として扱う」は外す |
| 効果音（SFX） | ノーマライズ（ピーク −3 dB）、リミッター −1 dB。ダッキングは外し、「声として扱う」も外す。EQ・ノイズ除去など他の項目は触らない |
| アンビエンス | ノーマライズ（ラウドネス −23 LUFS）、緩やかなダッキング（−8 dB・アタック 0.3 秒・リリース 1 秒。音声クリップのみ）、ノイズ除去 30%、EQ 高域 −2 dB（他の帯域は残す）、リミッター −1 dB。「声として扱う」は外す |

種類による差の考え方:

- 会話は「声として扱う」側（ダッキングの引き金）、ミュージックとアンビエンスは「下げられる」側（ダッキング対象）、効果音はどちらでもなく天井だけ守る。
- 動画クリップには「声として扱う」とダッキングが付けられない（既存仕様どおり。ダッキングの引き金・対象は音声クリップだけ）ため、会話プリセットの音声エフェクト部分だけが効く。ボイスクリップは元々「声」なので、会話プリセットでは音声エフェクト部分だけが効く。

## 設計

### モデルと保存形式（`Sources/MovieCutCore/Project.swift`）

`Clip` に `audioCategory: AudioCategory?`（キー `audioCategory`、値は `"dialogue"` / `"music"` / `"sfx"` / `"ambience"`）を追加した。

- 未分類（nil）のときはキー自体を書かない。種別を使わない既存プロジェクトは、保存内容が従来とバイト単位で一致する（テストで担保）。
- 読み込みは `blendMode` と同じ作法: 知らない種別文字列や型の違う値は捨てずに `Clip.extra` へ残して書き戻す。`knownKeys` にも追加済み。
- 種別タグ自体は音を変えない。ミックス段（`AudioMixer` / `Ducking.voiceSpans`）はタグを読まないので、タグを付けただけでは再生・書き出し・ダッキングの挙動は従来と変わらない。音が変わるのは整音プリセットを適用したときだけで、その内容も既存設定（`audioFx` / `treatAsVoice` / `duck`）そのものである。

### 整音の計算（`Sources/MovieCutCore/EssentialSound.swift`、新規）

- `AudioCategory`: 種別（rawValue・表示名 `label`・説明 `presetSummary`）。
- `EssentialSoundEditing`: 純粋な編集計算。`supports`（音声エフェクトを受けられるクリップ）、`setCategory`（タグだけ）、`applyPreset`（タグ＋整音一式。すでに同じ内容なら変化なしを返す）、`isPresetApplied`（適用済み判定。写しに適用して一致するかで判定）。
- `ClipEditing.setAudioCategory` / `setAudioCategories` / `applyEssentialSound`: プロジェクト単位の適用。複合クリップの中を再帰し、ロックされたレイヤー・クリップ（外側の複合クリップのロックも含む）を飛ばす（`ClipVoice` の「声として扱う」と同じ作法）。何も変わらなければ nil。

### アプリ側

- `Sources/MovieCut/ProjectModel+EssentialSound.swift`（新規）: `setAudioCategory(clipId:_:)`（Undo 名「音の種類の変更」）と `applyEssentialSound(clipId:)`（Undo 名「エッセンシャルサウンドの整音」）。どちらも 1 操作 = Undo 1 回で、変化が無ければ履歴に積まない。
- `Sources/MovieCut/EssentialSoundPanel.swift`（新規）: インスペクタ用パネル。`AudioFxInspector.swift` の `AudioFxPanel` の先頭に差し込んだので、音声・ボイス・動画クリップの「音声」節すべてに出る。見た目は統一デザインシステム（`MCDesign` のフォント・余白、既存パネルと同じ部品）に従う。
- 文言は日本語で追加し、英訳を `L10nTable` に 15 件追加した（既存キーとの重複がないことを機械確認済み）。パネル文言は `L10n.t` 経由で表示する。

# 台本CSV・台本編集ウィンドウ・アイテムテンプレート

第2波バッチE（監査 #8 / #41 / #42）の仕様。実装は Core（`ItemTemplate.swift` / `ScriptTable.swift` / `ScriptCSVRoundTrip.swift`）とアプリ（`ProjectModel+ItemTemplates.swift` / `ProjectModel+ScriptTable.swift` / `ScriptTableSheet.swift`）。

## 台本CSV（#42）

### 列仕様（書き出し）

見出し行つき・UTF-8 BOM・改行 CRLF・RFC 4180 の引用符（カンマ・引用符・改行を含むセルは `"` で囲み、`"` は `""` にする）。

| 列 | 見出し | 意味 | 空のとき |
|---|---|---|---|
| 1 | キャラ | 話すキャラの名前 | 名前なし（台本欄の既定キャラ） |
| 2 | セリフ | 元の表記（観客が読む文） | —（空の行は読み飛ばす） |
| 3 | 読み | 読み上げ文の上書き（かな等） | セリフをそのまま読む |
| 4 | 字幕 | 表示する字幕文 | セリフと同じ表示 |
| 5 | 表情 | 表情タグ名（角括弧なし） | タグなし |

字幕列の特殊形: `""`（引用符で囲んだ空）は「字幕なし」。引用符なしの空は「指定なし（セリフと同じ）」。この 2 つを区別するため、字幕なしは書き出しで必ず `""` になる。

メモ行: 先頭のセルが `※` で始まる行は作業メモとしてそのまま台本へ通す（読み上げも字幕も作らない）。

### 読み込みの互換

- 見出し行があれば列名で対応づける。別名も受ける: キャラ=「名前」「キャラクター」「話者」、セリフ=「台詞」「本文」、読み=「読み上げ」「読み上げ文」「発音」「よみ」、字幕=「字幕文」「表示」、表情=「表情名」。
- 見出しに「セリフ」が無く「読み」系だけがある場合は、その列をセリフ（読み上げ文）として読む（従来形式）。
- 見出しが無い場合は列数で判断する: 1列=セリフのみ、2列=キャラ・セリフ、3列=従来形式（キャラ・読み上げ文・字幕文）、4列=キャラ・セリフ・読み・字幕、5列以上=全列。
- 文字コードは BOM があれば UTF-16 を先に、無ければ UTF-8 → Shift_JIS → UTF-16 の順に推定する（アプリの読み込み時）。
- アプリでは「出力 ▸ 台本CSVを読み込む…」で CSV を台本テキストの行に直して台本欄の末尾へ足す。声の生成は従来どおり「台本から音声を作る」。

### ボイスクリップとの対応（往復の規則）

- 読み上げ文（`Clip.text` の表情タグを除いた本文）= 読み（無ければセリフ）。
- `Clip.subtitleText` = 字幕の指定があればそれ。指定が無く、読みがセリフと違うときはセリフ（元の表記を字幕に残す。読み辞書で作ったクリップと同じ形）。それ以外は nil（字幕 = 読み上げ文）。
- 書き出し時、`subtitleText` が読み上げ文と別にあるクリップは「セリフ=subtitleText / 読み=読み上げ文」に振り分ける。字幕だけを別文にしているクリップもこの形になるが、読み込みで同じ `text` / `subtitleText` に戻るため往復は保たれる。
- 表情タグは `Clip.text` 先頭の `[名前]` と表情列を行き来する。
- 対象外（キャラが無い・名前が空・セリフが空のボイス）は書き出さず、件数を数えて知らせる（`VoiceScriptExport` と同じ規則・同じ開始時刻順）。

往復（プロジェクト → CSV → 行 → 台本行）が保たれることは `ScriptCSVRoundTripTests` で担保する。特殊文字（カンマ・引用符・改行）・空欄・字幕の 3 状態も同テストで確認する。

## 台本編集ウィンドウ（#41）

- 「クリップ ▸ 台本を編集…」で開く。既存のボイスクリップを開始時刻順に一覧し、キャラ（プルダウン）・セリフ（読み上げ文）・字幕（空 = セリフと同じ、「字幕なし」チェック = 字幕を出さない）・表情を編集する。
- 保存は `ProjectModel.edit` 経由で全体まとめて 1 回の Undo。計算は Core の `ScriptTable`。
- 音声そのもの（素材・長さ・開始時刻）は変えない。セリフの文字を変えたら、既存の「音声の作り直し」で合成し直す。字幕文が読み上げ文と同じ場合はファイルに書かない（従来の流儀）。

## アイテムテンプレート（#8）

プロジェクト全体のテンプレート（`ProjectTemplate`）とは別に、クリップ 1 個分の設定一式を名前つきで保存・適用する（YMM4 のアイテムテンプレート相当）。

- 保存先: `Application Support/MovieCut/Templates/item-templates.json`（`{"version":1,"templates":[...]}`）。プロジェクトファイルには入らないので、既存プロジェクトの互換・バイト一致には影響しない。組み込み 3 件（字幕・標準(ボイス) / 見出し(文字) / ぼかし・標準）+ ユーザー保存分（最大 100 件）。壊れた項目は読み込み時にその 1 件だけ捨てる。
- 保存: 「クリップ ▸ 選択クリップをアイテムテンプレートとして保存…」。開始時刻は 0 にそろえ、メモ・ロック・消音・グループ・知らないキーは持ち込まない。同じ名前は「名前 2」のように避ける。
- 既存クリップへ適用: 「クリップ ▸ アイテムテンプレートを適用 ▸ 名前」。同じ種類のクリップにだけ当たる。写すのは見た目・振る舞い（位置・大きさ・文字の装飾・エフェクト・トランジション・速度・音声まわり等）だけで、素材パス・セリフ・字幕文・話すキャラ・開始時刻・長さ・素材の切り出し位置は適用先のまま残す。複数選択はまとめて 1 回の Undo。
- 新規作成: 「クリップ ▸ テンプレートからクリップを作成 ▸ 名前」。保存した写し（素材・セリフも含む）を再生ヘッドの位置・対象レイヤーに置いて選択する。長さが 0 以下のテンプレートは 2 秒にする。

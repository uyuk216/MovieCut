# Movie Cut ロードマップ(「超万能な動画編集ソフト」へ)

方針: Mac 専用・Apple Silicon・ネイティブ(Swift / AVFoundation / Core Image / Metal / Vision / Speech)。外部ライブラリは使わない。
作る順番は A → B → C → D。各フェーズは小さな段階に分けて、段階ごとにテスト・確認・コミットする。

## 先に作るもの(進行中)
- メニューバーの「出力」メニュー(解像度・FPS・書き出し形式・背景色・書き出し・プリセット)に集約
- 解像度のカスタム、フレームレートのカスタム(小数・NTSC レート対応)

## フェーズ A: 編集の基本を万能に
1. **変形とキーフレーム**: 位置・拡大・回転・反転・切り抜き(クロップ)・不透明度を、時間で変化させる(イーズ付き) — **実装済み**(`DESIGN.md` の「変形とキーフレーム」。キーフレームのイージング編集 UI(曲線エディタ)は未実装、`bezier:` はファイルに直接書く)
2. **トランジション**: フェード、クロスフェード、スライド、ワイプ、ズーム(クリップの頭・尻に付ける) — **実装済み**(`DESIGN.md` の「トランジションと音声フェード」。クリップ間の「ずらして重ねる」自動配置・トランジション専用のプレビュー取っ手は未実装)
3. **エフェクト(Core Image)**: 明るさ/コントラスト/彩度/色相/露出、シャープ、モノクロ/セピア、ビネット、モザイク、各種ぼかし(ガウス/ズーム/モーション)、グロー、ドロップシャドウ、縁取り — **実装済み**(`DESIGN.md` の「エフェクト」。キャンバス外へはみ出す影・縁、LUT は未実装)
4. **速度変更**: 0.25〜4 倍、逆再生、静止画(フリーズフレーム) — **実装済み**(`DESIGN.md` の「速度変更・逆再生・フリーズフレーム」。音程を保つ/保たない、タイムラインの札、分割・トリムの追従まで。速度のキーフレーム(時間で速さが変わるスピードランプ)は未対応)
5. **クリップの音声**: フェードイン/アウト(**実装済み**: A-2)、音量のキーフレーム・パン・3 バンド EQ・コンプレッサー・リバーブ・ノーマライズ(**実装済み**: A-5。`DESIGN.md` の「クリップの音声処理」。タイムラインの音量包絡線・クリップ単位の消音・ゲート付きラウドネスは未対応)
6. **タイムラインの見やすさ**: 動画/画像のサムネイル、音声の波形、複数選択、コピー&ペースト、レイヤーの名前変更/ロック/ソロ/高さ — **実装済み**(A6。`DESIGN.md` の「タイムライン(フェーズ A6)」)。**範囲選択(ルーラーの ⌥ ドラッグ・範囲の削除)は未実装**

## フェーズ B: 解説・実況動画に強くする
1. **文字の強化**: 影・背景ボックス・グラデーション、字間・行間・揃え・太字・斜体、アニメーション(タイプライター、ポップ、揺れ)、スタイルの保存(組み込み 6 つ + 名前をつけて保存) — **実装済み**(B-1。`DESIGN.md` の「文字の装飾・スタイル・アニメーション」)。**縦書き、文字ごと(1 文字ずつ)の動き、字幕(ボイス)のアニメーションは未対応**
2. **吹き出しと図形**: 吹き出し(ゆっくり風)、矢印、四角・丸・線、スタンプ/絵文字、GIF・APNG
3. **字幕**: SRT/VTT の書き出しと読み込み、台本から字幕トラックを自動生成、YouTube のチャプターをマーカーから生成 — **SRT/VTT の書き出し・読み込み、チャプターのコピーは実装済み**(`DESIGN.md` の「字幕ファイルとチャプター」)。**台本から字幕トラックの自動生成は未実装**(ボイスの字幕は従来どおり描画され、書き出しにも入る)
4. **自動ぼかし(Vision)**: 顔・文字を検出して、動くぼかし範囲を自動で付ける
5. **無音カット**: 無音区間を検出して自動で詰める(実況向け)
6. **BGM の自動ダッキング**: 声が出ている間だけ BGM を下げる
7. **キャラクター演出**: まばたき、話している間のバウンス、セリフごとの表情切り替え(`[笑顔]` のタグ)、口の形(あいうえお)でのリップシンク
8. **読み辞書とイントネーション**: セリフごとの読み修正、VOICEVOX のアクセント編集、AquesTalk のユーザー辞書、COEIROINK / SHAREVOX 対応

## フェーズ C: 出力とワークフロー
1. **書き出し**: イン/アウト範囲、GIF、ProRes、静止画、連番画像、書き出しキュー(バックグラウンド)
2. **素材ライブラリ(メディアプール)**: 取り込み素材の一覧、リンク切れの再接続、プロジェクトのテンプレート
3. **色**: LUT(.cube)の読み込み、カラーホイール、クロマキー(グリーンバック)
4. **プレビューの高速化**: Metal でのレンダリング、プロキシ(軽量版)での 4K 編集

## フェーズ D: 取り込みと自動化
1. **自動文字起こし**: Apple の音声認識(オンデバイス)で字幕を自動生成
2. **画面収録・Web カメラ収録**を、アプリの中から
3. ショートカットアプリ(Shortcuts)・AppleScript からの操作

## 守ること
- 互換: `.mcpjc` / `.ymproj` を壊さない(新しい項目は読み飛ばせる形で追加、古いファイルはそのまま開ける)
- 動作確認で、アプリを繰り返し起動しない(画面に出ない静かな起動を少回数、またはテスト内で)
- 公開前: 署名とノータライズ、ライセンス文の空欄、「Movie Cut」の商標確認

## 機能調査からの追加候補
200 機能の調査と Movie Cut との突き合わせ: [機能調査/Movie Cutとの突き合わせ.md](機能調査/Movie%20Cutとの突き合わせ.md)(元の調査は同じフォルダ)。上の B〜D に無く、追加したい候補(工数は見積もり):
- **書き出し(C-1 に足す)**: ビットレート指定・独自の書き出しプリセット保存(小)
- **素材(C-2 に足す)**: 書き出し前の欠落素材の検出(小)
- **A の残り**: クリップ間の自動クロスフェード配置(中)、スピードランプ(大)、ノイズゲート・リミッター(中)、音量/ラウドネスメーター(中)、リップルトリム・ロール編集・範囲選択(中)
- **字幕(B-3 に足す)**: 時刻付き字幕(SRT)から音声クリップを配置(中)
- **キャラ(B-7 に足す)**: 立ち絵のパーツ合成・PSD 読み込み(大)
- **編集**: J/L カット(映像と音声を分けてずらす)(大)、キーボードショートカットの変更(中)
- **信頼性**: 世代バックアップ・異常終了からの復元の確認と補強(中)、Undo の回帰テスト追加(小)
- **音声**: 実況の環境音のノイズ除去(大。Apple 標準 API で足りるか要調査)

## 候補: 書き出し中のファン最大化(2026-10-31 ユーザー案)
- 内容: 動画の書き出し中だけ、ファンの風量を最大にするかどうかを選べる(出力シートか設定のチェック)。対象機種は MacBook Pro / Mac mini / Mac Studio。MacBook Air はファンがないので対象外。
- 機種判定: `sysctl hw.model`(例 `Mac14,5`)と `system_profiler SPHardwareDataType` のモデル名で判定し、ファンの有無は SMC のキー `FNum` で確認(0 なら対象外)。
- 難所: ファンの回転数の書き込み(SMC の `F0Md`・`F0Tg` など)は管理者権限(root)が要り、Apple Silicon では制約が多い。アプリ本体からは書けないので、特権ヘルパー(`SMAppService` のデーモン)が必要。いまのビルドはアドホック署名なので、ヘルパーの登録・承認は Developer ID 署名とノータライズが済んでから。
- 先にできること(権限なし): 機種判定とファン有無の検出、設定項目の UI(署名が済むまで「未対応」表示)、書き出しの開始・終了の通知口を作っておく。実際の風量制御は、署名後に特権ヘルパーとして別段階で実装(失敗時は必ず自動に戻す、書き出しが終了・中断・クラッシュしたら元に戻す、温度の上限監視を入れる)。
- リスク: SMC の誤書き込みは冷却不全につながるため、ユーザーが明示的にオンにしたときだけ動かし、終了時の復帰を最優先で確実にする。

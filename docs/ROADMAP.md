# Movie Cut ロードマップ(「超万能な動画編集ソフト」へ)

方針: Mac 専用・Apple Silicon・ネイティブ(Swift / AVFoundation / Core Image / Metal / Vision / Speech)。外部ライブラリは使わない。
作る順番は A → B → C → D。各フェーズは小さな段階に分けて、段階ごとにテスト・確認・コミットする。

## 先に作るもの(進行中)
- メニューバーの「出力」メニュー(解像度・FPS・書き出し形式・背景色・書き出し・プリセット)に集約
- 解像度のカスタム、フレームレートのカスタム(小数・NTSC レート対応)

## フェーズ A: 編集の基本を万能に
1. **変形とキーフレーム**: 位置・拡大・回転・反転・切り抜き(クロップ)・不透明度を、時間で変化させる(イーズ付き) — **実装済み**(`DESIGN.md` の「変形とキーフレーム」。キーフレームのイージング編集 UI(曲線エディタ)は未実装、`bezier:` はファイルに直接書く)
2. **トランジション**: フェード、クロスフェード、スライド、ワイプ、ズーム(クリップの頭・尻に付ける) — **実装済み**(`DESIGN.md` の「トランジションと音声フェード」。クリップ間の「ずらして重ねる」自動配置・トランジション専用のプレビュー取っ手は未実装)
3. **エフェクト(Core Image)**: 明るさ/コントラスト/彩度/色相/露出、シャープ、モノクロ/セピア、ビネット、モザイク、各種ぼかし(ガウス/ズーム/モーション)、グロー、ドロップシャドウ、縁取り — **実装済み**(`DESIGN.md` の「エフェクト」。キャンバス外へはみ出す影・縁は未実装。**クロマキー・LUT(.cube)も実装済み**)
4. **速度変更**: 0.25〜4 倍、逆再生、静止画(フリーズフレーム) — **実装済み**(`DESIGN.md` の「速度変更・逆再生・フリーズフレーム」。音程を保つ/保たない、タイムラインの札、分割・トリムの追従まで。速度のキーフレーム(時間で速さが変わるスピードランプ)は未対応)
5. **クリップの音声**: フェードイン/アウト(**実装済み**: A-2)、音量のキーフレーム・パン・3 バンド EQ・コンプレッサー・リバーブ・ノーマライズ(**実装済み**: A-5。`DESIGN.md` の「クリップの音声処理」。タイムラインの音量包絡線・クリップ単位の消音・ゲート付きラウドネスは未対応)
6. **タイムラインの見やすさ**: 動画/画像のサムネイル、音声の波形、複数選択、コピー&ペースト、レイヤーの名前変更/ロック/ソロ/高さ — **実装済み**(A6。`DESIGN.md` の「タイムライン(フェーズ A6)」)。**範囲選択(ルーラーの ⌥ ドラッグ・範囲の削除)は未実装**

## フェーズ B: 解説・実況動画に強くする
1. **文字の強化**: 影・背景ボックス・グラデーション、字間・行間・揃え・太字・斜体、アニメーション(タイプライター、ポップ、揺れ)、スタイルの保存(組み込み 6 つ + 名前をつけて保存) — **実装済み**(B-1。`DESIGN.md` の「文字の装飾・スタイル・アニメーション」)。**縦書き、文字ごと(1 文字ずつ)の動き、字幕(ボイス)のアニメーションは未対応**
2. **吹き出しと図形**: 吹き出し(ゆっくり風)、矢印、四角・丸・線、スタンプ/絵文字、GIF・APNG
3. **字幕**: SRT/VTT の書き出しと読み込み、台本から字幕トラックを自動生成、YouTube のチャプターをマーカーから生成 — **SRT/VTT の書き出し・読み込み、チャプターのコピーは実装済み**(`DESIGN.md` の「字幕ファイルとチャプター」)。**台本から字幕トラックの自動生成は実装済み**(出力 ▸ 字幕を自動生成。ボイスの「字幕を出す」を切り、同じ時刻の文字クリップを「字幕」レイヤーに作る。1 回で元に戻せ、生成済みなら何もしない)
4. **自動ぼかし(Vision)**: 顔・文字を検出して、動くぼかし範囲を自動で付ける
5. **無音カット**: 無音区間を検出して自動で詰める(実況向け) — **実装済み**(クリップ ▸ 無音をカット…、`moviecut-cli silence`。`DESIGN.md` の「無音カットと BGM の自動ダッキング」。速度・逆再生のあるクリップ、字幕・波形の連動カットは未対応)
6. **BGM の自動ダッキング**: 声が出ている間だけ BGM を下げる — **実装済み**(音声クリップの `duck`。インスペクタとクリップ ▸ 音声 ▸ 自動ダッキングを切り替え。ボイスクリップを「声」とみなす。録音した話し声(音声クリップ)を声として扱う指定は未対応)
7. **キャラクター演出**: まばたき、話している間のバウンス、セリフごとの表情切り替え(`[笑顔]` のタグ)、口の形(あいうえお)でのリップシンク — **部分実装済み**(`DESIGN.md` の「キャラクター演出(B-7)」。口の開閉のヒステリシス・まばたき・表情タグ・バウンスは描画と書き出しに入った。**インスペクタで画像を割り当てる UI は未実装**(保存された項目を直接書いて使う)。あいうえおのリップシンク(口の形の判定)は未対応)
8. **読み辞書とイントネーション**: セリフごとの読み修正、VOICEVOX のアクセント編集、AquesTalk のユーザー辞書、COEIROINK / SHAREVOX 対応

## フェーズ C: 出力とワークフロー
1. **書き出し**: イン/アウト範囲・静止画(PNG/JPEG)・連番画像 — **実装済み**(`DESIGN.md` の「書き出し範囲・静止画・連番画像」。範囲をルーラー上のドラッグで動かす操作と範囲ループ再生は実装済み(再生 ▸ 範囲をループ再生)。書き出し範囲の印は、ルーラーで掴んで動かせます)。GIF、ProRes、書き出しキュー(バックグラウンド)は未実装
2. **素材ライブラリ(メディアプール)**: 取り込み素材の一覧、プロジェクトのテンプレート(リンク切れの検出・書き出し前の停止・場所の再指定は実装済み)
3. **色**: LUT(.cube)の読み込み、カラーホイール、クロマキー(グリーンバック)
4. **プレビューの高速化**: Metal でのレンダリング、プロキシ(軽量版)での 4K 編集

## フェーズ D: 取り込みと自動化
1. **自動文字起こし**: Apple の音声認識(オンデバイス)で字幕を自動生成
2. **画面収録・Web カメラ収録**を、アプリの中から
3. ショートカットアプリ(Shortcuts)・AppleScript からの操作

## AI 連携(フェーズをまたぐ小さな機能) — **実装済み(最小版)**
- ローカルのコマンド / このマシン上のサーバー(Ollama 形式)を呼ぶ `AIProvider`。鍵は保存しない・自動送信しない・送る前に内容を見せる・キャンセル可。`DESIGN.md` の「AI 連携」。
- AIで台本を作る(ファイル)、チャプター案をAIで作る(出力)、AIでセリフを直す(クリップ。選んでいる 1 つのボイスクリップ)、`moviecut-cli ai script` / `project-info`。
- 未対応: 複数クリップの一括言い換え、ストリーミング表示、字幕(ボイス以外)の言い換え、MCP サーバーとしての常駐(今は CLI の `project-info` で外部 AI が読む形)。

## 守ること
- 互換: `.mcpjc` / `.ymproj` を壊さない(新しい項目は読み飛ばせる形で追加、古いファイルはそのまま開ける)
- 動作確認で、アプリを繰り返し起動しない(画面に出ない静かな起動を少回数、またはテスト内で)
- 公開前: 署名とノータライズ、ライセンス文の空欄、「Movie Cut」の商標確認

## 機能調査からの追加候補
200 機能の調査と Movie Cut との突き合わせ: [機能調査/Movie Cutとの突き合わせ.md](機能調査/Movie%20Cutとの突き合わせ.md)(元の調査は同じフォルダ)。上の B〜D に無く、追加したい候補(工数は見積もり):
- **書き出し(C-1 に足す)**: ビットレート指定・独自の書き出しプリセット保存(小)
- **素材(C-2 に足す)**: 書き出し前の欠落素材の検出(小。実装済み: 書き出しを止めて表示、場所の再指定)
- **A の残り**: クリップ間の自動クロスフェード配置(中)、スピードランプ(大)、ノイズゲート・リミッター(中)、音量/ラウドネスメーター(中)、リップルトリム・ロール編集・範囲選択(中)
- **字幕(B-3 に足す)**: 時刻付き字幕(SRT)から音声クリップを配置(中)
- **キャラ(B-7 に足す)**: 立ち絵のパーツ合成・PSD 読み込み(大)
- **編集**: J/L カット(映像と音声を分けてずらす)(大)、キーボードショートカットの変更(中)
- **信頼性**: 自動保存と異常終了からの復元は実装済み(復元フォルダへの写し・起動時の確認)。世代バックアップは未実装(中)、Undo の回帰テスト追加(小)
- **音声**: 実況の環境音のノイズ除去(大。Apple 標準 API で足りるか要調査)

## 実装済み: 書き出し中のファン最大化(2026-10-31)
- 出力 ▸ 「書き出し中はファンを最大にする」(設定シートの「書き出し」欄にも同じチェック)。アプリ全体の設定(UserDefaults `fanMaxDuringExport`)。仕組み・安全策・ポート・手順は DESIGN.md の「書き出し中のファン最大化」と README.md を参照。
- 実装は Core `FanControl.swift`(機種の許可リスト・FanGuard・HTTP クライアント・インストール用シェルの組み立て)、アプリ `FanService.swift`、特権ヘルパー `Sources/moviecut-fanhelper`、確認用 CLI `moviecut-cli fan status | fan test` と `export --fan-max`。
- 未了: 署名・ノータライズ済みの配布では `SMAppService.daemon` に切り替える(いまは `NSAppleScript` の管理者権限で `/usr/local/libexec` と `/Library/LaunchDaemons` に置く暫定方式)。実際の管理者権限インストールは未検証。

# Movie Cut ロードマップ(「超万能な動画編集ソフト」へ)

方針: Mac 専用・Apple Silicon・ネイティブ(Swift / AVFoundation / Core Image / Metal / Vision / Speech)。外部ライブラリは使わない。
作る順番は A → B → C → D。各フェーズは小さな段階に分けて、段階ごとにテスト・確認・コミットする。

## 先に作るもの(進行中)
- メニューバーの「出力」メニュー(解像度・FPS・書き出し形式・背景色・書き出し・プリセット)に集約
- 解像度のカスタム、フレームレートのカスタム(小数・NTSC レート対応)

## フェーズ A: 編集の基本を万能に
1. **変形とキーフレーム**: 位置・拡大・回転・反転・切り抜き(クロップ)・不透明度を、時間で変化させる(イーズ付き) — **実装済み**(`DESIGN.md` の「変形とキーフレーム」。キーフレームのイージング編集 UI(曲線エディタ)は未実装、`bezier:` はファイルに直接書く)
2. **トランジション**: フェード、クロスフェード、スライド、ワイプ、ズーム(クリップの頭・尻に付ける) — **実装済み**(`DESIGN.md` の「トランジションと音声フェード」。クリップ間の「ずらして重ねる」自動配置・トランジション専用のプレビュー取っ手は未実装)
3. **エフェクト(Core Image)**: 明るさ/コントラスト/彩度/色相/露出、シャープ、モノクロ/セピア、ビネット、モザイク、各種ぼかし(ガウス/ズーム/モーション)、グロー、ドロップシャドウ、縁取り — **実装済み**(`DESIGN.md` の「エフェクト」。キャンバス外へはみ出す影・縁は未実装。**クロマキー・LUT(.cube)・光学ミスト(ハイライトのにじみ)も実装済み**)
4. **速度変更**: 0.25〜4 倍、逆再生、静止画(フリーズフレーム) — **実装済み**(`DESIGN.md` の「速度変更・逆再生・フリーズフレーム」。音程を保つ/保たない、タイムラインの札、分割・トリムの追従まで。速度ランプ(時間で速さが変わる・直線補間)は実装済み。イージングは未対応)
5. **クリップの音声**: フェードイン/アウト(**実装済み**: A-2)、音量のキーフレーム・パン・3 バンド EQ・コンプレッサー・リバーブ・ノーマライズ(**実装済み**: A-5。`DESIGN.md` の「クリップの音声処理」。タイムラインの音量包絡線・クリップ単位の消音・ゲート付きラウドネスは未対応)
6. **タイムラインの見やすさ**: 動画/画像のサムネイル、音声の波形、複数選択、コピー&ペースト、レイヤーの名前変更/ロック/ソロ/高さ/削除(確認つき・Undo 1 回・最後の 1 つは不可) — **実装済み**(A6。`DESIGN.md` の「タイムライン(フェーズ A6)」)。**範囲選択(ルーラーの ⌥ ドラッグ・範囲の削除)は未実装**

## フェーズ B: 解説・実況動画に強くする
1. **文字の強化**: 影・背景ボックス・グラデーション、字間・行間・揃え・太字・斜体、アニメーション(タイプライター、ポップ、揺れ)、フェードイン、スタイルの保存(組み込み 9 つ(フェードイン・タイプライター・ポップの動きつきプリセットを含む) + 名前をつけて保存) — **実装済み**(B-1。`DESIGN.md` の「文字の装飾・スタイル・アニメーション」)。**縦書き、文字ごと(1 文字ずつ)の動き、字幕(ボイス)のアニメーションは未対応**
2. **吹き出しと図形**: 吹き出し(ゆっくり風) — **吹き出しは実装済み**(文字クリップの `bubble`: 丸角・雲・四角、塗り・縁・尾(点かキャラ)、インスペクタ、「吹き出し風」プリセット。`DESIGN.md` の「吹き出し(B-2)」。吹き出しの不透明度・フェード、文字の回転への追従は未対応)。**矢印・四角・丸・線・星は実装済み(クリップ ▸ 図形を追加。`DESIGN.md` の「図形・ビート検出・ガイド線・サムネイル」)。**スタンプ/絵文字は実装済み(第6弾)。APNG は未実装**(GIF の書き出しは C-1 に移して実装済み)
3. **字幕**: SRT/VTT の書き出しと読み込み、台本から字幕トラックを自動生成、YouTube のチャプターをマーカーから生成 — **SRT/VTT の書き出し・読み込み、チャプターのコピーは実装済み**(`DESIGN.md` の「字幕ファイルとチャプター」)。**台本から字幕トラックの自動生成は実装済み**(出力 ▸ 字幕を自動生成。ボイスの「字幕を出す」を切り、同じ時刻の文字クリップを「字幕」レイヤーに作る。1 回で元に戻せ、生成済みなら何もしない)
4. **自動ぼかし(Vision)**: 顔・文字を検出して、動くぼかし範囲を自動で付ける — **顔は一部実装済み**(エフェクト `faceBlur`: 顔の枠をモザイク/ぼかし。検出は `VisionFaceDetector`、同じ時刻の検出はキャッシュ。`DESIGN.md` の「顔ぼかし」。**自動で付ける**(クリップごとに一括で付与する操作)・文字の検出・動くぼかし範囲(追従)・調整レイヤーへの適用は未対応。実際の顔での検出精度は未確認)
5. **無音カット**: 無音区間を検出して自動で詰める(実況向け) — **実装済み**(クリップ ▸ 無音をカット…、`moviecut-cli silence`。`DESIGN.md` の「無音カットと BGM の自動ダッキング」。速度・逆再生のあるクリップ、字幕・波形の連動カットは未対応)
6. **BGM の自動ダッキング**: 声が出ている間だけ BGM を下げる — **実装済み**(音声クリップの `duck`。インスペクタとクリップ ▸ 音声 ▸ 自動ダッキングを切り替え。ボイスクリップを「声」とみなす。録音した話し声(音声クリップ)を声として扱う指定は未対応)
7. **キャラクター演出**: まばたき、話している間のバウンス、セリフごとの表情切り替え(`[笑顔]` のタグ)、口の形(あいうえお)でのリップシンク — **部分実装済み**(`DESIGN.md` の「キャラクター演出(B-7)」。口の開閉・まばたき・表情タグ・バウンスは描画と書き出しに入り、インスペクタで画像の割り当て・表情の追加・名前変更・削除ができる。あいうえおのリップシンク(口の形の判定)は未対応)
8. **読み辞書とイントネーション**: セリフごとの読み修正、VOICEVOX のアクセント編集、AquesTalk のユーザー辞書、COEIROINK / SHAREVOX 対応
9. **調整レイヤー・スクロール文字** — **実装済み**(`DESIGN.md` の「調整レイヤー」と文字アニメーションの `scrollUp` / `scrollLeft`。クリップ ▸ 調整レイヤーを追加、クリップ ▸ テキスト ▸ 文字アニメーション ▸ スクロール)。AI 画像生成のフックは実装済み(クリップ ▸ AIで画像を作る…。`DESIGN.md` の「AI 画像生成フック」)。

## フェーズ C: 出力とワークフロー
1. **書き出し**: イン/アウト範囲・静止画(PNG/JPEG)・連番画像 — **実装済み**(`DESIGN.md` の「書き出し範囲・静止画・連番画像」。範囲をルーラー上のドラッグで動かす操作と範囲ループ再生は実装済み(再生 ▸ 範囲をループ再生)。書き出し範囲の印は、ルーラーで掴んで動かせます)。GIF(出力 ▸ GIFとして書き出す…、`DESIGN.md` の「GIF 書き出し」)は実装済み。書き出しキュー(出力 ▸ 書き出しキューに追加… / 書き出しキューを表示…)は実装済み(`DESIGN.md` の「書き出しキューと素材ブラウザ」)。キューの件は Dock の進行バーとファン最大化を使わない。ProRes は未実装
2. **素材ライブラリ(メディアプール)**: 取り込み素材の一覧(プロジェクトのテンプレートは実装済み。BGM・効果音のフォルダ参照の素材ブラウザは実装済み。同梱ライブラリとサブフォルダ・波形は未実装)(リンク切れの検出・書き出し前の停止・場所の再指定は実装済み)
3. **色**: LUT(.cube)の読み込み、クロマキー(グリーンバック)は実装済み。カラーホイール(持ち上げ・ガンマ・ゲイン)とホワイトバランス(色温度・ティント)は実装済み(`DESIGN.md` の「色補正・形のマスク・自動リフレーム」)。形のマスク(矩形・楕円・反転・羽根)も実装済み。自動リフレームは実装済み(`DESIGN.md` の同じ節。検出は Vision、実機での見た目は未確認)
4. **プレビューの高速化**: Metal でのレンダリング、プロキシ(軽量版)での 4K 編集 — **プロキシは実装済み**(出力 ▸ プロキシを作成、表示 ▸ プロキシで編集。540p・プレビューだけが読む。`DESIGN.md` の「プロキシ編集」。Metal は未対応)

## (旧)設計メモ: 複合クリップ
- **目的**: 複数のクリップを 1 つにまとめ、中を子のタイムラインとして編集できるようにする(まとめてから動かす・効果をかける)。
- **案**: 新しいクリップの種類 `compound`(素材なし)に、子の `tracks`(任意。無いときは書かない)を持たせる。描画は、子のタイムラインを時刻 `t − start + offset` で描いて、親のクリップと同じく「画素 → 変形・エフェクト・不透明度」の経路に載せる(調整レイヤーと同じ考え方)。音声は `AudioMixer` が子を再帰的に混ぜる(時刻の対応は親の速度・逆再生に従う)。
- **ファイル**: `compound` と子の `tracks` は任意項目(既定では書かない)。古いファイルは変わらない。ファジング(`ProjectFuzzTests`)に子の入れ子を足す。
- **Undo**: まとめる・ばらすは 1 回。子の編集は子のタイムラインの中の Undo として、親の 1 回に畳む(案)。
- **危険**: 入れ子の循環(自分を含む)を読み込み時に拒否する必要がある。描画は子ごとにオフスクリーンを作るため、1 コマの描画時間が増える(ms/フレームを測ってから決める)。音声のキャッシュ鍵に子の内容を足す必要がある。
- **段階**: (1) データ形式と読み書き・循環の拒否 (2) 映像の描画(オフスクリーン) (3) 音声の再帰 (4) メニュー「まとめる」「ばらす」と Undo (5) 書き出しとプレビューの同一性テスト。今回はコードに手を付けず、ここまでの判断だけ残した。

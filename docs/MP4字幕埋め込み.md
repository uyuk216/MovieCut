# MP4 字幕埋め込み(mov_text)

MP4 書き出しのとき、字幕を別ファイル(サイドカー)ではなく **MP4 の中の字幕トラック**として埋め込めるようにした記録。Premiere 棚卸しの残り候補「字幕の MP4 埋め込み」の実装(2026-11-19)。

## 使い方

- **アプリ**: 書き出しの保存パネルで「字幕を埋め込む」にチェックする(既定はオフ)。
- **CLI**: `moviecut-cli export <project> <out.mp4> --embed-subtitles`
- **Core**: `Exporter(..., subtitleEmbed: .japanese)` / `ExportJob.run(..., subtitleEmbed:)`。設定は `SubtitleEmbedSettings`(既定 `.disabled`)。

既定は従来どおりで、埋め込みを選んだときだけ字幕トラックが付く。サイドカー(SRT/VTT/SCC/EBU-STL)の書き出し、映像・音声の書き出しは無変更。

## 仕様

- **元データ**: サイドカー書き出しとまったく同じ `SubtitleFile.cues(from:)`。つまり「字幕がオンのボイスの表示字幕」と「字幕」レイヤーの文字クリップ。複数レイヤーに分かれていても 1 本のトラックにまとめる。
- **形式**: mov_text(3GPP Timed Text、tx3g)。言語は日本語(ja、ファイル内では jpn と記録される)。
- **範囲書き出し**: 範囲の頭に合わせて時刻をずらし、範囲の外は切り捨てる。
- **重なり**: 前の件の終わりを次の件の開始まで詰めて解消する(サイドカーと違い、トラック内では重ねない)。
- **終わりの時刻**: 件と件の間と末尾には空のサンプルを明示的に入れる。入れないと読み手が表示を次の件まで伸ばしてしまうため(下記の実機確認で判明)。
- **本文の整え方**: サイドカーと同じ(空行・前後の空白を除く)。複数行はそのまま改行として入る。
- **見た目**: 書式記述に固定のスタイルを持たせる(フォント Helvetica、白文字、背景透明、配置は中央・下、大きさは画面の高さ ÷ 20 を 12〜64 に丸めた値)。MovieCut の字幕の見た目(フォント・色・縁取り・座布団)は再現しない。
- **ルビ**: mov_text の平文には載せない。親文字だけが入る。
- **上限**: 1 件の本文は tx3g の記録上限(65,535 バイト)で文字の途中で切れないよう切り詰める。

## 対象外(従来どおり埋め込まない)

- **ProRes(.mov)**: 字幕トラックは入れない(MP4 専用)。CLI で `--embed-subtitles` を付けても .mov には付かない(実測済み)。
- **音声のみ(.m4a)**: 対象外。
- **WebM / AV1 / WebP / DNxHR(ffmpeg 経路)**: 対象外。中間 MP4 にも埋め込まない。
- **字幕が無いプロジェクト**: 埋め込みを選んでも字幕トラックは作らず、従来と同一の出力になる。

## 採用した経路と実機確認(2026-11-19、対象 Mac)

現在の MP4 書き出しの主経路は `AVAssetWriter`(`Exporter`)で、ffmpeg は追加形式専用の任意バックエンド。そのため、まず両経路がこの Mac で実際に書けるかを最小実験で確かめた。

| 経路 | 確認内容 | 結果 |
|---|---|---|
| AVAssetWriter(書式記述なしのテキスト入力) | `canAdd` | **false**(そのままでは追加できない) |
| AVAssetWriter(素の tx3g 書式記述・拡張なし) | 追加と append は成功、しかし `finishWriting` | **失敗**(-11800 / -12712) |
| AVAssetWriter(拡張から既定スタイル・フォント表だけ欠いた書式記述) | `finishWriting` | **失敗**(-12715、書式記述が不正) |
| AVAssetWriter(拡張を全部そろえた書式記述) | 書き出し完了 → ffprobe / ffmpeg で読み戻し | **成功**(下記)。採用 |
| ffmpeg の mov_text エンコーダ | 小さい MP4 + 日本語 SRT を mux → ffprobe / SRT 往復 | **成功**(使えるが不採用) |

ffmpeg 経路を採らなかった理由: 主経路が ffmpeg 不要で完結すること(MovieCut 本体は「ffmpeg 不要」が原則で、ffmpeg が無い環境でも MP4 書き出しは動く必要がある)、1 回の書き出しで済み映像・音声の再 mux が要らないこと。

### 採用経路の検証結果(実測)

- テストプロジェクト(320×180、字幕 2 件: 0.2〜1.2 秒「こんにちは、世界」、1.5〜2.8 秒「日本語の字幕テストです」)を CLI で書き出し:
  - フラグなし: 映像トラックのみ(従来どおり)。
  - `--embed-subtitles`: 映像 + `mov_text` 字幕トラック(言語 jpn)が付く。
  - ffprobe のパケット: `0.200/1.000`、隙間 `1.200/0.300`、`1.500/1.300`、末尾 `2.800/0.200` と、件の時刻がそのまま保たれる。
  - ffmpeg で SRT に戻すと `00:00:00,200 --> 00:00:01,200` / `00:00:01,500 --> 00:00:02,800` で一致し、日本語も化けない。
  - HEVC のプロジェクトでも同じく埋め込めることを確認。
- 単体テスト `SubtitleEmbedTests` 17 件: 件の取り出し・範囲のずらし・重なりの解消・隙間の挿入・tx3g バイト列の純粋検証に加え、実書き出しを AVFoundation で読み戻して照合(埋め込みあり/なし、字幕なし、範囲書き出し、ExportJob 経由)。

## プレイヤー互換性の注意

- mov_text(tx3g)は MP4 の標準的な字幕形式で、QuickTime Player / VLC / IINA などでは「選択できる字幕」として扱われる想定の形式。ただし **本作業では実プレイヤーでの表示確認はしていない**(未検証事項)。
- AVAssetReader で字幕サンプルを読むと、トラックの開始位置を引いた相対時刻で返り、境界に長さ 0 の空サンプルも足される(ファイル自体のパケット時刻は ffprobe の値が正)。
- ffmpeg で SRT に戻すと、スタイルが `<font face="Helvetica" size="12">{\an0}` のようなタグとして現れる。これは tx3g の既定スタイルを ffmpeg が SRT 記法へ訳したもので、本文と時刻は一致する。プレイヤーではタグではなくスタイルとして解釈される。

## 未検証事項

- QuickTime Player / VLC / IINA 等の実プレイヤーで字幕が表示・選択できるか(表示位置・大きさの見え方を含む)。
- YouTube 等の配信先にアップロードしたとき、埋め込み字幕が字幕として取り込まれるか。
- 字幕件数が非常に多い(数千件)プロジェクトでの書き出し時間への影響。
- macOS 14 以外(15/26 等)での AVAssetWriter の字幕トラック対応。書式記述が作れない・トラックを追加できない環境では、書き出し自体が「字幕の書き出し設定を使えませんでした」で失敗する(黙って字幕なしにはしない)。

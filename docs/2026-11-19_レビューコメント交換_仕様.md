# レビューコメント交換(Frame.io 等価のローカル実現)

タイムコード付きのレビューコメントをプロジェクトに保持し、交換用ファイルで
他の人・他の道具とやり取りする仕組み。Frame.io のようなクラウド共有そのものは
作らない(下記「Frame.io との違い・未対応事項」)。

## 使い方

- アプリ:移動 ▸「レビューコメントを追加…」/「レビューコメント一覧…」でシートを開く。
  - シート上部:作成者名と本文を入れて「追加」で、現在の再生位置にコメントが付く。
    選択中のクリップがあれば、そのクリップの id が対象として記録される。
  - 一覧の各行:タイムコードを押すとその位置へ移動、本文は編集して確定(Enter)すると
    反映、解決済み/未解決の切り替え、削除ができる。すべて Undo 1 回で戻せる。
  - 移動メニューの「レビューコメント」サブメニューからも各コメントへ移動できる
    (解決済みにはチェックが付く)。
- 交換:移動 ▸「レビューコメントを書き出す…」(JSON / CSV)、
  「レビューコメントを読み込む…」(JSON)。
  - 書き出し先に `.csv` を選ぶと CSV、それ以外は JSON になる。
  - 読み込みは 1 回の Undo で戻せる。

## 保存形式(プロジェクト内)

- `Project.reviewComments`(配列)。空のときはキーごと書かないので、
  コメントを使っていないプロジェクトのファイルは従来とバイト単位で一致する。
- 各コメントの項目:
  - `id`(文字列、必須)、`time`(秒、0 以上)、`body`(本文)
  - `endTime`(秒、任意。範囲コメントの終わり。`time` 以下なら読み捨てる)
  - `author`(作成者名、任意。空なら書かない。アカウント情報ではない表示名)
  - `clipId`(対象クリップの id、任意。クリップが消えてもコメントは残る)
  - `resolved`(解決済み。false なら書かない)
  - `createdAt` / `updatedAt`(ISO 8601 文字列、任意)
- マーカーと同じ作法:型が違う値は既定値に倒し、知らないキーは保持して書き戻す。
  コメント全体が型違いの場合はプロジェクトの `extra` に保持する。

## 交換ファイルの仕様

### JSON(正形式)

```json
{
  "format": "moviecut-review-comments",
  "version": 1,
  "exportedAt": "2026-11-19T12:00:00Z",
  "comments": [ { "id": "…", "time": 12.5, "body": "…", "author": "…" } ]
}
```

- コメントの各項目はプロジェクト内の保存形式と同じ。
- 読み込みは、素の配列 `[ {…}, … ]` だけの JSON も受け付ける
  (他の道具が作った一覧を取り込めるように)。
- `format` が違うファイル、`version` が 1 より大きいファイルは、黙って空にせず
  エラーとして断る。

### CSV(書き出し専用・閲覧用)

- 列:`id,timecode,time,endTime,author,resolved,clipId,body`
- `timecode` は `m:ss`(1 時間以上は `h:mm:ss`)、`resolved` は `resolved` / `open`。
- 引用は RFC 4180 式(カンマ・引用符・改行を含む項目は `"` で囲み、`"` は二重化)。
- CSV の読み込みには対応していない(往復の正は JSON)。

### 読み込み時の競合規則

- 同じ `id` が既にある → 読み込んだ側で**上書き**(更新として数える)。
- 新しい `id` → **追加**。
- 交換ファイルに無い既存コメントは**消さない**。
- 内容がまったく同じ `id` は「変更なし」に数え、プロジェクトも Undo 歩数も変えない
  (同じファイルの再読み込みは冪等)。
- 反映後は時刻順に並べ直す。件数(追加・更新・変更なし)は状態欄に表示する。

## Frame.io との違い・未対応事項

- **クラウド共有はしない**:コメントはプロジェクトファイルと交換ファイルの中だけに
  あり、外部サービスへの自動送信・同期は一切しない
  (ユーザーのサーバに個人情報を持たせない大原則に従う)。
- **リアルタイム共同編集・同時接続は対象外**。受け渡しはファイル単位で、
  競合は上記の id 単位の規則で解決する(本文のマージはしない)。
- コメントへの返信(スレッド)、メンション、通知、承認ワークフローは未対応。
- 動画そのものへの描き込み(フレームへの図形注釈)は未対応。位置はタイムコードと
  対象クリップ id で表す。
- CSV は書き出し専用。Frame.io 等の他サービスの形式との直接互換はなく、
  取り込みたい場合は上記 JSON 形式(または素の配列)に変換してから読み込む。

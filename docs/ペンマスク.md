# ペンマスク（ベジェマスク）

ブランチ `feat/pen-mask`（起点は `feat/muse-access` e1c4305）。
棚卸し表 `premiere-inventory.md` エフェクト節「マスク（矩形・楕円・ペン）＋マスク追跡」が仕様の起点。
Premiere Pro のペンマスク相当として、制御点を持つベジェ曲線の閉じたパスを
クリップの形マスク（`Clip.mask`）の第 3 の形 `pen` として追加した。
既存の矩形・楕円マスク、オブジェクトマスク、HSL マスクの挙動は変えていない（追加のみ）。
形マスク未使用時（`Clip.mask == nil`）の描画は従来と画素一致する。

## 使い方

1. 映像・画像など、エフェクトを扱えるクリップを選ぶ。
2. プロパティ欄の「形のマスク」節で「形で切り抜く（外は透明）」をオンにする。
3. 「形」で「ペン」を選ぶ。最初は既定の菱形（4 点）が入る。
4. 形を作る。
   - **プレビュー上**: 点（四角）をドラッグすると、その点がハンドルごと動く。
     ハンドル（丸）をドラッグすると、そのハンドルだけが動き、辺が曲がる。
     輪郭とハンドルは、クリップを選んで再生を止めているときだけ表示される
     （変形の取っ手と同じ条件。対象は画像・動画・文字・立ち絵クリップ）。
   - **プロパティ欄**: 点ごとに、アンカー（点の横／縦）と入るハンドル・出るハンドル
     （各 横／縦）をスライダーで調整できる。「ハンドルをまっすぐにする」で
     その点のハンドルがアンカーへ戻り、角（直線の点）になる。
   - **点を追加**: 「点を追加」ボタンで、閉じる辺（最後の点→最初の点）の中点に点が増える。
     特定の辺に挟む操作（`ProjectModel.insertPenPoint(after:)`）もモデルにはある。
   - **点を削除**: 各点の「削除」。面積を保つため 3 点未満にはできない。
5. 「羽根（ぼかし）」と「反転（中を透明にする）」は矩形・楕円とそのまま併用できる。
   羽根の基準（短い辺）は、ペンでは点列（ハンドル込み）の外接矩形の短い辺。
6. オフにするとマスクは外れる（`Clip.mask` が nil になり、ファイルにも書かれない）。
   形を矩形・楕円へ戻しても点列は保持されるので、ペンへ戻すと続きから編集できる
   （ファイルにも、点があるときは形によらず `points` を書く）。

座標はすべてキャンバスに対する割合（0〜1・左上原点）で、矩形・楕円と同じ約束。
点・ハンドルとも 0〜1 に収まる（キャンバスの外へは出せない）。点の上限は 64。

## 仕組み

| 段階 | 実装 |
|---|---|
| 保存 | `ClipMask.points: [MaskPoint]` を追加。`MaskPoint` は アンカー (x, y) と入るハンドル (inX, inY)、出るハンドル (outX, outY)。ハンドルがアンカーと一致するときはファイルに書かない。矩形・楕円だけの既存ファイルは `points` を含まず、そのまま読める・書き戻せる（互換テストあり）。知らないキーは従来どおり `extra` に残して書き戻す |
| 幾何 | `ClipMask.sampledPolygon`（3 次ベジェを 1 曲線 16 分割で平らにする）、`penContains`（偶奇判定のレイキャスティング。テストと将来の当たり判定用）、`penCGPath`（CI 座標・左下原点へ変換した CGPath） |
| ラスタライズ | `ShapeMask.penImage`: パスをキャンバス解像度のビットマップへ白黒で描き（中＝白、外＝黒）、`CIImage` 化する。羽根なしの塗りは点列＋キャンバス大きさをキーに小さくキャッシュ（最大 8 件）し、羽根のガウスぼかしは呼び出しごとに重ねる。以後は矩形・楕円と共通の尾（黒へ合成・反転・`CIBlendWithMask` 適用）を通るので、適用順・併用（オブジェクト／HSL マスクとの積）も従来どおり |
| 描画経路 | 変更なし。`Renderer.drawEffectedClip` が `Clip.mask` を `ShapeMask.apply` へ渡す既存経路にそのまま乗る。マスク無しクリップは従来経路のまま |
| UI・モデル | インスペクタは統一デザインシステム（`InspectorSection` / `LiveSlider`）のまま、「形」ピッカーへ「ペン」を追加し、ペンのときだけ点の編集 UI を出す。編集は形マスクと同じ作法（`setClipProperty` 経由で 1 操作 1 回の Undo、ドラッグはジェスチャ集約で開始時から再計算）。プレビューの取っ手は変形（メッシュ／パペット）と同じレイヤー方式で、ペンの取っ手を最優先で掴む |
| 書き出し変換 | YMM4 (.ymmp) / AviUtl (.exo) では、形マスク全体が従来どおり「変換が未対応のため落とす」警告の対象（ペンも自動的に含まれる） |

## キーフレームの扱い

**ペンの点・ハンドルはキーフレーム対象にしていない。** 理由:

- 既存の形マスク（矩形・楕円）の項目（x / y / w / h / 羽根）は、そもそも
  `Animation.keys(for:)` に入っておらず、クリップ単位で静的な値として扱われている。
  ペンも同じ仕組みに素直に乗せ、マスク全体で扱いをそろえた（形を切り替えても
  キーフレームの有無が変わらない）。
- 全点をキーフレーム化すると、点の追加・削除でキー列の対応付け（何番の点のキーか）が
  壊れる問題が出る。やるなら変形（メッシュ／パペット）の `WarpKey` 方式
  （点番号をキー名に含める）をマスク用に拡張し、点の増減に追従してキーを
  付け替える設計が別途必要で、本実装の範囲を超える。
- 時間で形を変えたい場合は、現状はクリップを分割して区間ごとに別のペンを付ける
  ことで代替できる。マスク追跡（オブジェクトマスク／モーショントラッキング）との
  連動も今回はしていない（追跡結果をペン点列へ変換する設計が別途必要）。

## テスト

- Core（`PenMaskTests` 12 件）: 直線ペンの内外の画素、上下非対称の三角形での
  向き（上下反転していないこと）、ベジェの膨らみ（弦の外・曲線の内が残り、
  曲線より上は透明。画素と `penContains` の両方）、反転、羽根（単調な階調と
  中心の不透明）、既定の菱形、点 3 未満は全面が外（反転で全面が残る）、
  点数上限と座標クランプ、保存/復元（往復一致・ハンドルの省略・知らないキーの保持・
  点の無い既存形状ファイルの互換）、Renderer 経由の画素（背景との合成）。
- App（`PenMaskAppTests` 5 件）: ペンへの切り替えで既定の点が入り 1 回の Undo、
  点の追加（閉じる辺の中点）・削除・ハンドル初期化が各 1 回の Undo、
  3 点未満へは削除しない、live ドラッグで元へ戻すと既定と一致、
  矩形のままでは点の操作が効かない。
- 既存の `ClipMaskTests`（矩形・楕円・Renderer）は無変更で全件通過。

## 未検証事項

- アプリ画面（インスペクタの節とプレビューの取っ手）での実操作確認は未実施
  （コンパイル＋単体テストまで）。プレビューのドラッグはモデル経由の
  ロジック（`liveMaskField` と開始時クリップからの再計算）までは App テストで
  確かめたが、実マウス操作での当たり判定・追従は未確認。
- 実写素材での見た目の確認は未実施。テストは合成画像（単色）での画素確認。
- 大きなキャンバス（4K）での毎コマ描画の速さは未計測。羽根なしの塗りは
  キャッシュされるが、羽根ありでは毎コマぼかしがかかる。重い場合は
  マスク解像度の間引き（トランジションのマスクと同じ方式）が候補。
- Premiere Pro のペンマスクとの数値一致（羽根の効き方、自己交差パスの
  塗り方）は未検証。自己交差パスは CG の nonzero winding で塗る
  （`penContains` の偶奇判定とは自己交差時に結果が違いうる）。
- 点の座標は 0〜1 に制限した（Premiere はキャンバス外の点も置ける）。
  外へはみ出すマスクが必要になれば、変形の点と同じ広い範囲への拡張が候補。

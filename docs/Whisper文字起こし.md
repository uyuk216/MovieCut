# Whisper 文字起こし

Movie Cut は、音声から字幕を作る第 2 のエンジンとして [whisper.cpp](https://github.com/ggerganov/whisper.cpp)(OpenAI Whisper の C/C++ 実装)を使えます。Apple の音声認識より日本語の精度が高いことが期待できます。既定は従来どおり Apple の音声認識で、Whisper は使いたいときだけ選びます。

**モデルはアプリに同梱していません。** whisper.cpp 本体もモデルも、初回利用時に利用者が自分で配置します(下記)。Movie Cut は検証した外部実行ファイルを、シェルを通さず引数配列で実行するだけです。

> **検証状況(2026-11-19)**: 単体テストは偽の実行ファイル(固定の JSON を書くスクリプト)で配線・引数・失敗・キャンセルを確かめた範囲です。これに加えて統括が実エンジン(Homebrew の whisper.cpp 1.9.5 + ggml-base)で `moviecut-cli transcribe --engine whisper` を実行し、日本語音声から字幕(SRT)が作れることと、モデル未配置時に日本語の案内が出ることを確認しました。アプリ画面からの実行・長い素材での速度・精度は未確認です。

## 1. whisper.cpp を入れる

次のどちらかです。

- **Homebrew**: `brew install whisper-cpp`
  - 実行ファイル `whisper-cli` が `/opt/homebrew/bin`(Intel Mac は `/usr/local/bin`)に入ります。Movie Cut はここも自動で探します。
- **公式リリースのバイナリ**: <https://github.com/ggerganov/whisper.cpp> の Releases からビルド済みを取得(または自分でビルド)し、実行ファイルを後述の配置先に置きます。

実行ファイル名は `whisper-cli` です。旧名の `whisper-cpp` / `main` でも使えます(配置先に置く場合)。

## 2. モデルを入れる

<https://huggingface.co/ggerganov/whisper.cpp> から `ggml-base.bin` などをダウンロードします。

| モデル | ファイル名 | サイズの目安 |
| --- | --- | --- |
| tiny | `ggml-tiny.bin` | 75 MB |
| base | `ggml-base.bin` | 142 MB |
| small | `ggml-small.bin` | 466 MB |
| medium | `ggml-medium.bin` | 1.5 GB |
| large-v3-turbo | `ggml-large-v3-turbo.bin` | 1.6 GB |
| large-v3 | `ggml-large-v3.bin` | 3.1 GB |

**精度を重視するなら large-v3(約 3.1 GB)をおすすめします。** 大きいほど精度は上がりますが、時間とメモリを使います。小さいモデル(base 等)でも動きますが、日本語・日英混在の精度は落ちます。設定画面の Whisper 欄に「large-v3 をダウンロード…」ボタンがあり、押すと配布元のページ(Hugging Face)を開きます。ダウンロードはアプリがしません。取得したファイルを配置先に置いてください。

## 2.1 VAD モデル(任意・推奨)

無音の区間を先に取り除く VAD(音声区間検出)のモデルを置くと、自動で使います。無音の区間で出やすい誤認識(幻覚)が減ることを期待しています。効果は素材によって違い、実機での比較は未確認です。

- ファイル: `ggml-silero-v5.1.2.bin`(配布元: <https://huggingface.co/ggml-org/whisper-vad>)
- 置き場所: 配布先と同じ `Whisper/` フォルダ(`Application Support/MovieCut/Whisper/`)。名前に `silero` を含む `ggml-*.bin` を優先し、無ければ `vad` を含むものを使います。
- 無いときは VAD なしで認識します(従来どおり)。設定画面の Whisper 欄に、VAD を使うかどうかの状態を表示します。

## 3. 置き場所

次のどちらかです。

- **配置先フォルダに置く**: `~/Library/Application Support/MovieCut/Whisper/` に、実行ファイルとモデル(`ggml-*.bin`)を入れます(配布版は `Movie Cut (Public)` の下の `Whisper/`)。モデルが複数あるときは、大きいものを優先します(large-v3、large-v3-turbo、medium、small、base、tiny の順)。
- **設定画面で選ぶ**: 「設定」シートの「Whisper（文字起こし）」欄で「実行ファイルを選ぶ…」「モデルを選ぶ…」を押して選びます。「選択を解除」で元に戻せます。選んだ場所はこの Mac の設定に保存し、プロジェクトファイルには保存しません。

実行ファイルは、設定で選んだもの、アプリ内、配置先フォルダ、Homebrew の場所の順に探します。見つからない場合や、モデルが無い場合は、メニューを実行したときと設定シートに案内が出ます。

### Homebrew のバイナリについて

Homebrew の `whisper-cli` はシンボリックリンクです。Movie Cut はリンクの先(実体のパス)を調べ、実体が利用者のもので、他の人が書き換えられないことを確かめてから実行します。自分で何かする必要はありません。この確認を通らない場合は、設定画面にその理由が出ます。

## 4. 使い方

- **アプリ**: 音のあるクリップを選び、メニュー「出力 ▸ 音声から字幕を作る（Whisper）…」。認識した文が「字幕」レイヤーに入ります。1 回で元に戻せ、途中でキャンセルできます。
- **アプリ(書き出し)**: 「出力 ▸ 文字起こしを書き出す（Whisper）…」で、認識した文字を `.txt`(本文だけ)か `.srt`(時刻つき)で保存します。保存先を決めたあと、タイムラインの字幕レイヤーにも載せるかを聞きます。詳しくは [transcribe-export.md](transcribe-export.md)。
- **CLI**:
  ```sh
  moviecut-cli transcribe --engine whisper --locale ja-JP ...
  ```
  `--engine` は `apple`(既定)か `whisper`。`--locale` を付けないときの Whisper は**言語の自動判定**です。`--locale ja-JP` は言語コード `ja` として渡されます。`--locale auto` も自動判定です。`--out` は `.srt` / `.vtt` / `.txt` から選びます。その他の引数は `moviecut-cli transcribe` の usage を見てください。

## 4.1 言語と精度の設定

- **言語は既定で自動判定**です(whisper の `-l auto`)。日英が混ざった音声でも、英語の単語は英語のまま、日本語は日本語のまま出ます(カタカナに直されません)。言語を固定したいときだけ `ja` などを指定します。
- **デコード**: ビーム探索の幅 5、候補数 5、温度 0(揺らぎを抑える)、記号・音楽記号の抑止を既定にしています(`WhisperOptions`)。
- **VAD**: 上の 2.1 のモデルがあれば自動で有効になります。
- **前処理**: 認識の前に、ノイズ除去(強さ 0.5)と音量の正規化(ピークを -1 dBFS へ。増幅は最大 +24 dB まで)をかけます。長さ(時刻)は変えません。30 分を超える素材はノイズ除去を省き、音量の正規化だけにします。前処理が失敗したときは、元の音声のまま認識します。
- 前処理を切るには `WhisperTranscriber(preprocessing: false)` を指定します(アプリの設定画面には出していません)。
- **区間ごとの認識**: whisper は 1 ファイルを 1 つの言語でデコードするため、途中で言語が切り替わると後半の外国語が丸ごと欠けることがあります(large-v3 で実測)。そこで、認識の前に無音(0.25 秒以上)で発話区間に分け、区間ごとに言語を自動判定させて認識し直します。区間は前後 0.15 秒の余白つきで切り出し、結果は連結して全体の時刻に直します。
  - 長所: 日英が混ざった音声でも、両方の言語が出ます。
  - 短所: 区間ごとに whisper を起動してモデルを読み直すため、区間が多い音声ほど遅くなります。精度を優先した設計です。
  - 発話が 1 区間しか無いとき(無音だけのときも含む)は、従来どおり 1 回で認識します。短すぎる区間(1.5 秒未満)は次の区間と連結し、30 秒を超える区間は 30 秒ごとに分けます。

## 6. 困ったとき

- 「whisper.cpp が見つかりません」: 上の 1 と 3 を確認。
- 「モデルが見つかりません」: `ggml-*.bin` を配置先に置くか、設定画面で選ぶ。
- 認識に時間がかかる: 長い素材は時間がかかります(制限時間は素材の長さに応じて最大 1 時間)。小さいモデルにすると速くなりますが精度は下がります。

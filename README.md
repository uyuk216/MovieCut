# Movie Cut

動画編集ソフト for Mac。台本を書くと、VOICEVOX やゆっくり音声(AquesTalk)の声でしゃべるキャラクター付きの動画を作れます。Swift 製のネイティブアプリです。

## 必要なもの
- macOS 14 以降、Apple Silicon (arm64)
- 音声エンジンは同梱していません。使うものを別にインストールしてください。
  - VOICEVOX(`/Applications/VOICEVOX.app`)
  - AquesTalkPlayer(`/Applications/AquesTalkPlayer.app`)。無いときは macOS の「Kyoko」で代用します。
- ビルドするには Swift 6 のツールチェーン(Xcode または Command Line Tools)

## ビルドと実行
```
swift build                      # 開発用ビルド
swift run MovieCut               # アプリを起動
Scripts/make-app.sh              # build/Movie Cut.app を作る(ad-hoc 署名)
Scripts/make-app.sh dmg          # build/MovieCut-0.2.0-arm64.dmg も作る
Scripts/make-app.sh --edition public dmg   # 配布版(build/public/)。個人の環境と完全に分かれる
Scripts/make-app.sh --edition public --dry-run   # 何も作らず、やることの表示と個人情報の検査だけ試す
```

## 書き出し(コマンドライン)
```
moviecut-cli export in.mcpjc out.mp4                       # プロジェクトの設定のまま
moviecut-cli export in.mcpjc out.mp4 --size 2048x1080 --fps 29.97 [--codec hevc]  # 任意の幅x高さ(64〜8192)・fps(1〜240、23.976 や 30000/1001 も可)
moviecut-cli smoke --out out.mp4 --size 1280x720 --fps 23.976
moviecut-cli export in.mcpjc out.mp4 --preset youtube1080  # 1920×1080 H.264
moviecut-cli export in.mcpjc out.mp4 --preset youtube4k    # 3840×2160 HEVC
moviecut-cli export in.mcpjc out.mp4 --preset short        # 1080×1920 H.264
moviecut-cli export in.mcpjc out.mp4 --preset light        # 1280×720 H.264、fps は 30 まで
moviecut-cli export in.mcpjc out.m4a --preset audio        # 音声のみ(AAC 256 kbps・48 kHz)
```
アプリでは「出力 ▸ 書き出しプリセット ▸ …」の同じプリセットを使えます。プリセットはプロジェクトの写しに当てるので、元のプロジェクトは変わりません。
縦型・X 向けの `tiktok` / `shorts` / `reels`(1080×1920)、`x720` / `x1080`(8 Mbps)、`youtube1080p60` を追加しました。`--bitrate 8`(Mbps、1〜100)で映像のビットレートを指定できます。
「出力 ▸ 書き出しプリセット ▸ 現在の設定をプリセットに保存…」で自分のプリセットを作れます(Application Support の `MovieCut/export-presets.json`。壊れていても無視して起動します)。CLI は保存したプリセット名もそのまま `--preset` に使えます。
保存パネルでは「書き出しの種類」と「ビットレート」を選べます。

- ラウドネス: 「出力 ▸ ラウドネスを測る…」(書き出しと同じミックスを BS.1770 で測る。統合・ショートターム最大・真のピーク)。CLI: `moviecut-cli loudness <project>`。YouTube の −14 LUFS は目安として差を見せるだけで、音量は変えません。
- スコープ: 「表示 ▸ スコープ…」で、今のコマのヒストグラムと波形を見られます(表示用。書き出しには影響しません)。

縦書き・1 文字ずつの動き: インスペクタの「装飾」に「縦書き（右の列から左へ）」、「文字アニメーション」に「1文字ずつ動かす」と文字の間隔。メニューはクリップ ▸ テキスト ▸ 縦書き / 1文字ずつ動かす。字幕(ボイス)にも縦書きと文字アニメーション(スクロール以外)が使えます。

APNG・ProRes: 出力 ▸ APNGとして書き出す…(アニメーション PNG。背景色を「透明」にすると透明のまま)。出力 ▸ 書き出し形式に ProRes 422 / ProRes 4444(.mov。4444 は背景が透明なら透明を残す)。

世代バックアップ: 保存のたびに、プロジェクトの写しを最大 10 世代(設定で変更可)残します。ファイル ▸ 過去の版から復元… で選ぶと、コピーを新しい無題の書類として開きます(元のファイルは変わりません)。

書き出し範囲・静止画・連番画像: 出力 ▸ 書き出し開始 / 終了を現在位置に(ルーラーにオレンジの印。範囲を解除で消える。プロジェクトに保存され、範囲が無い古いファイルは変わりません)。ルーラーの印(オレンジの「[」「]」)はドラッグで動かせます(離したときに 1 回で元に戻せます)。メニューの再生 ▸ **トリム点を反復再生**(再生位置の前後 0.5 / 1 / 2 秒を繰り返す。幅は「反復再生の幅」で選ぶ。アプリの設定に保存、プロジェクトには入らない)・**選択クリップを反復再生**(同じメニューをもう一度か Space で止まる)、**範囲をループ再生**(範囲の中だけを繰り返します。保存されず、プロジェクトは変わりません)。範囲があると、MP4 の書き出しの保存パネルに「範囲だけ書き出す」(初期オン)が出て、映像も音声も同じ区間だけ書きます。出力 ▸ 現在のフレームを画像で書き出す…(PNG / JPEG。拡張子で決まる)、出力 ▸ 連番画像を書き出す…(名前のフォルダに `名前_00001.png` …、進み具合とキャンセルは動画と同じ)。出力 ▸ GIFとして書き出す…(アニメーション GIF。音は入りません。保存パネルで 5〜30 fps と幅 320 / 480 / 640 px・原寸を選べます。範囲があれば範囲だけ。無限ループ。進み具合とキャンセルは動画と同じ。GIF は 1/100 秒単位なので、15 fps などは表示時間が 1/100 秒に丸められます)。画面なしでは `moviecut-cli export in.mcpjc out.mp4 --range 1:3`(秒。`2:` や `:5` も可、`--range project` は保存済みの範囲)、`moviecut-cli frame in.mcpjc --t 1 --out f.png|f.jpg`、`moviecut-cli sequence in.mcpjc --out dir --format png|jpeg [--range 1:3] [--fps 30]`、`moviecut-cli gif in.mcpjc --out x.gif [--fps 10] [--width 480] [--range 1:3]`。

素材と復元: ファイル ▸ **素材の場所を再指定…**(欠けている素材があるとき。フォルダを選ぶと、その中から同じファイル名を探して差し替えます。1 回で元に戻せます)。出力 ▸ 書き出しは、欠けている素材があると保存パネルの前で止まり、どれが無いかを表示します。


重なったクリップの音だけの試聴・巡回選択・ドラッグ中の前後のコマ(2026-11-03): 再生 ▸ **重なったクリップの音だけ試聴**(オン/オフ。オンの間、止まっている再生位置を動かす(ルーラーのドラッグ・←/→・クリック)と、選んだ 1 つのクリップだけが約 0.5 秒鳴る。他のクリップは混ざらない。複合クリップの中のクリップも対象)・**次の重なったクリップを試聴**(再生位置で鳴っているクリップを順に巡回)。プレビューを **⌥ クリック**すると、その場所に重なったクリップを手前から奥へ巡回して選べる(クリップ ▸ **重なったクリップを巡回選択** でも同じ。座標なしで画面に見えているクリップを巡回)。タイムラインでクリップを**移動**している間は、移動先のつなぎ目 ―― クリップの 1 コマ前・最初のコマ・最後のコマ・1 コマ後 ―― の 4 コマを帯にして重ねて出す(離すと消える。1 回の Undo は変わらない)。どれも保存されるデータは増えず、Undo にも載らない(ショートカットなし)。

コマの補間(2026-11-03): インスペクタの速度の欄に「コマの補間(速度が 1 未満のとき)」を追加(なし / ブレンド / オプティカルフロー)。オプティカルフローは Vision で前後のコマの動きを推定し、動きに沿った中間のコマを作る(重ね合わせの二重像が出ない)。最初のコマの組は動きの推定で約 0.2 秒かかる(1080p・Release の単一測定。組ごとに覚える)。保存は `frameFlow: true`(使うときだけ)。

絞りぼかし(2026-11-03): エフェクト **絞りぼかし**(半径・絞りの形 = 円/三角形/四角形/五角形/六角形/八角形/星/ハート・ハイライトの強調・形の向き)と、**ぼかし範囲**の方式「絞り」(背景ぼかしの形を選ぶ。`bokehShape`、円のときは書かない)。明るい光が選んだ形の円盤になる。
ファイル ▸ **未使用の素材…**: どのクリップ(複合クリップの中も含む)にも使われていない取り込み済みの素材を一覧し、「削除」「一括削除」で素材リストから外します(ディスクのファイルは消えません。1 回で元に戻せます。ショートカットなし)。編集でどのクリップからも使われなくなった素材は自動でこの一覧に入ります(`mediaPool` ができる前に消したクリップの素材は、書類に記録が無く出せません)。
自動保存: 編集中の書類の写しを、利用者のファイルとは別に `~/Library/Application Support/MovieCut/Recovery` へ 30 秒ごとに書きます(元のファイルは書き換えません)。保存・閉じたときに写しは消えます。異常終了で残った写しは、次の起動で「復元」「捨てる」「あとで」から選べます(「復元」は新しい書類として開きます)。

字幕とチャプター: ファイル ▸ 字幕を読み込む…(SRT / VTT を「字幕」レイヤーの文字クリップに。1 回で元に戻せます)、出力 ▸ **字幕を自動生成**(台本のセリフ = ボイスの文字から、同じ時刻の文字クリップを「字幕」レイヤーに作ります。見た目は「ゆっくり風」の文字スタイル。元のセリフの字幕表示は切れて二重に出ません。1 回で元に戻せ、もう一度押しても増えません)、出力 ▸ 字幕を書き出す…(ボイスの字幕と「字幕」レイヤーの文字を .srt / .vtt に)、出力 ▸ チャプターをコピー(マーカーから YouTube の `0:00 題名` を作ってコピー)。画面なしでは `moviecut-cli subs in.mcpjc --out x.srt`(`.vtt` も可)と `moviecut-cli chapters in.mcpjc`。

音声から字幕を作る: 出力 ▸ **音声から字幕を作る…**(選んでいる音のあるクリップ = 音声・ボイス・動画。速度を変えたもの・逆再生は対象外)を、Apple の音声認識で **この Mac の中だけで** 日本語として文字にし、「字幕」レイヤーの文字クリップ(字幕の自動生成と同じ見た目)に足します。時刻はクリップの位置に合わせ、1 回で元に戻せます。認識できた文が無ければ何も変えません。字幕のスタイルに「カラオケ字幕」が入っていると、認識した単語の時刻に合わせて色が付きます(文字が一致しないときは従来の字数比例)。処理中はキャンセルできます。初回は「音声認識」の許可を求められます(システム設定 ▸ プライバシーとセキュリティ ▸ 音声認識)。画面なしでは `moviecut-cli transcribe 素材.wav --out x.srt`。コマンドラインは許可を求められないので、先にアプリで許可してください。

## 書き出し中のファン最大化
「出力 ▸ 書き出し中はファンを最大にする」(設定シートにも同じチェック)をオンにすると、書き出しの間だけファンを最大回転にします。終了・キャンセル・失敗・アプリ終了のどれでも自動に戻し、状態欄に「ファン: 最大(6550 rpm)」→「ファン: 自動」と出ます。
- **対象機種**: MacBook Pro / Mac mini / Mac Studio だけ(`sysctl hw.model` と `system_profiler` のモデル名で判定する許可リスト。MacBook Air・iMac・Mac Pro・判定できない機種は対象外 = 何もしない)。対象外やサービス未導入のときはチェックが押せず、理由が 1 行出ます。
- **ファンを動かす仕組み**: SMC への書き込みは root が必要なので、別プロセスのヘルパーが `127.0.0.1` で待ち受け、アプリは HTTP で頼みます。**ポート 1200** = ユーザー自身の `fanctl`(あれば優先)、**ポート 1201** = Movie Cut 同梱の `moviecut-fanhelper`。
- **インストール**(同梱ヘルパーを使うとき): 出力 ▸ ファン制御を有効にする…(説明を確認 → 管理者パスワード)。`/usr/local/libexec/moviecut-fanhelper` と `/Library/LaunchDaemons/com.moviecut.fanhelper.plist` を置いて launchd に登録します。出力 ▸ ファン制御を無効にする…で停止・削除(止まるとき全ファンが自動に戻ります)。
- **安全策**: ユーザーがオンにしたときだけ動く / 5 秒ごとの heartbeat、ヘルパーは 15 秒途切れたら自動に戻す(fanctl には見張りが無いので、別セッションの小さなシェルが親プロセスの消滅を見て自動に戻す)/ CPU・GPU・SoC のセンサーが 95 ℃ 以上で自動に戻し、その書き出しでは再び最大にしない(ヘルパー自身も 100 ℃ で戻す)/ SIGTERM・SIGINT・終了時・解放漏れ(deinit)でも戻す / ヘルパーはブラウザ(Origin 付き)や別ホスト名(Host)からの要求を拒否。
- **限界**: アドホック署名のため `SMAppService` ではなく管理者権限のシェルでインストールする暫定方式。署名・ノータライズした配布版では `SMAppService.daemon` に切り替える。Apple Silicon の将来の macOS で SMC の書き込みが制限されると使えなくなる可能性がある。
- **コマンドライン**: `moviecut-cli fan status`(機種・サービス・ファンの状態)、`moviecut-cli fan test [--seconds 6]`(最大にして読み戻し、必ず自動に戻して確認。最大 8 秒)、`moviecut-cli export in.mcpjc out.mp4 --fan-max`。`--fan-port 1200|1201` で調べる先を固定できます。

AI 連携(任意・オフライン優先): クラウドの鍵はアプリにもプロジェクトにも保存しません。ファイル ▸ **AI の設定…** で、ご自分のコマンド(例: `claude -p` / `codex exec -`。プロンプトは標準入力で渡す)か、このマシン上の Ollama 形式のサーバー(`http://127.0.0.1:11434`)を指定します(設定は UserDefaults)。呼ばれるのは次のメニューを選んだときだけで、**送る内容を必ず見せて確認してから**送ります(問い合わせ中はキャンセルできます。失敗は日本語で表示)。ファイル ▸ **AIで台本を作る…**(テーマ・キャラ・行数 → 「キャラ名: セリフ」を台本欄へ。音声は自分で「台本から音声を作る」を押したときだけ)、出力 ▸ **チャプター案をAIで作る…**(字幕から。マーカーに足してコピー / コピーだけ)、クリップ ▸ **AIでセリフを直す…**(言い換え・短縮・くだけた口調。前後を見て適用すると音声ごと作り直し、元に戻すのは 1 回)。画面なしでは `moviecut-cli ai script --theme 猫の飼い方 --provider-cmd "claude -p" [--chars 霊夢,魔理沙] [--lines 12] [--out x.txt] [--show-prompt]`(`--provider-url http://127.0.0.1:11434 --model <名前>` も可)と、外部の AI がプロジェクトを読むための読み取り専用 `moviecut-cli project-info in.mcpjc`(クリップ・長さ・キャラ・セリフの JSON)。

## 変形とキーフレーム
画像・動画・文字は、位置・拡大・回転・左右/上下反転・切り抜き・不透明度(と、ぼかし)を時間で動かせます。プロパティ欄の各項目の右の ◇ を押すと、再生ヘッドの位置にキーフレームを足します(◆ = ここにキーあり、半塗り = 動く項目)。◀ ▶ で前後のキーへ。キーに再生ヘッドを合わせて曲線ボタンを押すと、次のキーまでの動き方を曲線エディタ(制御点のドラッグ・プリセット・数値・リセット)で編集できます。選択クリップの下端の菱形はタイムラインで動かせ、プレビューの枠(角で拡大・上の丸で回転・本体で移動)でも変形できます。
メニュー: クリップ ▸ キーフレーム(追加/削除 ⌥⌘K・前へ ⌥⌘,・次へ ⌥⌘.・すべて消去)/ クリップ ▸ アニメーション(ズームイン・ズームアウト・左/右/上/下からスライド・回転しながら登場・ゆっくり拡大)。ファイル形式は `DESIGN.md` を見てください(古いファイルはそのまま開け、使わなければ書き足されません)。

## 文字の装飾・スタイル・アニメーション
文字クリップ(と字幕)に、影(色・ずれ・ぼかし・濃さ)・文字の後ろの箱(色・濃さ・余白・角の丸み)・グラデーションの塗り・字間・行間・揃え(左・中央・右)・太字・斜体を付けられます。プロパティ欄の「装飾」(字幕は「字幕の装飾」)で、スライダーはドラッグ 1 回 = 1 回の取り消しです。使わない項目はファイルに書かれず、古いファイルは変わりません。
「スタイル」: 組み込みの 6 つ(標準・ゆっくり風・ニュース帯・見出し・吹き出し風・注意)と、「現在の見た目を保存…」で名前をつけて保存したスタイル(色・縁・書体・装飾。アプリ全体で共有)を、1 回の取り消しで当てられます。名前の変更・削除は「保存したスタイルの管理」。
「文字アニメーション」: タイプライター(文字が順に出る)・ポップ(0.6 倍 → 1.1 倍 → 1 倍)・シェイク(揺れて止まる)・フェードイン(文字全体が透明から現れる)を、クリップの頭から指定の秒数だけかけます。スクロール（上へ・左へ）は速さで流れ、クリップの終わりまで動き続けます(クレジット・流れる帯)。組み込みスタイルに「フェードイン」「タイプライター」「ポップ」があり、選ぶと色や書体はそのままで、その動きだけを付けます(1 回の取り消しで戻せます)。
「調整レイヤー」(クリップ ▸ 調整レイヤーを追加): 下に描いてある全部の合成結果に、自分のエフェクトを一度かけます。不透明度で元の絵との混ぜ具合を決めます。
メニュー: クリップ ▸ テキスト ▸ スタイルを適用 / 文字アニメーション(ショートカットなし)。ファイル形式は `DESIGN.md`。

## エフェクト
画像・動画・文字のクリップに、明るさ・コントラスト・彩度・色相・露出・シャープ・モノクロ・セピア・ビネット・モザイク・ガウスぼかし・ズームぼかし・モーションぼかし・グロー・ドロップシャドウ・縁取り・クロマキー・LUT・ホワイトバランス（色温度・ティント）・カラーホイール（持ち上げ・ガンマ・ゲイン）・光学ミスト（明るい所だけがふんわりにじむ。量・しきい値・ぼかし半径）・ハイライト補正（明るい部分を白の手前へ寄せる。膝の位置）を重ねられます(Core Image。プレビューと書き出しは同じ描画)。プロパティ欄の「エフェクト」で追加・有効/無効・並べ替え・初期値に戻す・スライダー調整ができ、各値は ◇ でキーフレームにできます。
顔ぼかし(Vision で顔を検出し、その枠だけをモザイクかぼかし。強さと方式。顔が見つからなければ何もかかりません。調整レイヤーには効きません)。クロマキーは抜く色・色の許容・なめらかさ・色かぶりの除去、LUT は .cube(1D/3D)ファイルと強さ(ファイルが無い・壊れているときは何もかからず、プロパティ欄に赤字で出ます)。メニュー: クリップ ▸ LUT を読み込む…(.cube を選ぶと LUT エフェクトを足す/差し替え)。クリップ ▸ エフェクト(各種類を追加 / プリセット: ビンテージ・白黒映画・夢のような・強調・モザイク全体 / エフェクトをすべて外す / エフェクトのコピー / エフェクトの貼り付け。ショートカットなし)。ファイル形式は `DESIGN.md`(古いファイルはそのまま開け、使わなければ書き足されません)。

## トランジションと音声フェード
画像・動画・文字のクリップの頭と終わりに、フェード・ズーム・スライド・ワイプ(直線・円形・時計回り)・ぼかし・回転を付けられます。プロパティ欄の「トランジション」で 開始 / 終了 の種類・長さ・進み方を選びます(長さは 0.05 秒〜クリップの半分・5 秒まで)。タイムラインのクリップの頭と終わりに三角が出て、選んでいるクリップは先端の丸をドラッグして長さを変えられます。音声・ボイス・動画は、フェードイン/アウト(秒)と曲線をプロパティ欄で設定でき、書き出しの音声に反映されます。
メニュー: クリップ ▸ トランジション(開始・終了の種類、両方にフェードを付ける ⌥⌘F、すべて外す)/ クリップ ▸ クロスフェードにする(下のレイヤーのクリップと重なっているとき、重なりの長さで頭をフェードにします)/ クリップ ▸ フェードイン・アウトを付ける(0.5 秒、映像と音声)。ファイル形式は `DESIGN.md` を見てください(古いファイルはそのまま開け、使わなければ書き足されません)。

## 速度・逆再生・フリーズフレーム
動画と音声のクリップは、0.25〜4 倍の速度、逆再生、音程を保つ/保たない(速度が 1 でないとき。保つのが既定)を選べます。プロパティ欄の「速度」(Picker・数値・スライダー・逆再生・音程を保つ・「元の長さ → 新しい長さ」)。クリップの頭と素材の頭(イン点)は変えずに長さが変わり、後ろのクリップは動かしません(延びる分は同じレイヤーの次のクリップの手前で止まります)。分割・トリムは、速度と逆再生を考えて素材が途切れないようにつながります。タイムラインでは速度が 1 でないクリップなどの右上に `×2` `◀` `静止` の札が付きます。
メニュー: クリップ ▸ 速度(0.25倍・0.5倍・通常・2倍・4倍・逆再生にする・フリーズフレーム)/ クリップ ▸ フリーズフレーム（静止画にする）(再生位置のコマを 2 秒の静止画にして、元のクリップをそこで割って間に入れます。同じレイヤーの後ろのクリップは 2 秒ずれます。音は無音。ショートカットなし)。ファイル形式と計算は `DESIGN.md` の「速度変更・逆再生・フリーズフレーム」(古いファイルはそのまま開け、使わなければ書き足されません)。逆再生の書き出しは、素材を区間ごとにメモリへ読むので、メモリの目安は環境変数 `MC_REVERSE_CACHE_MB`(既定 384)で変えられます。

速度ランプ(インスペクタで点を置き、時間で速さを変える)と、速度 1 未満のフレームブレンド(動画・インスペクタのチェック)も使えます。速度ランプの音は音程が速度に従います(「音程を保つ」は効きません)。詳しくは `DESIGN.md` の「速度ランプ・フレームブレンド」。

## クリップの音声処理
音声・ボイス・動画のクリップに、音量のキーフレーム(◇ と ◀ ▶)、パン(等パワー)、3 バンドのイコライザー(低域 100 Hz・中域 1 kHz・高域 8 kHz、±12 dB)、コンプレッサー、リバーブ(小・中・大・ホール)、ノーマライズ(ピーク / ラウドネス)を付けられます。プロパティ欄「音声」の折りたためる節で編集します(スライダーのドラッグは 1 回の Undo)。処理は MovieCutCore の純粋な Swift(Audio Unit は使わないので、同じ設定なら同じ音)で、プレビューと書き出しは同じミキサーを通ります。順番は 速度 → EQ → コンプレッサー → リバーブ → ノーマライズ → 音量 → フェード → パン。リバーブの余韻はクリップの終わりで切れ、ノーマライズはクリップ全体を一度測ってから合わせます。
メニュー: クリップ ▸ 音声(ノーマライズ（ピーク −1 dB）・音量を上げる +3 dB・音量を下げる −3 dB・ボイス向けプリセット（EQ + コンプレッサー）・音声エフェクトをすべて外す。ショートカットなし)。インスペクタ「音声」の先頭に「ノイズ除去」(簡易。静かな所を下げる。0〜100%)。ファイル形式と計算は `DESIGN.md` の「クリップの音声処理」(古いファイルはそのまま開け、使わなければ書き足されません)。

### 無音カットと BGM の自動ダッキング

- **無音をカット**: 音のあるクリップ(音声・ボイス・動画。速度・逆再生なし)を選び、クリップ ▸ 無音をカット…。しきい値(dB)・最短の無音(秒)・余白(秒)・後ろを詰める、を動かすと「N 箇所をカットします」がすぐ変わります。「カット」で全体が 1 回の Undo。余白は無音の両端(語頭・語尾)に残します。クリップの頭・終わりに接する側には残しません。全部が無音になる設定ではカットしません。「後ろを詰める」は、切った断片を前へ詰め、同じレイヤーの後ろのクリップも左へ詰めます(ほかのレイヤーは動きません)。
- **画面なしの確認**: `moviecut-cli silence <プロジェクト|音声・動画> --threshold -40 --min 0.4 --pad 0.1` で無音の範囲と残す範囲を表示します(ファイルは変えません)。
- **BGM の自動ダッキング**: 音声クリップ(BGM)のインスペクタ「自動ダッキング」(声があるときに BGM を下げる・下げる量 dB・アタック・リリース)、またはクリップ ▸ 音声 ▸ 自動ダッキングを切り替え。音の出るボイスクリップがある間、BGM を下げます。声の少し前(アタック)から下げ始め、声が終わるとリリースをかけて戻ります。プレビューも書き出しも同じ計算です。

### 書き出しキューと素材ブラウザ

- **書き出しキュー**: 出力 ▸ **書き出しキューに追加…**(今の設定のまま MP4。保存先を選ぶと、いまのプロジェクトの写しを末尾に積みます。範囲があれば範囲だけ。積んだあとで編集しても、その件は積んだ時点の内容で書き出します)。出力 ▸ **書き出しキューを表示…** で、件ごとの状態(待機中・書き出し中 %・完了・取り消し・失敗)と進み具合を見て、件ごとに「取り消す」を押せます。1 件ずつ先着順に実行します。終わった件は「終わったものを消す」で一覧から外せます。書き出しキューの件は Dock の進行バーとファン最大化は使いません(件数と状態はキューの画面で確認)。ショートカットはありません。
- **テンプレート: ファイル ▸ **テンプレートとして保存…**(クリップを外し、キャラクター・レイヤー・設定・マーカーを `~/Library/Application Support/MovieCut/Templates` に保存)、ファイル ▸ **テンプレートから新規作成**(一覧から選ぶと、中身を入れた無題の書類が開きます。元のテンプレートは変わりません)。
- **起動時の画面(最近使ったプロジェクト)**: 起動して開いている書類がないとき、名前・場所・更新日の一覧を出します(見つからないものは灰色で「見つかりません」)。ダブルクリックで開く、「新規」「開く…」、「起動時にこの画面を表示」のチェック(既定オン)。ファイル ▸ **最近使った項目**、ファイル ▸ **起動時の画面を表示** からも操作できます。履歴は開く・保存のたびに最大 20 件。
- **素材ブラウザ**: ファイル ▸ **素材ブラウザを開く…**。BGM・効果音を入れたフォルダを一度選ぶと(次回から覚えています)、中の音声(mp3・wav・m4a・aac・ogg。サブフォルダは見ません)が名前の順に並び、長さと一緒に出ます。▶ で試し聴き(一度に 1 つ)、「タイムラインに追加」で再生ヘッドの位置に置きます(1 回の取り消しで戻せます)。動画・音声・画像を並べ替え(名前・更新日・種類)でき、長さも出ます。行やグリッドをタイムラインへドラッグすると、落とした位置に吸着して(再生ヘッド・クリップの端・マーカー)、落とした行のレイヤーに入ります。壊れたファイルは「読めないファイル」と出て、追加もドラッグもできません。素材ブラウザは別ウインドウです(開いたままタイムラインへ落とせます)。
  - 2026-11-02 追加: 対象は動画・音声・画像。種類の絞り込み(すべて・動画・音声・画像)、名前での検索(大文字小文字・全角半角を無視)、リスト/グリッド表示(動画・画像はサムネイル)。選ぶと右にプレビュー。ダブルクリックか Return で再生ヘッドに置きます(1 回の取り消し)。
- **クリップ ▸ 選択クリップを再生ヘッドに揃える / 選択クリップをつなげて並べる**: 選んだクリップの位置合わせ(それぞれ 1 回の取り消し。ロックされたレイヤーは動かさない)。

## タイムライン(複数選択・コピー&ペースト・レイヤー・サムネイルと波形)
- **複数選択**: ⌘-クリックでトグル、⇧-クリックで同じレイヤーの間をまとめて足す、何もない所のドラッグで四角(ラバーバンド)、⌘A(タイムラインにフォーカスがあるとき)で全部。削除・すき間を詰めて削除・複製・切り取り・コピー・ドラッグ移動は選んだ全部にかかります(移動は相対位置を保ち、1 回の Undo。重なりは単独のドラッグと同じく許します)。プロパティ欄は「n個のクリップを選択中」+ 操作ボタン。
- **コピー&ペースト**: ⌘C / ⌘X / ⌘V(タイムラインにフォーカスがあるとき。入力欄にフォーカスがあれば入力欄のコピーと貼り付けのまま)。再生位置に、相対位置を保って貼ります。レイヤーの名前(またはレイヤーの空き地)を押して選んだレイヤーがあればそこへ、なければ元のレイヤーへ。ペーストボードに専用の形式で書くので、別のウィンドウ・別のドキュメントにも貼れます。
- **レイヤー**: 名前をダブルクリックで変更、錠前でロック(ロックされたレイヤーのクリップは編集・移動・削除できず、貼り付けも飛ばします)、`S` でソロ(ソロがあれば、そのレイヤーだけ音が出ます)、右クリックまたはクリップ ▸ レイヤー で高さ(小・標準・大)。レイヤーの削除は、ヘッダーの右クリック ▸ レイヤーを削除…、またはクリップ ▸ レイヤー ▸ レイヤーを削除…(中のクリップごと消えます。クリップがあるときとロック中のレイヤーでは確認が出て、ロック中はその旨が書かれます。最後の 1 つは消せません。取り消しは 1 回です)。
- **クリップのロック**: クリップ ▸ クリップをロック(ロック済みなら「ロックを解除」)、またはクリップの右クリック。ロックしたクリップは錠前の印が付き、移動・トリム・分割・削除・プロパティの編集ができません(選ぶ・コピーはできます)。取り消しは 1 回です。
- **ロール編集 / スリップ編集**: 同じレイヤーでぴったり隣り合う 2 つのクリップの境界を動かす(片方の終わりを縮め、もう片方の頭を同じだけ延ばす。全体の長さは変わらない)のがロール、クリップの位置と長さはそのままで使う素材の区間だけをずらすのがスリップです。タイムラインでは、クリップの端(境界)を **⌥ ドラッグ**でロック、クリップ本体を **⌥⇧ ドラッグ**でスリップ。メニューはクリップ ▸ **ロール編集…** / **スリップ編集…**(コマ数を入れる。負の数で前へ)。素材の範囲を超える分は手前で止まり、ロックされたクリップ・レイヤーは断ります。取り消しは 1 回、変わらないときは履歴に載りません。
- **リップルトリム**: クリップの頭または尻をトリムして、同じレイヤーの後ろのクリップを長さの変化ぶんだけ詰める(延ばせば空ける)。頭のトリムは頭の位置を動かさず、使う素材の区間と長さだけを変えます。タイムラインではクリップの端を **⌘ ドラッグ**(本体の ⌘ クリックはいつもどおり選択の切り替え)。メニューはクリップ ▸ **リップルトリム(頭)を再生位置へ** / **(尻)を再生位置へ**(再生位置がクリップの途中にあるとき)と、クリップ ▸ **リップルトリムをすべてのレイヤーに**(オンなら全レイヤーの後ろのクリップが動く。保存しない設定)。関わるクリップ・レイヤーに1つでもロックがあれば全体を断り、新しい重なりを作る編集も断ります。取り消しは 1 回、変わらないときは履歴に載りません。
- **マルチカメラ編集**: 同じ出来事を別のカメラで撮った映像クリップ(2〜9 個)を選び、クリップ ▸ マルチカメラ ▸ **マルチカメラを作る…**。いちばん先頭のクリップ(カメラ1)の音を基準に、音の相互相関(10 ミリ秒の精度)で各カメラのずれを測ります(合わなかったときは、シートでずれを手入力)。作ると、結果を置く新しいレイヤーが一番手前に足され、カメラ1 以外の元のクリップは無音になります(音はカメラ1)。**マルチカメラ切替…** のシートでは、再生しながら **1〜9 のキー**(またはボタン)でその時刻からそのカメラに切り替えます(キーはこのシートの中だけで、アプリ全体のショートカットにはしません)。メニューの「再生位置からアングル N に切り替え」でも同じ。切り替えの結果は**普通の分割クリップ**なので、書き出しに新しい経路はありません。切り替えは 1 回ずつ元に戻せ、同じカメラへの切り替えは履歴に載りません。ファイルには、使ったときだけ `multicams`(角度とずれ)が入ります。
- **トラックターゲット**: レイヤーのヘッダーの的の印(またはクリップ ▸ レイヤー ▸ トラックターゲットにする)で、新しく足すクリップの行き先を 1 つ決めます。素材を追加・素材ブラウザのダブルクリック・テキストを追加・字幕を追加がそのレイヤーに入ります(ロック中・その時間が埋まっているときは今までどおり)。印が無ければ従来の動きです。
- **サムネイルと波形**: 動画・画像のクリップに絵の帯、音声・ボイス・動画に波形。裏で作り(メモリのみ・待たせません)、できるまではクリップの色のままです。
- メニュー: 編集 ▸ クリップをコピー / 切り取り / 貼り付け / すべてのクリップを選択(アクセラレータなし。⌘C ⌘X ⌘V ⌘A は標準の項目が受けます)、クリップ ▸ レイヤー(レイヤーをロック・レイヤーをソロ・高さ: 小 / 標準 / 大)。右クリックのメニュー(ヘッダー・クリップ)もあります。ファイル形式は `DESIGN.md` の「タイムライン(フェーズ A6)」(古いファイルはそのまま開け、使わなければ書き足されません)。範囲選択は未実装です。

## キャラクター演出(口パク・まばたき・表情・バウンス)
- 口は、声の音量で開閉します(開く・閉じる閾値を分けて、境目でチラつかないようにしています)。キャラの「口を開いた画像」を入れると切り替わります。
- まばたき: キャラの `imgBlink`(目を閉じた画像)を入れると、3〜5 秒ごとに 0.15 秒だけ閉じます。
- 表情: キャラの `expressions`(表情名 → 画像)を入れて、台本のセリフを `[笑顔]こんにちは` のように書くと、その行の間だけ表情が変わります。字幕と読み上げからはタグが消えます。辞書に無い名前は無視されます。
- バウンス: キャラの `bounce: true` で、話している間に音量に合わせて上下に揺れます。
- あいうえお口パク: キャラの口画像「あ・い・う・え・お」(`imgVowels`)を 1 つでも選ぶと、セリフの読み(漢字も読みに直す)に合わせて口の形が変わります。ん・っ・無音は口を閉じ、ー は直前の母音を伸ばし、選んでいない母音は「口開き」の画像になります。プレビューと書き出しで同じ結果です。
- **パーツ式立ち絵**: 眉・目・口・髪・体などの透過 PNG(同じ大きさ)を重ねて 1 枚の立ち絵にして動かします。ファイル ▸ **立ち絵パーツのフォルダを読み込む…**(ファイル名・フォルダ名からスロットに自動で分けます)か、ファイル ▸ **PSDから立ち絵を作る…**(グループ名・レイヤー名から分けます)で新しいキャラができます。キャラのインスペクタの「立ち絵パーツ」で、スロットごとの見本からパーツを選び、「これを まばたき」「口の 閉じ/開き/あ・い・う・え・お」の割り当て、表情(今の選択を取り込んで名前をつける。セリフの `[名前]` で切り替え)を設定します。自動の振り分けは目安なので、違っていたらインスペクタで直します。確認用に `moviecut-cli rig-frame <フォルダ|.psd> --out x.png [--mouth あ] [--blink]` で合成を画像に書き出せます。
- インスペクタ(キャラクター)で、立ち絵(口閉じ・口開き)・まばたき画像・バウンス・表情(名前と画像の一覧。追加・名前の変更・差し替え・削除)を設定できます。画像は NSOpenPanel で選び、1 回の操作が 1 回の取り消しです。

## 手ぶれ補正(簡易版・映像クリップ)
映像クリップの揺れを、コマの画素のずれ(Vision の並進位置合わせ)から滑らかな軌跡に直して補正します。メニュー: クリップ ▸ 手ぶれ補正（映像を滑らかにする）(オン/オフ。強さは既定 0.8、ショートカットなし)。インスペクタの「手ぶれ補正」で強さ(0〜1)を動かせます(ドラッグは 1 回の取り消し)。縁は拡大で隠します。解析は素材ごとに 1 回だけ(キャッシュ)で、プレビューは解析が終わるまで補正なしのコマを出し、終わったら描き直します。書き出しは解析の完了を待つので結果は同じです。計算と計測は `DESIGN.md` の「手ぶれ補正(簡易版)」。

## 複合クリップ
複数のクリップを 1 つにまとめ、中を子のレイヤーとして持ちます(クリップ ▸ 複合クリップにまとめる / 複合クリップを解除。ショートカットなし。どちらも 1 回の取り消し)。まとめた複合クリップは、位置・効果・不透明度・トランジションを全体にかけられます。中身は描画と音声にそのまま効きます。解除すると、元のレイヤーに戻ります。詳しくは `DESIGN.md` の「複合クリップ」。

## 吹き出し(文字クリップ)
- 文字クリップのインスペクタ ▸ 吹き出し: 「吹き出しを付ける」で、文字の後ろに形(丸角・雲・四角)・塗り・縁の色と太さ・尾を付けます。尾の先は「画面上の点」(正規化した x・y)か「キャラ」(キャラの位置＋ずれ)で指定します。組み込みの「吹き出し風」スタイルも吹き出しを使います。

## 画面のドッキング(パネルの並べ替え)
キャラクター・プレビュー(再生バーつき)・プロパティ・タイムラインの 4 つのパネルを、自由に並べ替えられます。初期配置は YMM4 風で、左側約 66% の上にプレビュー(約 60%)、下にタイムライン(約 40%)を置き、右側約 34% にプロパティとキャラクターをタブでまとめます。最初はプロパティを表示します。
- パネルの上のタブをドラッグ: 重ねたグループの上に **5 つの置き場所**が出て、ポインタの下の領域が半透明の色で塗られ(着地する場所の予告)、ポインタに合わせて動きます。中央(点線の内側・タブバー)= **タブにまとめる**、上下左右 = その側に **分割**。ウインドウの**外側の端**(左・右・下の端の帯、上は端の細い帯)に落とすと、ドック全体の端に置きます(左右は幅の 1/4、上下は高さの 1/4)。仕切りをドラッグして大きさを変えられます。
- タブを右クリック: **別ウインドウで開く**(同じプロジェクトを別ウインドウで編集・再生できます。ウインドウを閉じると元に戻ります)/ **閉じる**。
- タブを掴んで書類のウインドウの外へ引き出すと、そのパネルは別ウインドウになってカーソルに付いてきます(Chrome のタブの引き剥がしと同じ)。書類の上で離すと元の隣へ戻り、端の帯で離すとその端に入ります。別ウインドウの上の「ウインドウに戻す」でも戻ります。戻し先は記録されていて、保存されます(実機での操作は未確認)。
- メニュー: 表示 ▸ パネル(キャラクター / プレビュー / プロパティ / タイムライン。出ているものに ✓、選ぶと閉じる・開く)、表示 ▸ レイアウト(初期配置に戻す / 1つのタブにまとめる / すべて分離 / プレビューを大きく)。ショートカットなし。
- 配置はアプリ全体の設定として保存され(プロジェクトファイルには入りません)、次の起動で復元します。別ウインドウに出していたパネルは、起動時に元の位置へ戻ります。形式は `DESIGN.md` の「画面のドッキング」。
- メニュー: 表示 ▸ **プレビューの背景** ▸ 暗い灰色(既定・#1E1E1E)/ 黒 / 白 / 中間グレー / 緑(クロマキー)/ 青(選んでいるものに ✓)。プレビューの背後は**単色**(市松模様は使いません)。アプリ全体の見た目の設定で(UserDefaults `previewBackground.v1`)、プロジェクトファイルにも書き出しにも関係しません(書き出しの背景は 出力 ▸ 背景色)。
- 解像度とフレームレート(「1920×1080 · 60fps」)は、映像の上には重ねず、再生バーの時刻の右に小さく出します。
- メニューバー右側の常駐アイコン(状態アイコン)は置きません(以前のものは撤去しました)。
- 「別画面に表示」(外付け画面へプレビューを全画面表示)は廃止しました。⌘P は空いています。

- **素材**: 開いたとき欠けた素材があれば案内(「フォルダから探す」「パッケージとして保存…」「あとで」)。探し直しはフォルダを再帰的に見て、目印にサイズがあればファイル名とサイズの両方で一致させます。ファイル ▸ **パッケージとして保存…** は、プロジェクトと使っている素材を `media/` にまとめたフォルダを作ります(参照は相対パス。今開いている書類は変わりません)。

## 音MAD 向け(2026-11-05)
- **音程**: 半音(−24〜+24)+ 微調整(セント)。速度とは独立(長さを変えずに高さだけ)。プレビューと書き出しは同じミキサーの経路。0 のときは書かない。キーフレームは未対応(音程は区間ごとに作り直す処理で、時間で連続的に変える方式が無いため)。
- **波形**: 音声・ボイス・動画のクリップに波形(素材ごとにパス+更新日時で裏で作り、メモリに保持。トリム・速度・逆再生に追従)。粗い段(8・64・512 ピークの最大値)を持ち、縮小表示でも描き直しが軽い(1 時間・2000 本で 1.2 ms、デバッグビルド)。
- **クリップ ▸ 選択クリップを音階で複製…**: 長音階・短音階・半音階・ペンタトニック(長調・短調)、開始の音(元の音から ±24 半音)、個数、下降。元のクリップが 1 つ目の音で、すき間なく並べる。元のレイヤーが塞がっていれば別のレイヤーへ。1 回の Undo。
- **クリップ ▸ ビートに合わせてクリップを並べる…**: クリップの位置以降のマーカー(「ビート」だけにもできる)の位置に繰り返し置く。次のマーカーより長いぶんは短くする。1 つごとの音程の変化(±12 半音)と個数の上限。1 回の Undo。
- **逆再生の音**: 既存の「逆再生にする」(クリップ ▸ 速度)が音も逆にする(新規実装なし)。

## 個人版と配布版(エディション)
Info.plist の `MovieCutEdition`(`personal` / `public`。無ければ `personal`)で、データの置き場を分けています。個人版は今までと同じ場所(`~/Library/Application Support/MovieCut/...`・バンドル ID `jp.local.moviecut`)で、既存のデータや設定は移動も変換もしません。

- **作り方**: 個人版は `Scripts/make-app.sh [dmg]`(`build/`)。配布版は `Scripts/make-app.sh --edition public [dmg]`(`build/public/`、バンドル ID `jp.local.moviecut.public`、アプリ名は同じ「Movie Cut」)。
- **分けているもの**: Application Support のフォルダ(個人版 `MovieCut`、配布版 `Movie Cut (Public)`)の下の Fonts・Proxies・voices・Templates・export-presets.json・Recovery(自動保存の復元)・QRCodes・AIImages・PSDCache・Cutouts と、設定(UserDefaults。最近使ったプロジェクト・素材フォルダ・文字スタイル・ドックの配置など)。保存先は Core の `DataLocations`(`AppEdition.swift`)だけが決めます。
- **個人のデータを配布に入れない**: 配布版のビルドはビルド場所のパスを消し(`-file-prefix-map`)、`strip` したうえで、バンドルに `/Users/`・個人名・PSD/動画/音声・試験用ファイル・データフォルダが入っていないかを調べ、見つかるとビルドを失敗にします。ソースにも個人のパスや名前を書かないことを試験(`DistributionGuardTests`)で守っています。
